# 宏观因子行业轮动体系

# ——主观与量化结合新尝试

## 核心观点

本文主要完成了两大类宏观变量指导行业轮动的建模方式在 A 股市场上的实证。一方面我们将普林格周期应用到 A 股行业轮动上，构造的组合 2019 年以来年化超额行业等权 5.4%，2023年 2 月以来（样本外）超额 11.3%。针对预测拟合型建模方式，我们设计了分类和回归两种方案，其中回归方案我们构造的模型5 分组多头年化超额 14%，4 月模型推荐组合超额行业等权 0.4%。5 月最新行业推荐为食品饮料、计算机、国防军工、传媒、通信。

## 主要结论

## 普林格周期在行业轮动中的应用

普林格周期使用先行指标、同步指标、滞后指标将宏观环境划分为六个状态，之前的实证结果表明，在普林格经济周期各个阶段的轮换中大类资产收益率有所分化，集中配置占优标的可以获得较高收益。我们将普林格周期应用于 A 股行业配置，根据历史各个阶段行业收益统计对占优行业进行集中配置，滚动回测结果显示，多头组年化超额5.44%，样本外（2023年2月以来）超额11.3%。

## 逐步回归+线性回归方案

模型自变量为 17 个基础宏观变量经过差分、主观标记、领先滞后等处理后的 204 个变量，因变量为 29 个中信一级行业超额收益。我们通过逐步回归进行变量选择，使用至多不超过 5 个宏观变量来解释单一行业超额收益。经过超额收益拟合、月度效应拟合构造宏观-行业超额收益预期因子，2019 年以来因子五分组多头年化超额 14.11%，多空年化 22.1%，分年来看多头每年均可以获得正超额收益。模型 4 月行业推荐为食品饮料、医药、传媒、非银行金融、有色金融，组合超额行业等权 0.4%，5 月最新行业推荐为食品饮料、计算机、国防军工、传媒、通信。

## 逻辑回归+L1 惩罚项方案

我们针对行业超额收益进行分解，通过行业两两配对的方式将回归问题等价转化为一系列更容易的分类问题，是一种对行业截面的精细化切分建模方式。模型自变量与回归方案一致，因变量为29 个中信一级行业的配对相对超额。我们通过逻辑回归+L1 惩罚项的方式进行嵌入式变量选择和模型拟合，通过将两两配对相对强弱进行加总可以得到行业截面排名预期因子，2019 年以来因子五分组多头年化超额 13.53%，多空年化 22.7%。

## 一、引言

本文主要介绍使用宏观变量进行行业轮动的建模过程。这一模块旨在利用宏观变量解释行业的截面收益差异进而从宏观视角对行业进行优选，本节针对这一话题进行文献回顾，文献中使用宏观变量指导行业选择的方法主要有两种，一种是使用少数几个宏观变量划分经济周期，对应的投资策略为投资于每个经济周期中的占优行业，另外一种为针对每个行业构建行业收益率与宏观变量之间的回归模型，对应投资策略为投资于预测收益率较高的行业。

第一种建模方式主要取决如如何划分经济周期。美林时钟模型是较为经典的划分经济阶段的方法，即使用GDP 和 CPI 的上行下行将经济周期划分为复苏、过热、滞涨、衰退，Greetham and Hartnett[2004]统计发现可选消费、通信、科技行业在复苏阶段占优，科技、制造业、能源周期类行业在过热阶段占优，医药、能源、基础设施行业在滞涨阶段占优，消费、金融等在衰退阶段占优。Sauer[2019]、Wang et al[2020]尝试使用不同的宏观变量对经济周期进行划分并在每个周期中进行行业优选。

第二种建模方式主要是构造行业超额收益与宏观变量的回归模型，使用宏观变量解释行业超额收益。Chongand Phillips[2015]使用滚动三年数据估计 ETA模型参数，并使用均值方差模型构造行业组合超越基准。Gao andRen[2015]利用主成分回归建模，使用滚动四年数据估计模型参数，周度预测行业收益率，根据预测收益率构造行业多空组合，回测业绩显著超越基准指数。Y. Zhu[2020]将这一思想应用于中国权益市场，通过 5 个宏观因子（增长、通胀、利率、信用、外汇）以及其滞后项来解释中信一级行业截面收益率，并用 PCA 和随机森林进行变量筛选，选取 5 个预测最优行业来构造等权组合，显著超额行业等权组合。

本文主要针对以上两种建模方法在中国权益市场上进行实证，针对第一种建模方式，我们使用普林格周期划分，这一经济周期划分已被证明在大类资产配置上表现卓越，本文进一步测试其在权益市场行业轮动上的表现，至于第二种建模方式，首先我们通过增加宏观变量范围以及领先滞后阶数的方式进一步扩大自变量维度，对因变量而言我们使用回归和分类两种建模方式，最终目标均为使用宏观变量预测未来行业截面收益率差异并据此构造策略。

## 二、普林格周期在行业轮动上的应用

普林格周期脱胎于美林时钟模型，在美林时钟模型增长/通胀的基础上加入信贷指标来更好的适应货币主义时代。在普林格周期中，使用先行指标（M1、M2 同比），同步指标（GDP 同比、工业增加值同比），滞后指标（PPI 同比）三个指标来衡量经济周期，将经济周期划分为六个阶段，并计算了在上述各个阶段中各类资产的回报率和股票不同风格回报率，结果表明，在经济周期各个阶段的轮换中，不论是大类资产还是股票风格，其收益率均有所分化，优势品种有超越大市的表现，具体周期划分以及表现如下图。

我们在资产因子月报中根据普林格周期划分构造了大类资产轮动策略：每月底预判下月普林格周期所处阶段，根据普林格所处阶段配置对应阶段占优资产，即阶段一配置债券，阶段二配置股票，阶段三和阶段四等权配置股票和商品，阶段五等权配置商品和黄金，阶段六等权配置债券和黄金。

## 二、行业超额收益-宏观变量回归建模实证

## 2.2回归变量选择与模型拟合

首先我们总览式地对整个建模和回测过程进行说明。假设我们想在某月月末𝑇使用模型预测𝑇+1月各个行业的超额收益，我们需要如下模型。

$$
Y _ { i , T + 1 } = f _ { i , T } ( X _ { T + 1 } )
$$

其中 $^ { \lceil } Y _ { i , T + 1 }$ 为行业𝑖在𝑇+1月相对行业等权的超额收益， $f _ { i , T }$ 表示模型拟合仅仅使用𝑇时刻可得的数据， $X _ { T + 1 }$ 表示𝑇+1月宏观变量的标记值。由于宏观数据的滞后披露性以及我们在基础数据中囊括了未来 1-3 期的变量，因此 $f _ { i , T }$ 基于的历史数据为截止到𝑇−5（3 个月领先变量+2 个月滞后披露）的所有可得宏观数据（自变量）以及对应时点行业超额收益（因变量）。预测时的输入变量 $\cdot X _ { T + 1 }$ 包括了𝑇+1当月的宏观变量和领先滞后 1-3 期变量，因此至多涉及到了𝑇+4月的宏观状态变量，这为模型的预测带来更多不确定性，模型预测误差将会既取决于历史拟合关系在未来是否延续又取决于对未来宏观变量趋势的预判，前者属于系统性误差（每个模型都有失效的时候）很难避免，但是后者我们可以通过变量选择尽可能的削弱其影响，考虑到宏观变量较多且单一变量与因变量之间相关性不高，类似 Lasso 式的嵌入式变量选择会失效，我们选择使用逐步回归的方法对变量进行选择。

我们对经典的逐步回归方法做了一些修改以适应使用宏观变量拟合行业超额收益率的目标。我们依次添加变量使得添加后的变量组合越来越显著（标准为模型拟合 值至少要小于 ），同时限制添加的变量与已有的变量是完全不同的变量，不能让同一变量的不同领先滞后变量入选（避免共线性），如果无法挑选出使得现有变量组合更显著的变量或者变量数达到预期设定上限（5）即停止变量筛选。

以上为单一月份训练时的变量选择流程。实际上由于训练数据量不同，每月训练的变量选择结果会有差异，为了控制最终使用的宏观模型变量的时变鲁棒性，即同一行业每月底训练时变量选择得到的变量尽可能一致或者随着时间变化不大，我们每月在决定哪些宏观变量最终入选时会回溯过去 Q 个月（包含本月最新变量选择结果）的变量选择结果，对变量出现的次数进行排序，使用出现次数在前 5 名的变量并剔除仅入选 1 次的变量作为最终模型入选变量。

最终模型拟合分为两步，首先使用行业超额收益率为因变量，逐步回归筛选出的变量为自变量进行 OLS 拟合并计算拟合残差，接着使用残差为因变量，月度示性变量为自变量进行第二步拟合。残差进行第二步拟合主要是为了刻画月度效应。

## 2.3基于宏观变量的行业超额收益率预期因子构建与回测

行业超额收益率预期因子主要取决于上节所述的回归模型以及目标月的宏观变量。我们对于模型拟合设计了若干参数：模型平均间隔 L，模型变量回看期 Q，两个参数均是为了提升模型时变鲁棒性，L 指的是使用过去 L个月月底训练得到的模型对目标月的行业预期收益率平均值作为因子值，Q 指的是每个月月底拟合前的宏观变量选择综合考虑了过去 Q 个月的变量选择结果。行业𝑖在𝑇+1月的因子值 $Y _ { i , T + 1 }$ 为

$$
Y _ { i , T + 1 } = \frac { \sum _ { k = 0 } ^ { L - 1 } f _ { i , T - k } ^ { Q } ( X _ { T + 1 } ) } { L }
$$

其中 $\mathsf { f } _ { \mathrm { i , T - k } } ^ { \mathrm { Q } }$ 指的是行业i使用截至到T−k月底的宏观变量拟合的模型且变量选择综合考虑了T−k,T−k−$1 \ldots \ldots \mathrm { T - k - Q + 1 }$ 月底的变量选择结果。

我们设定回测时间区间为 20181231-20240331，使用行业标的为中信一级行业指数（除综合金融），参数组合设置为 L=1，Q=6，即使用扩展的时间窗口训练模型，每月底的变量选择综合考虑了过去 6 个月的模型变量选择结果。

## 2.4参数敏感度分析

本节主要针对参数 L和 Q 对模型的回测表现做敏感度分析。我们令 L取值 1，2，3，4，6，12，Q 取值 1-10统计各种参数组合下回测时在每一年的超额收益分布情况。分年来看，模型在 2020，2021，2022，2024 表现较为优异，在 2023 年表现一般，具体主要是 2023 年下半年出现回撤，可能是宏观数据与实际资本市场反应的宏观感受出现了背离。从参数组合来看，Q=1 相比其余取值表现较为稳健，这也与直觉相符，Q=1 表示每个月滚动进行训练，相比其余参数对宏观环境的变化捕捉更为及时。 参数 L 表示每月的入选宏观变量决策回溯过去 L个月的宏观变量筛选结构，如果 L 取值较小，同一行业的变量每月仅仅取决于当月的逐步回归变量筛选结果，这可能会导致相近月份同一行业的入选宏观变量有较大差异，若 L取值较大，则当月宏观变量会因为综合考虑过于久远的历史时点变量筛选结果而失去时效性，综合分年回测结果，L=5，6，7，8 时模型表现较优。综合考虑两个参数分年表现，我们最终选择使用 Q=1,L=6 参数组合。

## 三、行业截面配对-宏观变量建模实证

在上一节中，我们对行业超额-宏观变量建模的方式为直接对行业超额收益与宏观变量进行 OLS 回归，这种建模方式通常会导致模型拟合优度较低，而且变量选择过程不具有时变稳定性，由此我们思考有没有可能将回归问题转化为更容易的分类问题，受到配对交易的启发，我们将行业超额收益进行了等价拆解，将一个回归任务等价拆解成了若干回归问题，并在新的框架下重新建模，本节相比上一节所用数据区别仅仅在因变量，自变量宏观变量的处理和使用与上节一致，不再赘述。

## 3.1回归问题等价转化为分类问题

针对行业选择，预测超额收益并在截面进行排名是一种建模方式，然而这种建模方式实际上存在信息冗余，如果投资目标是选择出截面排名靠前行业，那么不需要知道每个行业超额收益具体数值同样也能完成任务。具体来说，某个行业在截面上的排名等价于其相对其余行业的相对强弱，即只需要知道所有行业相对其余每个行业的超额收益率的符号即可。从公式角度来看，行业 A 的超额收益率实际上等于行业 A 相比其它行业超额收益的平均值，而针对预测截面排名的投资目标，事实上只需要知道行业 A 相比其余行业超额收益的符号。因此，我们可以另辟蹊径，将一个较难的回归任务转化为若干相对容易的分类任务。假如我们最终投资范围有n个行业，那么转化后的分类任务为n个行业的两两相对强弱，共计 $\begin{array} { r } { \mathrm { { C } } _ { \mathrm { { n } } } ^ { 2 } = \frac { \mathrm { { n } } ( \mathrm { { n } } - 1 ) } { 2 } } \end{array}$ 个分类任务。

## 3.2变量选择与模型拟合

假设我们想在某月月末𝑇使用模型预测𝑇+1月各个行业的相对强弱，我们需要如下模型。

$$
Y _ { i , j , T + 1 } = f _ { i , j , T } ( X _ { T + 1 } )
$$

其中 $Y _ { i , j , T + 1 }$ 为行业𝑖在𝑇+1月相对行业𝑗的超额收益符号，是一个仅取值 1 和 0 的二元变量，1 表示𝑇+1当月行业行业𝑖相对行业𝑗超额收益为正。 $f _ { i , j , T }$ 表示模型拟合仅仅使用𝑇时刻可得的数据， $X _ { T + 1 }$ 表示𝑇+1月宏观变量值。

29 个行业配对会将因变量变成 406 个配对的相对强弱，如果再使用以上逐步回归的方法进行变量筛选效率较慢，不利于后续模型开发和测试。同时由于问题从回归变为分类，模型拟合难度下降，类似 Lasso 式的嵌入式变量选择方案变得可行，考虑到模型可解释性，我们选择使用逻辑回归+L1 惩罚项的方式进行模型拟合和变量选择。

原始的逻辑回归本质上是在寻找一组参数使得给定样本在二项分布的假设下出现的概率最大，添加惩罚项即是在自变量的稀疏性与似然函数拟合之间做权衡，尽可能地使用较少的变量获得较高的似然拟合值，与我们想要在宏观变量-行业配对情形下想要达到的效果较为契合。

最终模型拟合即使用每一个行业配对相对强弱时间序列作为因变量，使用所有的宏观变量作为自变量来拟合带 L1 惩罚项的逻辑回归模型。

图 13:逻辑回归模型

$$
\hat { p } \left( X _ { i } \right) = \mathrm { e x p i t } \left( X _ { i } w + w _ { 0 } \right) = \frac { 1 } { 1 + \mathrm { e x p } \left( - X _ { i } w - w _ { 0 } \right) }
$$

$$
\operatorname* { m i n } _ { w } C \sum _ { i = 1 } ^ { n } s _ { i } \left( - y _ { i } \log \left( \hat { p } \left( X _ { i } \right) \right) - \left( 1 - y _ { i } \right) \log \left( 1 - \hat { p } \left( X _ { i } \right) \right) \right) + \| w \| _ { 1 }
$$

## 3.3基于宏观变量的行业截面排名预期因子构建与回测

行业截面排名预期因子主要取决于上节所述的逻辑回归模型以及目标月的宏观变量。我们对于模型拟合设计了若干参数：模型惩罚项参数 ，模型回看期 ，参数 为控制模型惩罚的程度，取值越小会使得最终筛选出的变量数越少，模型回看期 Q 是为了提升模型时变鲁棒性，Q 指的是使用过去 Q 个月月底训练得到的模型对目标月的行业配对综合打分作为配对因子值。行业配对 $( i , j )$ 在𝑇+1月的因子值 $Y _ { i , j , T + 1 }$ 为

$$
Y _ { i , j , T + 1 } = \sum _ { k = 0 } ^ { Q - 1 } f _ { i , j , T - k } ^ { C } ( X _ { T + 1 } )
$$

其中 $\mathsf { f } _ { \mathrm { i , j , T - k } } ^ { \mathrm { C } }$ 指的是使用截止到T−k月底的宏观变量拟合的模型且逻辑回归惩罚项参数设置为𝐶。通过对某一行业𝑖的所有配对因子值进行加总即可得到行业因子值。

$$
Y _ { i , T + 1 } = \sum _ { j } Y _ { i , j , T + 1 }
$$

## 3.4参数敏感度分析

本节主要针对参数 C和 L对模型的回测表现做敏感度分析。我们令 L取值 1，3，4，6，12，C取值 0.1-0.5等距 40 个点。统计各种参数组合下回测时在每一年的超额收益分布情况。分年来看，模型在 2023 年以外的年份表现较为优异，具体来看 2023 年主要是下半年出现回撤，可能是宏观数据与实际资本市场反应的宏观感受出现了背离。从参数组合来看，参数 L变动对最终回测的超额收益影响不大，说明模型的时变鲁棒性较好。参数C 表示模型拟合的惩罚程度，如果 C 取值较小，模型更倾向于使用较少的变量解释因变量，这可能会导致模型欠拟合，若 C取值较大，模型则倾向于尽可能使用更多的变量解释因变量，可能会导致模型过拟合。在本文框架下，我们希望尽可能使用较少的变量，因此我们最终选择参数的原则为在模型回测表现差异不大的条件下尽可能参数 C较小的参数组合。综合考虑两个参数分年表现，参数 C在 0.18 的邻域范围内取值时，模型表现均较为优异，最终我们选择 C=0.18，L=3 作为模型参数。

## 四、总结

本文详细讨论了宏观因子指导行业轮动的两种主流建模方式在 股上的实证。从实证结果可以发现，拟合预测模式相比周期划分精度更高，回测来看模型表现更为稳定，但是 2023 年拟合预测模型普遍失效，而周期划分表现优异，可能是 2023年中的经济状态切换较快，周期划分模型更容易捕捉变点，另一方面，2023 年以前周期划分在滚动测试时存在周期状态样本不足的问题，我们无法断言其在 2023 年以前表现不稳定是否是因为此问题，因此后续我们对两种建模结果均进行样本外跟踪。

针对拟合预测建模这一方式，我们展示了回归和分类两种任务设计方案。从实证结果可以发现，二者回测表现差异不大，分类模型的参数平原更为稳健，但是其变量筛选结果数量较多，解释性不如回归任务模式，而且会依赖更多的宏观变量预期，如果投资者对宏观预期准确率较有信心，我们推荐使用分类的模式，如果投资者对解释变量有较少的数量偏好且对模型解释性要求较高，我们推荐回归的模式。

我们创新性地对行业截面进行了配对切分，由此衍生出了回归的建模方式，事实上在切分这一维度，后续可以有更多工作可以开展，比如行业截面上是否也存在稀疏结构，即少数的配对即可解释截面的行业差异，或者配对在时序上的动量和反转效应等。
