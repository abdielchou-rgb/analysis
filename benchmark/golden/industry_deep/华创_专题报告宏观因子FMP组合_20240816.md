# 宏观因子 FMP 组合

## 研究背景

资产配置是投资组合管理中的一项重要策略，通过在不同资产类别之间进行分散投资，以实现风险和收益的平衡。在现代投资理论中，风险暴露的控制是资产配置的核心要素之一。随着全球金融市场的不断发展和演变，基于资产类别进行分散投资的传统资产配置方法面临越来越多的挑战。近年来的市场波动事件表明，仅依靠资产类别的多样化已不足以应对极端市场状况带来的风险，尤其是在金融危机期间，许多资产类别在危机中表现出高度的相关性，从而导致投资组合在关键时刻失去了应有的防御功能。在这种背景下，宏观因子量化方法逐渐受到关注和重视。宏观因子量化方法通过识别并利用驱动资产回报的系统性宏观风险因子，可以辅助理解和预测市场行为，帮助投资者在不同的经济环境下实现更有效的风险管理和收益优化。

## 宏观因子的因子模拟组合构建方法

从不同的逻辑角度出发，共有两种构建因子模拟组合（Factor MimickingPortfolio,FMP）的逻辑思路，最小化错误定价组合和最大化相关性组合。本文详细的介绍了两种因子模拟组合构建方法的底层逻辑，以及相应的公式推导，并列出了在构建因子模拟组合中可能遇到的问题以及解决方法，最终给出了构建因子投资组合的具体流程与步骤。

## 宏观因子的因子模拟组合构建过程

本文使用的宏观因子包括经济增长、通胀、利率、信用利差、期限利差、汇率以及流动性等七个因子，在构建模拟组合的时候先使用 Lasso 筛选出与目标因子相关的特征，再使用 PCA（Principal Components Analysis）提取这些特征的主成分，最后使用这些主成分来拟合原始因子，并在拟合的过程中通过使用自定义参数 K 来控制拟合效果，最终将得到的拟合出来的因子值作为原始因子值的工具变量，从而计算出每个因子模拟组合。这样操作的目的是为了解决参数估计中的 EIV（Errors in Variables）问题，并且在这种方法下得到的因子模拟组合的暴露更加统一，即在目标因子上的暴露为 1，其余因子暴露皆为 0。

## 宏观因子模拟组合对资产的解释度

我们将得到的宏观因子与大类资产和行业指数收益率做回归，得到了资产在各个宏观因子上的暴露情况。综合来看所计算的宏观因子组合对于大部分大类资产以及行业指数的解释度较高，且暴露情况符合经济逻辑，由此可以将其用于资产组合的风险归因以及资产配置。

## 一、研究背景

资产配置是投资组合管理中的关键策略之一，通过在不同资产类别之间分散投资，以平衡风险与收益。在现代投资理论中，控制风险暴露是资产配置的核心要素之一。传统的资产配置方法主要基于各类资产本身的特性，通常通过在股票、债券、现金及其他资产之间进行分配来分散风险。这一策略涉及对投资资金进行精细分配，涵盖股票、固定收益证券、现金等价物、房地产和大宗商品等多种资产类别。每种资产类别都有其独特的风险和收益特征，并在不同的经济周期中表现出不同的市场相关性。

通过精心设计的资产配置方案，投资者能够在风险承受能力与预期收益之间实现精准平衡，从而达成投资目标。要实现这一目标，不仅需要对各类资产的风险收益特性有深刻理解，还需具备对市场条件、经济周期及资产间相互作用的敏锐洞察。专业的资产配置策略为投资者提供了一个结构化的框架，在追求长期资本增值的同时，维持投资组合的稳定性。

随着市场环境的日益复杂和投资工具的多样化，单纯依赖资产种类或风险特征的传统配置方法已难以全面有效地控制风险暴露。近年来，因子投资逐渐受到广泛关注和应用。因子投资通过识别驱动资产收益的共同因子，从更深层次理解和控制风险暴露。以因子为核心的风险管理方法能够更精确地揭示并调整投资组合中的潜在风险来源，提供更有效的风险控制手段。在这种背景下，投资者不再仅仅关注具体的资产，而是更注重这些资产背后的风险因子，从而实现更科学和高效的风险管理。这种转变反映了大类资产配置方法的进化，是应对复杂市场环境和提升投资绩效的重要途径。

## （一）以资产种类为核心

资产配置的早期形式可以追溯到 20 世纪初期，当时的投资者通过简单的资产分散化策略，如将资金按照一定比例分配到股票和债券上，来降低单一资产类别的风险。这种分散化策略虽然缺乏系统的理论和量化分析，但已经体现了风险管理的基本思想。

1952年，Harry Markowitz提出了均值-方差模型（MVO），这一模型通过数学方法量化了资产的风险和收益，为资产配置提供了一个系统化和量化的框架。MVO 模型的核心在于通过优化组合的风险和收益，寻找到在给定风险水平下预期收益最大化的投资组合。

## （二）以风险为核心

在以资产分类为核心的传统资产配置策略中，MVO方法占据了重要地位，通过优化资产类别之间的权重，实现预期回报与风险的最佳平衡。然而，随着金融市场的日益复杂和波动加剧，仅仅依靠资产类别的多样化不足以应对系统性风险和极端市场环境，这促使投资者开始探索以风险为核心的新型资产配置策略，更好地实现资产风险的分散化与风险暴露的控制。

桥水基金（Bridgewater Associates）提出的全天候策略（All Weather Strategy）便是这种方法的典型代表。该策略的核心理念是通过风险配置而非资产种类配置来实现投资组合的稳定性和持续回报，通过识别并管理不同经济环境和市场条件下的优势大类资产来实现风险的分散化。该策略认为，市场的表现受到四大主要经济环境（增长、通胀、衰退和通缩）的影响。通过对这四种经济环境的深入分析，全天候策略将投资组合的风险暴露进行动态调整，以确保在每一种经济环境下都能有效分散和控制风险。这种以风险为核心的方法，使得全天候策略能够在各种市场情景中实现稳定和持续的投资回报。具体来说，全天候策略会根据不同经济环境下的风险特征，动态调整各类资产（如股票、债券、大宗商品和现金）的配置比例，从而在不同的市场周期中实现最佳的风险收益平衡。

全天候策略以其独特的风险配置理念和动态调整机制，为投资者提供了一种在复杂多变的市场环境中实现稳健投资的有效途径。这一策略的成功应用，也为风险平价（Risk Parity）等现代投资理论的发展奠定了重要基础。

## （三）以因子为核心

以资产或者以风险为核心的资产配置方法的主要优点在于其简便性和直接性，投资者可以通过分散投资于不同资产类别来降低风险。然而，这种方法也存在一些局限性，特别是在市场出现系统性风险时，各资产类别之间的相关性可能会显著增加，导致分散投资的效果减弱，引用 Sébastien Page 在《When Diversification Fails》文中的描述“diversificationseems to disappear when investors need it the most”，换句话说在市场下行甚至是金融危机的时候，不同资产间的相关性会显著提高，从而导致组合的风险分散能力降低。

鉴于此，投资者和资产管理者开始探索新的策略，以期在多变的市场环境中实现更为有效的风险管理和收益最大化。这种探索引导我们走向了以因子为核心的资产配置策略，该策略通过识别和利用驱动资产收益的关键经济和市场因子，提供了一种更为深入和系统化的投资方法。这种方法不仅考虑了资产的个体特性，还考虑了它们在更广泛经济环境中的作用和表现。

一般来说，在因子投资的框架下，资产的收益率存在表达式：

$$
R _ { t } = \alpha _ { t } + \beta _ { t } X _ { t } + \varepsilon _ { t }
$$

其中 $R _ { t }$ 为资 $\dot { \mathcal { P } }$ 超额收益率向量， $\alpha _ { t }$ 为不能被因子解释的alpha 收益率， $\beta _ { t } \mathfrak { F } ^ { \sharp } X _ { t }$ 分别为因子的暴露矩阵和因子收益率向量， $\varepsilon _ { t }$ 为资 $\cdot \dot { \vec { j ^ { z } } }$ 的特质收益率向量。

基于因子的资产配置策略首先需要确定影响资产回报的主要因子，这些因子可以通过历史数据分析、经验总结和其他统计方法来识别。接着，利用这些因子构建资产的风险和回报模型，量化每种资产对不同因子的暴露程度。在得到每种资产在不同因子上的暴露之后，计算得到组合在不同因子上的暴露，最后结合市场预期和经济环境，动态调整资产的配置比例以匹配投资者对于不同因子的目标暴露需求。

由此可见对于以因子为核心的资产配置模型而言，因子的选择往往是至关重要的一环，那么宏观因子是否对于大类资产配置有着指导意义呢？其实许多我们熟知的策略比如著名的美林时钟和上文提到的全天候策略即使没有对宏观因子做出定量分析，都在他们的配置框架中引入了宏观因子的思想。

美林时钟通过分析经济周期的四个阶段（复苏、过热、衰退和萧条），为投资者提供在不同经济环境下的投资指南，帮助他们在每个经济阶段选择最优的资产类别。这一框架利用了经济增长和通胀等宏观因子，对市场变化做出了预测和应对，为投资者提供了指导性意见。

美林时钟和全天候策略的成功侧面验证了宏观因子在大类资产配置方面的有效性，也为投资者提供了强有力的工具，使他们能够做出更为科学和理性的投资决策。然而，这两种方法对于宏观因子的运用主要停留在定性研究阶段，这在应对复杂多变的市场环境时存在一定的局限性和不确定性。在这种背景下，宏观因子量化研究方法逐渐受到关注和重视。

对宏观因子进行定量研究的必要性在于，了解大类资产在宏观因子上的具体暴露，可以显著提升资产配置策略的系统性，让我们能够测量和分析不同资产类别对关键宏观因子的敏感性，包括经济增长、通货膨胀、利率变化等，以动态地调整投资组合以响应实时的经济数据和市场变化。但宏观指标普遍存在频率低，不可交易等特点，所以为了对宏观因子进行定量研究，我们需要对宏观因子构建模拟组合。

## 二、宏观因子的因子模拟组合构建方法

从不同的逻辑角度出发，共有两种构建因子模拟组合（Factor Mimicking Portfolio,FMP）的逻辑思路，最小化错误定价组合（Pukthuanthong2022）和最大化相关性组合（Jurczenko2022）。

## （一）最小化错误定价组合

回顾上文提到的因子模型：

$$
R _ { t } = \alpha _ { t } + \beta _ { t } X _ { t } + \varepsilon _ { t }
$$

在因子模型中 $\alpha _ { t }$ 定义为所选因子无法解释的部分，即模型的错误定价部分， $\mathcal { \bar { \kappa } }$ 最小化错误定价组合顾名思义就是构建一个因子模拟组合让最终拟合出来的 $\alpha _ { t } .$ 尽可能小，则有：

$$
\begin{array} { c } { { \underset { w } { \mathrm { m i n } } \alpha ^ { \prime } \Sigma \alpha } } \\ { { { } } } \\ { { s . t . \ c o v ( w ^ { \prime } R , R ) = c o v ( \tilde { X } , R ) } } \end{array}
$$

其中w为 FMP 中各资产的权重，Σ为用于控制不同资产间的错误定价部分的权重矩阵由使用者定义，X̃为我们不可交易的因子 $\boldsymbol { \breve { \mathrm { X } } } = \mathrm { X } + \mathrm { \Sigma } \varepsilon _ { \mathrm { X } }$ ，X 为因子在超额收益空间的投影，即X 为超额收益的线性组合， $\varepsilon _ { \mathrm { X } }$ 为均值为 0 统计误差且 $. \mathrm { c o v } ( \varepsilon _ { \mathrm { X } } , \mathrm { R } ) = 0$ 。在以上最小化问题中，限制条件为模拟组合与任意资产收益率的协方差与因子与该资产收益率的协方差相当，即最终模拟组合的波动率等于原始因子的波动率，由此可推导出因子模拟组合的收益率等于不可交易因子X<sup>̃</sup>的投影 X（Pukthuanthong 2022）:

$$
w ^ { \prime } R = X
$$

同时已知：

$$
\alpha = E ( R ) - \beta E ( X ) = E ( R ) - \beta E ( w ^ { \prime } R )
$$

我们可以将目标函数改写为：

$$
\begin{array} { c } { { \displaystyle \operatorname* { m i n } _ { w } \alpha ^ { \prime } \varSigma \alpha = \left( E ( R ) - \beta E ( w ^ { \prime } R ) \right) ^ { \prime } \varSigma \left( E ( R ) - \beta E ( w ^ { \prime } R ) \right) } } \\ { { \ } } \\ { { = \left( E ( R ) - \displaystyle \frac { c o v ( X , R ) } { v a r ( w ^ { \prime } R ) } E ( w ^ { \prime } R ) \right) ^ { \prime } \varSigma \left( E ( R ) - \displaystyle \frac { c o v ( X , R ) } { v a r ( w ^ { \prime } R ) } E ( w ^ { \prime } R ) \right) } } \end{array}
$$

令 $\begin{array} { r } { { \bf \nabla } \cdot { \bf w } _ { s } = \frac { w } { v a r ( w ^ { \prime } R ) } , } \end{array}$ ，代入上式并展开可得：

$$
\begin{array} { c } { { \left( E ( R ) - \displaystyle \frac { c o v ( X , R ) } { v a r ( w ^ { \prime } R ) } E ( w ^ { \prime } R ) \right) ^ { \prime } \Sigma \left( E ( R ) - \displaystyle \frac { c o v ( X , R ) } { v a r ( w ^ { \prime } R ) } E ( w ^ { \prime } R ) \right) } } \\ { { { } } } \\ { { { } ~ = E ( R ) ^ { \prime } \Sigma E ( R ) - 2 \big ( c o v ( X , R ) E ( w _ { s } ^ { \prime } R ) \big ) ^ { \prime } \Sigma E ( R ) + } } \\ { { { } ~ } } \\ { { { } ~ \left( c o v ( X , R ) E ( w _ { s } ^ { \prime } R ) \right) ^ { \prime } \Sigma \left( c o v ( X , R ) E ( w _ { s } ^ { \prime } R ) \right) } } \end{array}
$$

对上式求关于 $w _ { s }$ 的一阶偏导可得：

$$
0 = \ - 2 ( c o v ( X , R ) ) ^ { \prime } \Sigma E ( R ) E ( R ) + 2 \big ( c o v ( X , R ) \big ) ^ { \prime } \Sigma ( c o v ( X , R ) ) E ( R ) E ( R ) ^ { \prime } w _ { s }
$$

再通过整理可得：

$$
\begin{array} { c } { { w _ { s } ^ { \ast } = { \displaystyle \frac { ( c o v ( X , R ) ) ^ { \prime } \Sigma E ( R ) } { \bigl ( c o v ( X , R ) \bigr ) ^ { \prime } \Sigma \bigl ( c o v ( X , R ) \bigr ) } E ( R ) ( E ( R ) ^ { \prime } E ( R ) ) ^ { - 1 } } } } \\ { { { } } } \\ { { E ( R ) ^ { \prime } w _ { s } ^ { \ast } = { \displaystyle \frac { ( c o v ( X , R ) ) ^ { \prime } \Sigma E ( R ) } { \bigl ( c o v ( X , R ) \bigr ) ^ { \prime } \Sigma \bigl ( c o v ( X , R ) \bigr ) } } } } \end{array}
$$

已知 $\begin{array} { r } { \tau \beta = \frac { c o v ( X , R ) } { v a r ( X ) } } \end{array}$ ，可得最小化错误定价组合收益率的表达式为：

$$
E ( R ) ^ { \prime } w _ { s } { } ^ { * } = \frac { 1 } { v a r ( X ) } \frac { \beta ^ { \prime } { \Sigma } E ( R ) } { \beta ^ { \prime } { \Sigma } \beta }
$$

此时根据不同的Σ的选择，有三种方法来构建因子的FMP。

## 1、时间序列方法

对最小化错误定价组合收益率表达式进行重组可得:

$$
\begin{array} { c } { { E ( R ) ^ { \prime } { w _ { s } } ^ { \mathrm { * } } = \displaystyle \frac { 1 } { v a r ( X ) } \displaystyle \frac { \beta ^ { \prime } \Sigma E ( R ) } { \beta ^ { \prime } \Sigma \beta } } } \\ { { { } } } \\ { { ( v a r ( X ) ) ^ { 2 } \displaystyle \beta ^ { \prime } \Sigma \beta E ( R ) ^ { \prime } { w _ { s } } ^ { \mathrm { * } } = v a r ( X ) \displaystyle \beta ^ { \prime } \Sigma E ( R ) = c o v ( X , R ) ^ { \prime } \Sigma E ( R ) } } \end{array}
$$

使用资产收益率 R对不可交易的因子X 构建时序回归:

$$
X = \alpha + b R + \varepsilon _ { t }
$$

得到b̂的估计量:

$$
\widehat { b } = ( R ^ { \prime } R ) ^ { - 1 } R ^ { \prime } X
$$

在大样本下 $\widehat { \mathrm { b } }$ 可以近似为:

$$
\hat { b } = v a r ( R ) ^ { - 1 } c o v ( X , R ) = c o v ( X , R ) ^ { \prime } ( v a r ( R ) ^ { - 1 } ) ^ { \prime } = c o v ( X , R ) ^ { \prime } v a r ( R ) ^ { - 1 }
$$

则最终时序模型的拟合值X̂为 $ { \hat { b } }  { \mathrm { R } } =  { \mathrm { c o v } } (  { \mathrm { X } } ,  { \mathrm { R } } ) ^ { \prime }  { \mathrm { v a r } } (  { \mathrm { R } } ) ^ { - 1 }  { \mathrm { R } }$ ，不难看出时间序列模型最终的拟合值实际上就是缩放后的 FMP 的收益率 $( \ ( v a r ( X ) ) ^ { 2 } \beta ^ { \prime } \varSigma \beta E ( R ) ^ { \prime } { w _ { s } } ^ { \ast } \ )$ ,而此时 $\Sigma =$ $\mathrm { v a r } ( \mathrm { R } ) ^ { - 1 }$

## 2、截面回归方法

将 $\Sigma = ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } ) \Omega ^ { - 1 } ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } )$ 带入表达式重组，其中Ω为资产收益率的协方差矩阵：

$$
\begin{array} { c } { { v a r ( X ) E ( R ) ^ { \prime } w _ { s } ^ { \ast } = { \displaystyle \frac { \beta ^ { \prime } ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } ) \Omega ^ { - 1 } ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } ) E ( R ) } { \beta ^ { \prime } ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } ) \Omega ^ { - 1 } ( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } ) \beta } } } } \\ { { { } } } \\ { { = { \displaystyle \frac { \bar { \beta } ^ { \prime } \Omega ^ { - 1 } \bar { E } ( R ) } { \bar { \beta } ^ { \prime } \Omega ^ { - 1 } \bar { \beta } } } } } \end{array}
$$

其中 $( I - 1 ( 1 ^ { \prime } 1 ) ^ { - 1 } 1 ^ { \prime } )$ 其实就是一个对角线元素为 $\textstyle 1 - { \frac { 1 } { n } } ,$ 其他位置为 $- { \frac { 1 } { n } } |$ 的矩阵，β̅表示中心化后的 $\beta$ 。可以看出等号右边即为GLS 下使用Ω作为权重矩阵对于系数的估计值。

所以对于截面回归而言，最普遍的做法是使用 FamaMacbeth回归的思路，先构建一个时序模型来估计每个资 $\cdot \dot { \vec { j ^ { z } } }$ 收益率在因子上的暴露 $\boldsymbol { \cdot } \beta _ { i , t }$

$$
R _ { i , t } = a _ { i , t } + \beta _ { i , t } X _ { t } + \varepsilon _ { t }
$$

然后在每个时间截面上使用 $\mathrm { v a r } ( \mathrm { R } ) ^ { - 1 }$ 作为权重矩阵做GLS：

$$
R _ { i , t } = \alpha _ { i , t } + \widehat { \beta _ { \iota , t } } \lambda _ { t } + \varepsilon _ { t }
$$

最后使用 $\widehat { \lambda } _ { t }$ 作为FMP的收益率，此时得到的也是缩放后的 FMP收益率。

研究表明采用截面回归的方式能够有效的控制不可交易因子中的测量误差（Pukthuanthong 2022，Balduzzi & Robotti 2008）。但是因为截面回归采用的是两次回归的方式，并且第一次回归的β，会被作为自变量传入第二次回归当中，所以这就导致截面回归中的 Error-in-Variable 的问题，简单来说就是我们在第一步回归中对于β的拟合误差会被传递到我们第二步回归当中，从而影响最终的结果。为了解决 EIV 问题，普遍的操作方法为在回归中引入一个工具变量 Instrument Variable，下文会详细介绍 IV 的具体操作流程。

## 3、排序分组方法

排序分组的方法在实际操作上是最简单的，在经典的 Fama-French 三因子模型中就使用了排序分组的思想来构建因子组合（HML，SMB），简单来说就是在每个截面上把所有资产按照因子暴露的大小（仍需要对因子暴露进行估计）从大到小排列，并使用最大组减去最小组的平均收益率作为缩放后的因子 FMP 的收益率。这种方法虽然操作简单但是使用的相对较少，对应的Σ也较为复杂，并且这种方法因为也是依靠拟合出来的β进行分组，所以同样面临着 EIV 问题，感兴趣的读者可以自行查阅具体文献。

## 4、总结

通过上文的介绍，我们可以看出以上三种方法最终得到的都是缩放后的因子收益率，并且不同的方法下的缩放因子不同，其中截面回归方法是业界最常用的方法。但以上三种方法在构建因子模拟组合的时候，均没有考虑最终因子模拟组合是否为纯因子组合，即在目标因子上的暴露为 1，其余因子上的暴露为 0。所以本文将采取下文介绍的最大化相关性组合来构建因子模拟组合。

## （二）最大化相关性组合

Breeden, Gibbons, Litzenberger (1989)和 Roll & Srivastava (2018)提供了研究最大化相关性组合的理论。给定因子模拟组合在目标因子上的暴露 $\beta _ { f m p }$ （一般设为 1），可知因子模拟组合的方差与因子模拟组合与因子之间的相关性呈反比：

$$
\beta _ { f m p } = c o r r ( \tilde { X } , w ^ { \prime } R ) \frac { \sqrt { v a r ( w ^ { \prime } R ) } } { \sqrt { v a r ( \tilde { X } ) } }
$$

其中 $\sqrt { v a r ( \tilde { X } ) }$ 为常数，所以最大化FMP与目标因子的相关性等同于最小化FMP的方差。得到组合最小化方差优化目标，其中Ω为资 $\cdot \dot { \vec { r } }$ 收益率的协方差矩阵：

$$
\operatorname* { m i n } _ { w } \frac { 1 } { 2 } w ^ { \prime } \varOmega w
$$

$$
S . ~ t . ~ \beta ^ { \prime } w = \beta _ { f m p }
$$

对优化目标构建拉格朗日函数：

$$
L ( w ; \lambda ) = { \frac { 1 } { 2 } } w ^ { \prime } \varOmega w - \lambda ( \beta ^ { \prime } w - \beta _ { f m p } )
$$

对拉格朗日函数求w 的一阶偏导：

$$
\frac { \partial ( L ( w ; \lambda ) ) } { \partial w } = \varOmega w - \beta \lambda = 0
$$

左右两边同乘 $\therefore \Omega ^ { - 1 }$ 得到：

$$
w = \varOmega ^ { - 1 } \beta \lambda
$$

$$
\beta ^ { \prime } w = \beta ^ { \prime } \varOmega ^ { - 1 } \beta \lambda = \beta _ { f m p }
$$

整理求解λ:

$$
\lambda = ( \beta ^ { \prime } \varOmega ^ { - 1 } \beta ) ^ { - 1 } \beta _ { f m p }
$$

得到 $\mathbf { w } ^ { * } ;$

$$
\boldsymbol { w } ^ { * } = \Omega ^ { - 1 } \beta ( \beta ^ { \prime } \Omega ^ { - 1 } \beta ) ^ { - 1 } \beta _ { f m p }
$$

设 ${ \beta _ { \mathrm { f m p } } } = 1$ ，即因子组合在目标因子上的暴露为1，最终可得因子模拟组合的权重以及收益率为：

$$
\begin{array} { c } { { w ^ { * } = \varOmega ^ { - 1 } \beta ( \beta ^ { \prime } \varOmega ^ { - 1 } \beta ) ^ { - 1 } } } \\ { { } } \\ { { E ( R ) ^ { \prime } w ^ { * } = E ( R ) ^ { \prime } \varOmega ^ { - 1 } \beta ( \beta ^ { \prime } \varOmega ^ { - 1 } \beta ) ^ { - 1 } } } \end{array}
$$

由于资产收益率的协方差矩阵Ω已知，所以普遍采用截面回归对β进行估计。对β进行拟合就必然会遇到EIV问题，常见的解决方法为上文提到的IV：

## 1、工具变量回归 IV regression

工具变量回归是一种统计技术，用于解决内生性问题，即当回归模型中的自变量与误差项相关时，传统的最小二乘法（OLS）估计结果可能会有偏误或不一致。为了解决问题，我们可以引入一个工具变量，此变量应该与模型的误差项不相关，但与自变量相关。这样，工具变量可以用来估计自变量对因变量的因果效应。

即对于一个简单的线性回归模型：

$$
y = \beta _ { 0 } + \beta _ { 1 } x + u
$$

假如我们对自变量 x的测量存在误差 $\epsilon _ { x }$ ，E $[ \epsilon _ { x } ] = 0$ 且与 $\mathbf { X }$ 和u都不相关：

$$
x _ { o b s } = x + \epsilon _ { x }
$$

此时回归方程为：

$$
y = \beta _ { 0 } + \beta _ { 1 } x _ { o b s } + ( u - \beta _ { 1 } \epsilon _ { x } )
$$

此时 $\mathrm { u } - \beta _ { 1 } \epsilon _ { \mathrm { x } }$ 为新的误差项，且与 $\mathbf { X _ { 0 b s } }$ 相关。为此需要引入工具变量 z，满足

1. z 与 x 高度相关

## 2. z 与 $\mathsf { u } - \beta _ { 1 } \epsilon _ { \mathrm { x } }$ 不相关

然后使用工具变量 z做两阶段最小二乘法估计 $\beta _ { 1 }$ ：

首先使用 z来估计x的预测值x̂:

$$
x _ { o b s } = \pi _ { 0 } + \pi _ { 1 } z + v
$$

$$
\widehat { x } = \widehat { \pi } _ { 0 } + \widehat { \pi } _ { 1 } z
$$

然后使用x̂代替 x在原模型中进行回归：

$$
y = { \beta _ { 0 } } ^ { \prime } + { \beta _ { 1 } } ^ { \prime } \hat { x } + \varepsilon
$$

由于 z与 $\mathsf { u } - \beta _ { 1 } \epsilon _ { \mathrm { x } }$ 不相关，所以此时我们可以得到不偏的一致估计 ${ \bf \widehat { \beta } } _ { 1 } ^ { \prime }$

## 2、工具变量的选择

只要能满足工具变量的标准，选择工具变量的方法有很多：

1. Pukthuanthong提出可以将回归区间内的奇数月份和偶数月份的样本分开进行回归，在偶数月份使用奇数月的β作为工具变量，在奇数月份使用偶数月份的β作为工具变量。

2. Giglio and Xiu 提出可以对资产收益率做 PCA 提取主成分，然后使用主成分作为因子的工具变量，Jurczenko 在这个基础上做出修正，使用 Lasso 来对所有资产做一步预筛选，然后再做 PCA。本文最终选择采取这种方法来对β进行估计。

## 三、宏观因子的因子模拟组合构建

## （一）选取合适的宏观因子

目前普遍选取合适的宏观因子方法主要分为两种方法：

1. 第一种是使用主成分分析(PCA)，对若干大类资产的收益率进行降维，并对其中每一个主成分进行主观解读，根据其对于不同大类资 $- \frac { \triangledown \cdot \triangledown } { \triangledown ^ { \prime } }$ 的影响，将其定义成不同的宏观因子。

2. 第二种是根据经验以及基于经济逻辑进行主观判断。

对于第一种方法而言，主成分分析中输入的资产、窗口长度以及主成分个数并没有严格统一的标准但却会对结果造成很大的影响，即选择不同的资产或者不同的时间区间都会导致最终输出的主成分不同，但是不同的参数之间并没有办法进行比较哪种参数更加合理。除此之外在得到最终主成分之后依然要对主成分进行主观解读。所以我们选择直接采用第二种方法，最终结合国内外文献选取了经济增长、通胀、利率、信用利差、期限利差、汇率、流动性等 7 个因子来构成宏观因子的研究框架。

## （二）构建宏观因子

由于宏观数据而言普遍存在数据频率低、滞后性强、且不可直接交易等特点，如果直接使用类似于 GDP 等指标作为宏观因子，会因为数据量过少且时效性等问题，导致模型难以训练，所以业界普遍的做法是选择具有经济意义且与目标因子关联性强的宏观指标来构建高频化的宏观因子，我们沿用这种思路对 7 个目标宏观因子进行指标筛选最终选取了以下指标：

1. 经济增长：中国:制造业 PMI（M0017126），中国:社会消费品零售总额:当月同比（M0001428），中国:规模以上工业增加值:当月同比（M0000545）

2. 通胀：中国:CPI:当月同比（M0000612），中国:PPI:全部工业品:当月同比（M0001227）

3. 利率：国债到期收益率(1Y)（S0059744）

4. 信用利差：中国:中债国债到期收益率:1年（S0059744），中债企业债到期收益率(AA):1年（S0059761）

5. 期限利差：国债到期收益率(1Y)（S0059744），国债到期收益率(10Y)（S0059749）

6. 汇率：美元兑人民币中间价（M0000185）

7. 流动性：中国:M2:同比（M0001385）

对于指标中的缺失值，采用前值加上过去 12个月的一阶差分中位数的方法进行填充，具体的构建方式如下：

1. 对于经济增长因子与通胀因子等存在多个相关指标的因子，采取波动率倒数加权的方法将以上指标合称为最终的因子，其中因为PMI本身为经过季节调整后的环比指标，所以对其进行同比差分处理，将最后结果作为因子值。

2. 利率因子直接采用一年期国债到期收益率同比差分作为因子值。

3. 信用利差因子使用 1 年期中债企业债到期收益率减去 1 年期中债国债到期收益率的同比差分作为因子值。

4. 期限利差因子使用 10 年期国债到期收益率减去 1 年期中债国债到期收益率的同比差分作为因子值。

5. 汇率因子使用美元兑人民币中间价的同比差分作为因子值。

6. 流动性因子使用 M2同比作为因子值。

7. 此外因为数据本身的问题，将经济增长、通胀、流动性等数据发布存在滞后性的指标进行滞后一期处理，并且为了增加数据量，对月频的经济增长、通胀、流动性因子采用线性插补的方法进行增频调整为周频，因为原始数据都经过了滞后一期处理，所以这样操作并不会造成使用未来数据的问题，而其他指标本身存在周频数据所以不需要增频操作，具体的因子构建方法如下：

## （四）构建因子模拟组合

本文沿用了最大化相关性组合构建因子模拟组合的方法，并使用了 PCA 来解决 EIV 问题，具体步骤如下：

1. 在周末时间点 T，取前 6 年共 312（6\*52）周的因子数据与基础资产月度收益率数据，对因子做标准化，对基础资产收益率做去均值化。

2. 对于每一个宏观因子生成其对应的工具变量：

a) 生成不同滞后期（1周至6周）的因子以及基础资产同比收益率序列，将其拼接在原始基础资产同比收益率上，作为解释变量，原始因子作为因变量，做Lasso回归来进行特征筛选。

b) 获取到选择的解释变量后，对被选择的变量进行主成分分析并提取主成分。

c) 使用提取出来的主成分作为解释变量，原始宏观因子 raw factor作为因变量做回归，得到拟合出来的因子值fittedfactor。因为在有的区间内，回归的拟合效果会比较差，为了保证整体因子序列的稳定性，这里引入了一个参数 k=0.5，将每一期回归的 R-squared 的值与 k 进行比较，最终输出拟合结果 adjusted fitted factor。

$$
\begin{array} { r } { \mathrm { a d j u s t e d \ f i t t e d \ f a c t o r } = \left\{ \begin{array} { l l } { \mathrm { f i t t e d \ f a c t o r } * ( \mathrm { R } ^ { 2 } \times 2 ) + \mathrm { r a w \ f a c t o r } * ( 1 - \mathrm { R } ^ { 2 } \times 2 ) , \quad } & { k \le \mathrm { R } ^ { 2 } } \\ { \qquad \mathrm { f i t t e d \ f a c t o r } , \quad } & { k > \mathrm { R } ^ { 2 } } \end{array} \right. } \end{array}
$$

3. 使用工具变量作为解释变量，对基础资产收益率做回归，得到每个资产在因子上的暴露 $\cdot \beta ^ { P C I V }$

4. 计算基础资产收益率的协方差矩阵Ω。

5. 带入公式计算因子模拟组合的权重w。

$$
\boldsymbol { w } ^ { * } = \Omega ^ { - 1 } \beta ^ { P C I V } ( \beta ^ { P C I V ^ { \prime } } \Omega ^ { - 1 } \beta ^ { P C I V } ) ^ { - 1 } \boldsymbol { \beta } _ { f m p }
$$

其中 $\beta _ { \mathrm { f m p } }$ 为主对角线为 1，其余位置为 0 的 7 × 7 的矩阵，表示构建出来的因子组合在目标因子上的暴露为 <sub>1</sub>，其余因子的暴露为 <sub>0</sub>：

$$
\beta _ { f m p } = \left[ { \begin{array} { c c c } { 1 } & { \cdots } & { 0 } \\ { \vdots } & { \ddots } & { \vdots } \\ { 0 } & { \cdots } & { 1 } \end{array} } \right]
$$

6. 将得到的 $w ^ { * }$ 乘以基础资产日度收益率，得到因子模拟组合的日度收益率。

可以看出不同的大类资产对宏观因子的暴露程度存在明显的差异，例如：

1. 股票权益类资产普遍在通胀因子、汇率因子上呈现负向暴露，在利率因子上普遍呈现正向暴露，这表明通胀上升、人民币贬值可能对股票市场产生不利影响，同时尽管利率上升增加了企业的融资成本，但在经济增长强势或者上调利率以控制通胀时，如果市场认为这种政策能够有效稳定物价，抑制过度的通胀预期，那么市场可能会对未来的经济环境感到更有信心。这种信心可以转化为对股票市场的乐观情绪，促使股市上涨。对于经济增长因子与流动性因子而言，我们看到只有沪深 300 在经济增长因子上呈现明显的正向暴露，同时沪深 300 与恒生指数在流动性因子上呈现了负向暴露，这说明大盘指数在经济增长的时候表现更好，而中盘小盘指数则是在流动性更好的时候更占优。

2. 对于债券类资产，我们可以看到利率因子和信用利差因子是主要的影响因子，且国债、企业债、信用债在利率因子上的暴露皆为负，而信用利差因子在国债上的暴露为正，企业债与信用债的暴露为负，这符合基本的经济逻辑。

3. 对于大宗商品类资产而言，可以看到大宗商品指数普遍都在经济增长、与通胀因子上呈现正向暴露，这意味着这些大宗商品对经济周期的敏感性更强，在经济上行扩张期的时候，且通胀上行的时候，商品的需求旺盛价格上行，同时又具有一定的抗通胀能力，这与我们在介绍美林时钟中的结论一致。同时我们也发现农产品与工业品在利率因子与流动性因子上呈现差异，其中工业品指数在利率因子上呈现正暴露，而农产品指数正好相反，这种差异可能是因为工业品和农产品在经济中的角色和需求特性有所不同。工业品通常与经济周期密切相关，当利率上升时，通常反映经济前景改善，需求增加，因此工业品价格可能上涨，另一方面，农产品的需求通常较为刚性，不容易受到利率变动的影响。这种不同的暴露模式反映了工业品和农产品在面对宏观经济条件变化时所表现出的不同市场动态和需求弹性。

4. 对于黄金而言，主要的影响因子包括呈现正暴露的通胀因子以及负暴露的利率因子，这说明黄金价格往往受益于通胀上升的环境，因为通胀上升通常会导致货币购买力下降，而黄金作为一种保值资产，其吸引力在通胀时期往往增强，因此价格会上涨。同时，黄金对利率因子呈现负暴露，意味着当利率预期上升时，黄金价格往往下跌。这可能是因为利率上升提高了持有无息资产（如黄金）的机会成本，促使投资者转向收益更高的固定收益资产，如债券，从而导致黄金需求下降，价格走低。

2. 房地产指数在经济增长因子上的暴露最高，这是因为经济增长通常伴随着居民收入水平的提高、就业率的上升以及整体经济活力的增强，这些因素都会直接推动房地产需求的增加。当经济处于扩张期时，购房需求上升，房地产市场通常会表现出较强的增长势头，推动房价和地产类资产价格上涨。因此，房地产指数对经济增长因子的高暴露表明，在经济扩张阶段，房地产市场往往会迎来更好的表现。

3. 所有行业指数在通胀因子、汇率因子上呈现负暴露，在利率因子上呈现正暴露，这说明普遍而言通胀、汇率以及利率对股市的影响是全面的，这与上文对于权益型资产暴露分析中结论一致。

4. 银行指数在流动性因子上呈现最高的负向暴露，这可能是因为银行指数成分偏大盘，而按照上文的分析，在流动性宽松的时候，中盘股与小盘股相对占优，与前文的结论一致。

5. 通过以上分析可以看出，在获得宏观因子的模拟组合后，我们可以将其与不同资产的收益率进行回归分析，从而确定各类资产对目标因子的暴露。这让我们能够把宏观因子纳入组合风险控制体系中，并且能够帮助我们深入理解组合在宏观因子上的具体暴露情况，以及对关键宏观因子的敏感性。

## 五、总结

进行宏观因子的定量研究的必要性在于，明确大类资产对宏观因子的具体暴露情况，这能够显著提高资产配置策略的系统性，使我们能够测量和分析不同资产类别对关键宏观因子（如经济增长、通货膨胀、利率变化等）的敏感性，从而能够根据实时的经济数据和市场变化，动态调整投资组合。

本文详细的介绍了两种因子模拟组合构建方法的底层逻辑，以及相应的公式推导，并列出了在构建因子模拟组合中可能遇到的问题以及解决方法，最终给出了构建因子投资组合的具体流程与步骤。本文使用的宏观因子包括经济增长、通胀、利率、信用利差、期限利差、汇率以及流动性等七个因子，在构建模拟组合的时候先使用 Lasso 筛选出与目标因子相关的特征，再使用 PCA 提取这些特征的主成分，最后使用这些主成分来拟合原始因子，并在拟合的过程中通过使用自定义参数K来控制拟合效果，最终将得到的拟合出来的因子值作为原始因子值的工具变量，从而计算出每个因子模拟组合。这样操作的目的是为了解决参数估计中的 EIV 问题，并且在这种方法下得到的因子模拟组合的暴露更加统一，即在目标因子上的暴露为 1，其余因子暴露皆为0。

最终，我们将所得的宏观因子与大类资产和行业指数的收益率进行回归分析，得出了各资产在不同宏观因子上的暴露情况。整体来看，所构建的宏观因子组合对大多数大类资产和行业指数的解释度较高，且暴露情况符合经济逻辑，因此可以将这些因子组合用于资产组合的风险归因和资产配置策略的优化。
