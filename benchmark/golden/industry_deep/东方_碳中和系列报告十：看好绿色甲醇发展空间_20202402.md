# 碳中和系列报告十：看好绿色甲醇发展空间

## 核心观点

欧盟对绿色甲醇的标准较高。根据欧盟最新版本的可再生能源指令，满足欧盟标准的绿色甲醇可以分为生物燃料、非生物来源的可再生燃料、再循环碳燃料三类。想要生产符合欧盟标准的绿色甲醇并不容易，尤其是生产非生物来源的可再生燃料和再循环碳燃料类别的甲醇。相较于化石燃料70%的减排量对绿色甲醇生命周期内的碳捕获、甲醇生产和运输过程的可再生能源渗透率提出了很高的要求。采用来自工业废气的碳源则有可能面临2035或2040年以后不能继续满足欧盟标准的风险。

欧洲或出于产业先发优势选择绿色甲醇。从生产工艺来看，绿氨的生产工艺比绿色甲醇的生产工艺更加成熟；从燃烧特性来看，绿色甲醇则比绿氨更加优秀；从配套设施来看，绿色甲醇各方面条件已具备；从安全性来看，绿色甲醇和绿氨均需解决安全性问题。综合来看，绿醇相较于绿氨并没有决定性优势。我们认为绿色甲醇成为航运替代燃料主流主要是由欧洲引导，而欧洲航运巨头选择甲醇内在原因是欧洲在绿色甲醇项目布局上有先发优势，而在绿氨项目上缺乏竞争力。由于绿氨的生产技术比较成熟，绿氨生产的核心竞争力其实是可再生能源的丰富程度。欧洲虽然风力资源丰富，但太阳能资源相较于中东、美国和中国要明显匮乏。因此无论是从成本上还是技术上，欧洲在绿氨领域都不具备竞争力。在绿色甲醇方面，欧盟经过多年布局已经将其定义的绿色甲醇标准推向全世界，现有标准下工业密集型国家相对于欧洲国家并不具有优势。而从绿色甲醇现有产能和生产技术方面来看，欧洲企业则具有先发优势。

绿色甲醇市场空间巨大，降低成本是产业化关键。我们认为绿色甲醇未来有望获得巨大市场空间。我们测算2030、2040年全球航运业绿色甲醇需求量分别约为0.34、1.37亿吨。远期来看，除了可以作为船用燃料外，绿色甲醇还有望应用到车用燃料领域和发电领域。我们测算，到2050年，航运业中绿色甲醇的渗透率每提升1%，则对应的需求量增长0.11亿吨/年；车用燃料方面，绿色甲醇对汽油的替代率每提升1%，对应的需求量增长0.096亿吨/年；发电方面，绿色甲醇发电对天然气发电的替代率每提升1%，对应的绿色甲醇需求量增长0.356亿吨/年。目前绿色甲醇的生产成本较高。按目前内蒙地区的绿氢成本，我们测算使用绿氢和捕集的CO₂生产绿色甲醇的成本为5544元/吨。假设生物天然气价格为5元/m³，我们测算以生物天然气制绿色甲醇的成本为5220元/吨。尽管目前绿色甲醇溢价较高，但我们认为降低生产成本是绿色甲醇产业化和企业长期盈利的关键。

## 投资建议与投资标的

我们看好绿色甲醇未来的发展空间和盈利机会，建议关注吉电股份(000875，未评级)、上海电气(601727，未评级)、中煤能源(601898，买入)等布局生物质绿色甲醇和二氧化碳捕集制绿色甲醇项目的公司，建议关注参与构建绿色甲醇全产业链的中远海能(600026，未评级)。

## 风险提示

●欧盟标准变动；绿色甲醇推广不及预期；绿色甲醇价格大幅降低；绿色甲醇成本居高不下；新项目投产不及预期；假设条件变化影响测算结果。

## 1. 前言

近年来，国内外相继规划了大量绿色甲醇项目。根据吉电股份的预测，绿色甲醇的市场价格目前可达1000美元/吨以上，相较于23年甲醇约2171元/吨的均价高227%。考虑到绿色甲醇正受到越来越多的关注，而资本市场对于绿色甲醇行业还不够熟知，因此我们对绿色甲醇定义、优势、发展空间和生产成本进行了研究。我们认为：

1.愿意为绿色甲醇支付高溢价的主要是欧洲客户，而欧盟对绿色甲醇设定了较高的门槛。

2.绿色甲醇相对于绿氨的优势并不明显，欧洲或出于产业先发优势选择绿色甲醇。

3. 未来绿色甲醇有望渗透多个领域，市场空间巨大。

4. 绿色甲醇目前生产成本较高，降低成本是产业化关键。

综上，我们认为未来绿色甲醇行业有望得到高速发展，提前布局绿色甲醇的企业有望获得高额利润。

## 2. 绿色甲醇的定义

绿色甲醇的定义目前国际上尚无统一标准，但考虑到目前愿意为绿色甲醇支付溢价的主要下游是欧洲客户，那么生产符合欧盟标准的绿色甲醇就成为了现阶段绿色甲醇项目的主要目标。根据欧盟最新版本的可再生能源指令（Renewable Energy Directive），满足欧盟标准的绿色甲醇可以分为生物燃料（Biofuels）、非生物来源的可再生燃料（RenewableFuels of Non-BiologicalOrigin)、再循环碳燃料(Recycled Carbon Fuels)三类。

生物燃料（Biofuels）类甲醇的碳和氢均来自于生物资源。对于这类燃料，欧盟主要提出两方面的要求：其一，对于以粮食和饲料为原料生产的生物质燃料，如果其具有高的间接土地利用变化风险，则限制其使用占比，最晚于2030年底占比降低到0%；其二，生物燃料应满足温室气体减排标准，2021年起运营生产的生物燃料的温室气体排放量相较于可比的化石燃料的排放量（用于运输的参照排放量为 94g CO₂eq/MJ)降低 65%。

非生物来源的可再生燃料(Renewable Fuels of Non-Biological Origin)类甲醇主要使用可再生氢气生产。欧盟对于这类燃料主要提出两点要求：其一，生产过程使用的可再生电力来源需要满足欧盟制定的标准；其二，非生物来源的可再生燃料的温室气体排放量相较于可比的化石燃料排放量 $\left( 9 4 9 \mathsf { C O } _ { 2 } \mathsf { e q } / \mathsf { M J } \right)$ 降低70%。

再循环碳燃料（Recycled Carbon Fuels）类甲醇主要来自不可再生来源的液体或固体废物流，或工业装置运行过程中不可避免或无意生产的不可再生来源的废气和尾气。对于这类燃料，欧盟要求其温室气体排放量相较于可比的化石燃料排放量 $\left( 9 4 9 \mathsf { C O } _ { 2 } \mathsf { e q } / \mathsf { M J } \right)$ 降低70%。根据欧盟可再生能源指令，再循环碳燃料主要用于完成运输部门的减排目标。

市场对于使用 $\mathsf { C O } _ { 2 }$ 生产绿色甲醇的碳源问题比较关心。对于非生物来源的可再生燃料(Renewable Fuels of Non-Biological Origin)和再循环碳燃料(Recycled Carbon Fuels)的原料 $\mathtt { C O } _ { 2 }$ 来源，欧盟划定了可行范围：

(1)从空气捕集的 $\mathtt { C O } _ { 2 }$ o

(2)地质来源的 $\mathsf { C O } _ { 2 }$

(3)由生物燃料、非生物来源的可再生燃料和再循环碳燃料燃烧产生的 $\mathsf { C O } _ { 2 }$

(4）能源行业（火电、炼油、焦炉)、冶金制造业、矿物制品业及造纸业所排放的 $\mathsf { C O } _ { 2 }$ ，其上游已被有效的碳定价系统覆盖，并且这些排放已受到碳定价的约束。此外，火力发电所排放的$\mathtt { C O } _ { 2 }$ 仅可用到2035年，而其他使用非可持续燃料的工业 $\mathtt { C O } _ { 2 }$ 排放也只能用到2040年。

而且在（3）和（4）的情况下，如果下游要通过捕获 $\mathtt { C O } _ { 2 }$ 生产绿色甲醇，那这部分 $\mathtt { C O } _ { 2 }$ 就不能用于置换碳减排信用，即不能同时算在上游的减排量中。

综合来看，想要生产符合欧盟标准的绿色甲醇并不容易，尤其是生产非生物来源的可再生燃料和再循环碳燃料类别的甲醇。一方面，想要达到相较于化石燃料70%的减排量，对绿色甲醇生命周期内的碳捕获、甲醇生产和运输过程的可再生能源渗透率提出了很高的要求。另一方面，若采用来自工业废气的碳源，则绿色甲醇产品将面临在2035或2040年后不能继续满足欧盟标准的风险。

## 3. 绿色甲醇异军突起

## 3.1绿醇项目规划产能大幅增长

随着全球碳中和进程展开，寻找合适的绿电绿氢能源载体成为产业发展的关键环节。而在2023年前，产业届关注最多的还是绿氨。根据TrendBank统计数据，截至2022年底，国内规划的绿氢制合成氨产能远高于绿氢制甲醇，分别为461.7万吨/年和49.76 万吨/年。而2023 年后情况发生反转，国内绿色甲醇规划产能迎来爆发。根据中国产业发展促进会氢能分会数据，2023年1月至11 月，新增绿氢制合成氨项目规划产能约为485万吨/年，而新增绿氢制甲醇项目规划产能则达到约 865万吨/年。

## 3.2 绿醇与绿氨比较

我们从生产工艺、燃烧特性、配套设施和安全性的角度分别比较了绿色甲醇和绿氨之间的优劣势。从生产工艺来看，绿氨的生产工艺比绿色甲醇的生产工艺更加成熟。绿氨与传统合成氨的区别主要是氢气的来源不同，只要用绿氢替代传统煤或天然气制氢，就可以使用现有的空分装置和氨合成塔生产绿氨。而绿色甲醇的潜在生产路线更加多样，技术门槛也更高。如果使用生物质制甲醇，那么化学转化路线就需要根据生物质组成设计不同的气化和裂解方案，生物发酵路线则需要设计不同的发酵方案。如果使用CO₂加氢制甲醇，那么不同来源CO₂的捕获技术以及高效CO₂加氢技术也都是需要考虑和解决的问题。综上，我们认为从工艺技术的成熟度来说，绿氨实际比绿色甲醇更具有优势。

从配套设施来看，绿色甲醇各方面条件已具备，而绿氨则需要更多额外投入。甲醇在常温常压下是液体，其存储运输过程不需额外的加压和冷却过程，现有的燃料油存储和加注设施不需进行太多改造就可用于绿色甲醇的存储和加注。液氨常温常压下为气体，需要加压才能液化，这使得其存储和运输较甲醇更困难。不过绿氨与LPG的沸点接近，而LPG的大规模储运加注等已经非常成熟，相信液氨也并非难事。在应用方面，甲醇发动机较燃油发动机的改造比较小，目前已经投入使用。而由于氨气的点火温度较高，火焰速度较慢，氨燃料发动机需要更多的研发投入和设计。

从安全性来看，绿色甲醇和绿氨均需解决安全性问题。在腐蚀性方面，甲醇对橡胶和部分金属具有腐蚀性，并且粗甲醇中的酸性物质可能腐蚀金属。而液氨因其亲核性，对部分金属有腐蚀性。在毒性方面，根据GBZ230-2010《职业性接触毒物危害程度分级》，甲醇的职业性接触毒性危害程度也被评定为轻度危害(IV级），氨被评定为中度危害(ⅢI级）。根据GBZ2.1-2019《工作场所有害因素职业接触限制》，氨的短时间接触容许浓度（PC-STEL）为30mg/m³，甲醇为50mg/m³。考虑到氨常温常压下为气体，氨燃料发生泄漏的后果应该比甲醇更严重。

## 3.3为何绿醇能够兴起

根据上文比较，绿色甲醇相较于绿氨其实并没有决定性优势。而2023年开始产业发展产生较大转变，我们认为主要原因在于需求端的引导，其中最大的力量就来自航运业，而航运业加注绿色甲醇燃料的行为又主要由欧洲航运集团主导。

从欧盟将航运业纳入碳交易系统的具体执行措施来看，其对欧洲航运集团所施加的减排压力是最大的。自2024年1月1日起，航运业被纳入欧盟碳排放交易体系（EUETS）。欧盟境内航程需缴纳100%碳配额，欧盟和非欧盟地区之间的航程需缴纳50%碳配额。同时，欧洲航运公司本身就占据了全球最大的运力份额，根据Alphaliner数据，截至23年12月10日，全球在运营集装箱船数量共计6764艘，总运力为283.39万TEU，其中前三大班轮公司均为欧洲公司，总运力占全球市场的46.67%。因此，在替代燃料的推进上，欧洲公司具有最大的动力，而在替代燃料的选择上，欧洲公司具有最大的话语权。

为应对欧盟新规带来的减排压力，航运公司在2023年动作频频。根据克拉克森研究数据，2023年约有539艘涉及替代燃料船舶的新船订单，按吨位计占所有新船订单的45%。其中，甲醇双燃料船订单为125艘，比2022年增加了82艘，氨燃料船订单则仅为4艘。从现阶段来看，绿色甲醇明显更受航运企业青睐。

我们认为欧洲航运巨头选择绿醇的重要原因之一是欧洲在绿色甲醇项目布局上具有先发优势。前文提到，绿氨的生产技术相对成熟，由于空分装置、合成氨装置都可直接使用现成的技术甚至是装置，那么绿氨生产的核心竞争力主要就是绿电的成本。目前光伏发电成本低于风力发电，而欧洲虽然风力资源丰富，但太阳能资源相较于中东、美国和中国要明显匮乏。因此无论是从成本上还是存量装置上，欧洲在绿氨领域都不具备明显竞争力。

在绿色甲醇方面，欧盟经过多年布局已经将其定义的绿色甲醇标准推向全世界。而在欧盟的标准下，利用生物质生产绿色甲醇的相关标准较低，而非生物来源的绿色甲醇的标准则很高。直接利用化石能源制得的低碳甲醇则难以通过欧盟认证，这就使得工业密集型国家相对于欧洲国家的优势不复存在了。从现有产能来看，欧洲也是目前全球绿色甲醇产能最大的地区，目前德国绿色甲醇产能最高可达20万吨/年以上，挪威产能达18万吨/年。在技术方面，由于绿色甲醇生产具有较高的技术门槛，因此已经布局了绿色甲醇的欧洲企业就具备了技术优势，后续也可以通过技术合作的方式在其他国家布局绿色甲醇产能。

## 4、绿色甲醇空间如何

目前绿色甲醇已被广泛认可和接受的用途是作为航运燃料。我们认为在航运业减排目标下，绿色甲醇有望迎来巨大市场空间。在2023年7月7日通过的国际海事组织（IMO）温室气体减排战略修订案中，成员国达成一致目标：到2030年实现温室气体排放总量与2008年相比减排20%，到2040年实现温室气体排放总量与2008年相比减排70%，到2050年前后实现温室气体净零排放。我们认为在这样严格的减排目标下，航运业必然会加大绿色燃料对传统燃料的替代力度。而从现阶段航运公司的策略来看，绿色甲醇正成为绿色替代燃料主流。马士基中国脱碳业务总监就曾公开表示，2025年交付18艘大型甲醇船舶后，马士基每年需要绿色甲醇75万吨，到2030年这个需求量将达到500万吨，2040年大概需要2000万吨。根据Alphaliner数据，截至23年12月10日，马士基在航运在的运力占比为14.62%。假设2030、2040年绿色甲醇燃料在航运业整体的渗透进度与马士基同步，马士基运力占比不变，且各公司燃料需求占比与运力占比一致，那么就可以反推测算出2030、2040年全球航运业绿色甲醇需求量分别约为0.34、1.37亿吨。

在航运领域，根据IMO数据，2022年全球航运业消耗燃料约3.2亿吨。根据联合国《2023海运评述》预测，2024-2028年全球海运贸易量保持2.1%-2.2%的增速。我们假设2022-2030年前航运燃料消耗量平均增速为2%，2030-2050年平均增速放缓为1%，预测2050年航运业燃料消耗有望达4.6亿吨。在此基础上，考虑到绿色甲醇与传统燃料的热值差距，绿色甲醇在航运燃料中渗透率每提升1%，则对应的需求量增长0.11亿吨/年。

在车用燃料领域，根据2023版《bp世界能源展望》的预测，在加速转型和净零情景下，预计2050年电动汽车保有量增至20亿辆，在全球汽车保有量中的占比达80%。若剩余20%的汽车使用汽油作为燃料，则对汽油的需求量约为4.13亿吨。在此假设下，绿色甲醇对汽油的替代率每提升1%，对应的需求量增长0.096亿吨/年。

在发电领域，根据《世界能源统计年鉴》，2022年全球天然气发电量为66314亿千瓦时，同比增长1%。若保持1%增速，则到2050年天然气发电量将达87620亿千瓦时。在此基础上，若使用绿色甲醇替代天然气发电，假设发电效率为45%，则绿色甲醇发电对天然气发电的替代率每提升1%，对应的绿色甲醇需求量增长0.356亿吨/年。

## 5、绿色甲醇成本测算

绿色甲醇的生产工艺路线多，我们选取比较受关注的 $\mathsf { C O } _ { 2 }$ 加绿氢路线以及生物天然气路线，分别对二者的成本进行了测算。我们参考江苏斯尔邦环评中的原料和公用工程需求量数据对 $\mathtt { C O } _ { 2 }$ 加氢制甲醇成本进行测算。原料价格方面，参考内蒙绿氢生产成本约21000元/吨，参考同兴环保公布的 $\mathsf { C O } _ { 2 }$ 捕集成本范围将 $\mathsf { C O } _ { 2 }$ 成本假设为200元/吨。测算结果表明，目前使用绿氢和捕集的 $\mathsf { C O } _ { 2 }$ (来自废气)生产绿色甲醇的成本为5544元/吨。若绿色甲醇市场价格可达1000美元/吨，则目前有1600元/吨的盈利空间。在该路线下，绿氢成本对绿色甲醇生产成本的影响非常大，经过测算，若绿氢成本降低至10000元/吨，则绿色甲醇成本可降低至3234元/吨。

生物天然气制甲醇可以使用天然气制甲醇的工艺。目前工业上应用较广的天然气制甲醇工艺是水蒸气催化转化法，先将天然气与水蒸汽反应制合成气，再由合成气生产甲醇。生物天然气可由沼气提纯获得，根据《碳中和目标下的生物天然气行业展望》报告，目前国内以畜禽粪污、粪便与秸秆混合废弃物、餐厨垃圾为原料的生物天然气的平准化能源成本高达4.4\~11.5元/m³。我们假设生物天然气价格为5元/m³，测算出以生物天然气制绿色甲醇的成本为5220元/吨，若绿色甲醇价格可达1000美元/吨，则盈利空间在1900元/吨以上。

目前我国生物天然气成本较高的一大原因是生物天然气的生产原料比较分布分散，收集、储存和运输成本均相对较高，这也是利用生物天然气制绿色甲醇需面临的产业化难题。国内已有企业提出一种采用生物天然气异地接收、等量置换的方式制取绿色甲醇，通过这种方式可以避免生物天然气原料和产品的长距离运输过程，大大降低了绿色甲醇的生产成本，我们认为这种方式在国内具有较好的产业化前景。

虽然目前绿色甲醇的生产成本是传统甲醇的两倍以上，但我们认为，只要通过了欧盟认证标准，绿色甲醇现阶段就可以获得足额的利润。从长期来看，较高的生产成本会降低绿色甲醇相对于其他绿色替代方案的竞争力，影响绿色甲醇发展空间。而尽管目前绿色甲醇的潜在生产路线较多，但当绿色甲醇行业扩大到一定规模化后，具有较高成本的生产路线可能面临淘汰风险。总之，降低生产成本是绿色甲醇产业化和企业长期盈利的关键。

## 6、投资建议

我们看好绿色甲醇未来的发展空间和盈利机会，建议关注吉电股份、上海电气、中煤能源等布局生物质绿色甲醇和二氧化碳捕集制绿色甲醇项目的公司，建议关注参与构建绿色甲醇全产业链的中远海能。

## 7、风险提示

1)欧盟标准变动：若欧盟后续修改生物燃料、生物来源的可再生燃料和再循环碳燃料燃烧标准则可能导致部分项目的绿色甲醇产品不能满足欧盟标准。

2)绿色甲醇推广不及预期：若绿色甲醇在航运业、车用燃料以及作为能源载体的推广不及预期，则会影响未来绿色甲醇的市场空间，使得相关项目无法获得超额收益。

3)绿色甲醇价格大幅降低：若未来绿色甲醇价格大幅降低，则可能会影响绿色甲醇项目的经济收益。

4)绿色甲醇成本居高不下：若未来绿氢和生物质等原料成本依然较高，则可能会导致绿色甲醇生产成本较高，项目盈利能力不及预期。

5)新项目投产不及预期：若现有规划的绿色甲醇项目不能如期投产，则会影响相关公司未来通过绿色甲醇业务获得的经济收益。

6)假设条件变化影响测算结果：若文中测算部分的假设条件变化，则可能导致对绿色甲醇生产成本和未来市场空间测算的结果不准确。
