# 筹码理论行业轮动指数

## 核心观点

在加快建设金融强国的背景下，服务资本市场高质量发展与值指数化投资正当其时。中信建投筹码理论行业轮动指数在估值、成长、质量等基本面数据和传统量价指标的基础上，结合筹码结构，旨在衡量高动量、筹码不拥挤且多方力量强、高成长、现金流稳健、盈利强行业的整体表现。自 2018 年以来，策略相对于等权行业基准的超额年化收益约为 10%，年初至 6 月13 日录得 12.59%的超额收益。多数年份跟踪误差小于 9%且信息比率均大于 0.8、超额最大回撤不超过 6%。

## 中信建投筹码理论行业轮动指数

在加快建设金融强国的背景下，服务资本市场高质量发展与值指数化投资正当其时。中信建投筹码理论行业轮动指数衡量了符合高成长、现金流稳健、盈利强等特征，同时筹码不拥挤、动量较强的高质量行业的整体表现。

自 2018 年以来，策略相对于等权行业基准的超额年化收益约为10%，相对中证 800 约为 13.37%。相对等权行业指数来说，年初至 6月 13日录得 12.59%的超额收益，多数年份跟踪误差均小于 9%。除 2018 年和 2021 年外，策略的信息比率均大于 0.8；超额最大回撤也基本可控，2021 年达到 10.66%，其余年份均小于 6%。

## 筹码结构介绍

我们从指数的动量或反转类、多空力量、拥挤度和集中度等角度利用筹码分布数据构建了多种指标作为传统的量价指标的补充。

动量和反转：反转筹码动量的多空净值下降趋势稳定，表明短期涨幅较大的行业反转概率较高。筹码动量在刻画上涨趋势上与传统动量指标不相上下，高动量行业持续跑赢，但自 2021 年以来，策略逐渐失效。

多空力量：收盘价上方筹码越松散，即低套牢比例的行业组合越有可能跑赢。

拥挤类：盈利占比、筹码均价提升度比例高的行业收益更低、波动率更高。

集中度类：在高动量组合表现不佳时，高集中度组合能够持续跑赢；而在高动量组合表现良好时，高集中度组合的收益中枢则趋于振荡。将两者结合起来可以有效稳定组合收益。

风险提示：指数过往业绩不代表未来；筹码基于量价数据模拟，不代表真实数据分布。

## 1.1 编制方案

中信建投筹码理论行业轮动指数（CTSRI, Chip Theory Sector Rotation Index）在估值、成长、质量等基本面数据和传统量价指标的基础上，结合筹码结构，旨在衡量高动量、筹码不拥挤且多方力量强、高成长、现金流稳健、盈利强行业的整体表现。

该指数以 2018 年 1 月 2 日为基日，以 1000 点为基点，样本备选空间由除综合行业外，其余 30 个申万一级行业构成。

第一步，筛选多空力量、动量和反转类因子：根据 2015 年 1 月至本次调整日月末的月度 Rank ICIR ，在筹码多空力量、动量、反转各细分类别的因子备选集选择 1个最佳因子，等权合成大类因子。

 第二步，剔除样本：剔除月末拥挤度得分位于前 10%的行业和质量得分位于末尾 10%的行业并集。

第三步，精选样本：根据除拥挤类外的七个大类指标进行汇总打分（详见图表 1 分类），每类大类指标的权重相同，最终筛选出综合得分位于前 5名的除综合外的申万一级行业指数作为本期样本。

权重调整上，每个行业的期初权重均为 20%，即等权配置。

样本定期调整上，筹码理论行业轮动指数每月末调整，各类指标打分的调整计算日为截止到月末的最后一个交易日，样本调整实施时间为下个月的第一个交易日。

## 二、筹码指标介绍

## 2.1筹码分布定义回顾

筹码分布，亦称成本分布，是技术分析领域中用于描述证券在不同价格区间内持仓情况的重要工具。筹码分布是动量+换手的有机结合体，通过日度 vwap、最高价、最低价以及换手率等，模拟出每一个交易日的持仓分布 $f _ { t }$ ，个股为三角分布，行业指数为均匀分布。基于前一日的分布 $F _ { t }$ 、当天的模拟分布 $f _ { t }$ 以及的换手率𝑡𝑢𝑟𝑛𝑜𝑣𝑒𝑟 ，通过迭代方法推算出下一交易日的筹码分布，计算公式如下：

$$
F _ { t + 1 } = ( 1 - t u r n o v e r _ { t + 1 } ) F _ { t } ~ + ~ t u r n o v e r _ { t + 1 } f _ { t }
$$

以图 8 所示的医药生物行业的筹码分布图为例，筹码分布图通过横轴表示证券价格，纵轴表示持仓权重，模拟出投资者在各个价位的买入和持仓情况。尽管筹码分布并非基于真实订单簿层级汇总的真实数据，但由于所有证券都依赖于统一的假设，这便于同类证券（如股票、同级行业指数）之间的横向比较用于选股或者行业精选，以及自身时序的纵向比较用于择时。

## 2.2 分析角度

行业的动量和反转效应较为显著，轮动速度较快，难以通过长期持有获得超额收益。在周频或月频策略构建中，量价指标是策略构建关键的一环，如何融合并确定价格和换手率指标的权重是最大的挑战之一；同时直观地解释量价指标背后对应的指数运行状态也至关重要。

基于上述问题，我们从指数的动量或反转类、多空力量、拥挤度和集中度等角度利用筹码分布数据构建了多种指标作为传统的量价指标的补充。指标列表如图表 9 所示，指标的构建思路和基于第二部分的回测结果的结论如下所示：

 动量或反转类：基于筹码均价构建的动量因子与行业指数的趋势有更好的一致性。在指数在“缩量上涨”时，价格的运动趋势难以持续，这一指数形态等价于在换手极低时，股票的筹码分布没有显著上移，筹码均价也没有大幅上行。而放量上涨时，筹码均价的提升幅度更大，更能反映出投资者的一致情绪。

多空力量：收盘价上下方的筹码比例，即套牢和盈利的比例，可以直接对比多空双方的筹码力量。通常来看，低套牢或低阻力的组合往往表现更佳。

 拥挤度：筹码盈利占比相比于其他拥挤度指标拥有更直观的解释性，价格和换手的双飙对应着筹码盈利占比的快速提升，往往预示着短期见顶，需要规避短期反转风险。每次盈利占比达到历史极值位置或者快速提升往往意味着指数进入反转区域。

 集中度：集中度指标能在动量指标表现不佳时提供对冲，一定程度上稳定组合的超额收益。

## 三、筹码指标的历史表现

研究的回测区间选取为 2014 年 12月 31日至 2024年 6月 13日，IC测试回测频率为月度，回测样本选择了除综合行业外的所有申万一级行业指数。

## 3.1动量和反转类

筹码动量的计算方式分为 2步：

 第一步根据筹码分布数据计算出当日的行业指数的筹码均价，

 第二步直接分别选定 1、3、6和 12个月的时间窗口对筹码均价进行 z-score标准化，得出筹码趋势指标 cyq\_mom\_{x}m。

首先，考虑到不同行业的波动率存在显著差异，在选股的过程中，可以通过市值和行业中性化指标在一定程度上避免这一问题。然而，在行业精选中，若仅使用原始的动量指标，可能无法区分出高波动的𝛽行业和具有长期趋势的𝛼行业。为了解决这一问题，本文对即将讨论的动量类指标分别进行了 6、12、24和 36个月的 zscore标准化，以尽可能消除波动率的影响，比如 mom\_12m\_zscore\_36m的含义为 12个月动量在近 3年时间窗口的标准化 z值。

短期筹码动量在刻画反转趋势上优于传统动量指标。如图表 10 所示，cyq\_mom\_6m\_zscore\_12m 的 ic 和rank ic 均值绝对值分别位 0.05 和 0.49，远远大于 mom\_6m\_zscore\_12m 的 0.001 和 0.003，且在 5%的水平上显著。由图表 11 所示，筹码动量的多空净值向下趋势更加稳定，呈现了一定的 alpha 特性。

长期筹码动量在刻画上涨趋势上与传统动量指标不分伯仲，但自 2021 年行业轮动加速以来，两类指标均逐渐失效。从图表 10 的 IC 测试结果来看，标准化后的动量指标 mom\_12m\_zscore\_36m 与筹码趋势指标cyq\_mom\_12m 的 IC 和 Rank IC 均值差距并不显著，分别为 0.037 和 0.033，以及 0.041 和 0.037。图表 12 所示，自 2021 年以来，行业轮动逐渐加速，动量策略表现逐渐疲弱，多空净值转而向下，拖累了两个指标的显著性表现，P值分别为 14.2%和 15%，在 10%水平上甚至都不显著。

市场流动性下降时，筹码动量和传统相关性逐渐衰减。从图表 13 的相关系数来看，当市场的换手率波动不大时，两者的相关系数围绕 0.5 的中枢波动，但在 2015 年和 2020 年中证全指的换手率大幅下滑时，两者的相关性迅速衰减至 0附近。

## 3.2 多空力量类

多空力量类筹码的计算逻辑较为直观。收盘价上方的筹码被定义为“套牢”筹码，这些筹码可以视为一个阻力位或者是空方力量。当行业指数上涨时，“套牢”筹码往往有很强的动机在接近其成本价时抛售，以减少损失。相反，收盘价下方的筹码被定义为“盈利”筹码，当行业指数处于上行趋势时，这些“盈利”筹码通常会继续持有，以期获得更高的收益，这里可以被理解为多方力量，行业动量效应的显著性可能也与“盈利”筹码的这种行为模式有关，最后两者的比值可以近似作为多空力量的对比。

## 3.3 拥挤类

我们从盈利占比绝对值、盈利占比提升度和筹码均价提升度三个维度衡量行业指数短期拥挤的概率。当盈利占比达到绝对高位时，大多数投资者已经盈利，获利离场的可能性增强，增加了市场的卖压。同时，指数点位和换手率的快速提升对应着筹码中枢的快速上行和盈利比例的大幅提高，导致筹码均价和盈利占比显著上升，市场中的买入成本上升可能会减弱新的买入需求，这些因素共同增加了市场短期反转的可能性。

## 3.3.1 盈利占比

为了更好地刻画盈利占比的长期趋势，本文对根据日度筹码盈利占比进行了滚动 252 天均值处理，将平滑后的所有申万行业指数盈利占比的均值±1 倍标准差作为市场盈利占比趋势的上下轨。我们发现拥挤度触发大致有两种情形，以地产、煤炭、有色等周期行业，以及关注度较高的电子行业为例进行说明，：

参考布林带的做法，当盈利占比的上轨和下轨逐渐收敛，且上轨接近甚至突破 时，往往暗示市场短期可能出现拥挤。例如，图表 20-23中的红色区域所示，在 2007年 6月、2009年 6月、2015年7月和 2017年 8月，市场盈利占比分别突破 70%后，四个行业均面临不同幅度的回调。

行业的盈利占比突破市场的上轨时易出现“均值回归”的迹象。例如，图表 20-23中的黄色区域所示，如地产在 2007 年 6 月和 2013 年 1 月，电子行业在 2009 年 11 月、2014 年 1 月、2016 年 10 月、2020年 8 月和 2023 年 11 月，煤炭行业在 2021 年 6 月和 2024 年 1 月，有色金属行业在 2016 年 3 月和2021年 7月，盈利占比均突破了市场的上轨。随后，这些行业均出现了显著的“均值回归”迹象。

策略深度报告

## 3.4 筹码集中度

集中度衡量了某固定权重筹码的价格空间。高筹码集中度通常表明部分投资者已在特定且狭窄的价位区间内完成了建仓。这些投资者通常会锁定其持有的筹码，等待更高的价格以实现盈利，从而减少了市场上的卖出压力。

当筹码高度集中时，持有这些筹码的投资者对该股票的未来表现有较为一致的预期，容易形成共识。这种共识导致投资者在面对市场波动时采取一致的行为（如共同持有或不轻易抛售），从而降低了股价的短期波动性。

其计算方式和示例图如下所示：

$$
c o n _ { n u m } = \frac { p _ { 2 } - p _ { 1 } } { p _ { 2 } + p _ { 1 } }
$$

其中 $\begin{array} { r } { \int _ { 0 } ^ { p _ { 1 } } F _ { t } = \frac { n u m } { 2 } \% , \int _ { p _ { 1 } } ^ { p _ { 2 } } F _ { t } = n u m \% } \end{array}$ 和 $\begin{array} { r } { \int _ { p _ { 2 } } ^ { \infty } F _ { t } = 1 - \frac { n u m } { 2 } \% , F _ { t } } \end{array}$ 为指数点位的筹码分布。

## 风险提示

指数过往业绩不代表未来。市场环境、政策变化以及经济周期等因素都会对策略的有效性产生影响，从而导致历史表现无法准确预测未来结果。其次，指标组合可能存在过拟合风险。模型可能会捕捉到历史数据中的偶然性或噪声，从而在实际应用中失效。投资者应持续监控和优化模型参数，确保其适应市场的动态变化。最后，市场流动性、交易成本等现实因素也需纳入考虑范围，以避免策略实施过程中的潜在风险。建议投资者在使用本策略时，结合其他分析工具和方法，以分散投资风险。

筹码基于量价数据模拟，不代表真实数据分布。因为交易数据本身存在噪音，并且市场行为复杂多变，导致模拟的筹码数据只能部分反映真实情况。投资者在使用这些数据进行决策时，应谨慎对待，并结合其他分析工具和信息，以提高决策的准确性和可靠性。模拟数据仅具有部分参考意义，不能完全替代真实数据的分析结果。
