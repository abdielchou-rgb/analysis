## 投资要点

行业进入成熟阶段，股息率、回购比例对股票收益率的重要性提升

基于G-K模型推导可知，股票收益率主要由公司股息率、股本变化、盈利增长、估值变化四个因素所决定。当行业从成长阶段步入成熟阶段时，盈利增长、估值变化贡献弱化，而股息率、回购比例重要性提升。

当前美股呈现股份回购、现金分红两大分配方式兼顾的多元特征，而日股仍以现金分红为主、但股份回购受政策驱动已逐步强化。中国通过推出一系列改革措施强化现金分红，并不断完善股份回购政策。

## 借鉴海外啤酒龙头，自由现金流量明显改善驱动分红率、股息率提升

2023年最新美股食饮龙头整体分红率为57.4%，整体股息率为2.5%，其中可口可乐、百事股息率分别达到3.1%、3.0%，而百威英博受限于财务压力股息率仅为1.3%。此外2023年日股食饮龙头整体分红率为40.1%，整体股息率为1.8%，其中麒麟、朝日股息率分别为3.4%、2.3%。

以百威英博、喜力、嘉士伯等美欧啤酒龙头经验来看，股息率提升需多维度因素共同驱动，一是收入增速降档，二是自由现金流进入明显改善趋势，此外估值水平回落到合理区间是重要支撑。以百威英博为例，2010年后收入增速明显降档，同期自由现金流大幅提升，带动分红率从2010年的41.5%大幅抬升至2017年的104.8%，股息率同步从0.7%大幅提升至3.9%，而期间市盈率也从20倍水平抬升至30倍水平。

朝日、麒麟等日本啤酒龙头21世纪以来基本呈现增长乏力态势，在经历持续稳健经营沉淀后，当进入自由现金流明显改善阶段会看到分红率、股息率的同步抬升。以朝日为例，2002-2010年收入增长乏力阶段分红率变化不大，而在2015年后自由现金流大幅改善，带动分红率从2015年的30.2%提升至2020年的55.1%，同期市盈率中枢20-25倍。

借鉴海外啤酒龙头，立足我国当前实际，股息率提升的逻辑框架推演

①收入增速降档或乏力时，产业层面进入出清阶段，龙头依靠规模效应及更好的成本控制能力渡过难关，期间资本开支从高位回落，自由现金流量仍处于较低水平，同时估值水平震荡下移。

②产业出清后形成寡头垄断格局，收入增速稳定在中低个位数，但产业升级带动龙头净利率实质性大幅提升，驱动自由现金流大幅改善，同时估值水平明显企稳反弹。

③ 利润持续双位数增长带来现金流量持续积累，龙头逐步提升分红率，期间股息率同步抬升，同时资本开支逐步回落到稳态水平，持续稳健的自由现金流量积累确保了股息率高兑现度，估值中枢稳定在合理水平。

投资建议：借鉴海外啤酒龙头，当行业进入收入增速降档或乏力后，主动升级带来的盈利提升将驱动自由现金流量持续积累，分红率同步大幅提升，带动股息率明显提升。估值节奏参照百威英博、朝日等，如百威英博在股息率明显提升的2010-2017年PE估值从20倍水平抬升至30倍水平，而朝日在股息率明显提升的2015-2020年PE估值中枢维持在20-25倍水平。中国啤酒龙头是攻守兼备的优质主线，进攻层面来自升级的韧性及持续性，防御层面股息率的明显提升已然持续兑现，重点推荐青岛啤酒、燕京啤酒，关注重庆啤酒、珠江啤酒。

风险提示：宏观经济不及预期；中高档啤酒竞争加剧；食品安全风险。

## 1、中国与海外资本市场分红、回购相关政策回顾

Grinold 和 Kroner (2002) 将股票风险溢价定义为未来 10 年标普 500 股票指数和10年期政府债券之间的预期回报差，但预测未来10年标普500股票指数回归较困难，因而使用相关框架将股票收益率分解为几个可理解的部分，即R=incomereturn + nominal earnings growth+ repricing，并进一步细化为

$$
R = \underbrace { \frac { D } { P } - \Delta S } _ { I n c o m e } + \underbrace { i + \mathbf { g } + \Delta P E } _ { E a r n i n g s g r o w t h }
$$

基于G-K模型推导可知，股票收益率主要由公司股息率、股本变化、盈利增长、估值变化四个因素所决定。

V 当行业处于成长阶段时，盈利增长、估值抬升是股票收益率的主要贡献；而当行业从成长阶段步入成熟阶段时，收入节奏亦从中高增速回落至中低增速，使得盈利增长、估值变化贡献弱化，而股息率、回购比例重要性提升，成为影响股票收益率的关键，进而推知具备较强分红或回购能力的公司具备更好的投资回报。

对比来看，美国股市呈现股份回购、现金分红两大分配方式兼顾的多元特征，而日本股市仍以现金分红为主、但股份回购受政策驱动已逐步强化。当前中国股市通过推出一系列改革措施强化现金分红，并不断完善股份回购政策，以现金分红为主导的策略符合当前发展阶段。

美国资本市场发展历史较为悠久，大小股东绑定、员工持股计划普遍推行，因而重视股东回报，形成了鼓励企业回购提高股价的文化。

而日本历史上所有权与经营权明显分离，往往由金融机构掌握企业所有权，因而倾向于储备现金而非加大分红，此后通过政策保障红利，2023年新规推行促进现金分红和回购。

当前中国资本市场鼓励现金分红，新国九条将严格上市公司持续监管，未来分红率、股息率持续提升值得期待。具体来看，2024年4月12日国务院最新印发《关于加强监管防范风险推动资本市场高质量发展的若干意见》，强调要强化上市公司现金分红监管，对多年未分红或分红比例偏低的公司，限制大股东减持、实施风险警示；加大对分红优质公司的激励力度，多措并举推动提高股息率；增强分红稳定性、持续性和可预期性，推动一年多次分红、预分红、春节前分红。

## 3、借鉴海外，啤酒龙头股息率提升的逻辑框架

## 3.1、美欧经验：收入增速降档、同期现金流大幅改善

以百威英博、喜力、嘉士伯等美欧啤酒龙头经验来看，股息率提升需多维度因素共同驱动，一是收入增速降档，二是自由现金流进入明显改善趋势，此外估值水平回落到合理区间是重要支撑。

百威英博研究区间在2005-2016年(收购南非米勒后的高负债阶段不具备参考性)，2005-2010 年收入 CAGR 达到 20.1%，而 2010-2015 收入 CAGR 仅为3.7%，可以看到百威英博收入增速在2010年后明显降档，同期自由现金流大幅提升，使得其具备强劲的分红及回购能力，期间百威英博分红率从2010年的41.5%大幅抬升至2017年的104.8%，同期股息率从0.7%大幅提升至3.9%，而期间市盈率也从20倍水平抬升至30倍水平。

喜力 2000-2020年期间收入 CAGR大致为 5.3%，同期自由现金流处于持续波动提升趋势，期间喜力分红率从20%水平提升至45%水平，同期市盈率中枢维持在20倍以上，2020年以来收入增速有所提升，估值虽有波动但仍维持在20-30倍区间，2023 年最新股息率大致为2.1%。

嘉士伯2000-2020年期间收入CAGR大致在2.6%，而自由现金流在2013年完成对重啤绝对控股后大幅改善，期间嘉士伯分红率从2013年的22.3%提升至2020年的54.1%，同期市盈率中枢抬升至25倍水平。近年来嘉士伯分红率基本维持稳定，2023年最新分红率、股息率分别为53.3%、3.2%，而控股子公司重啤2023年分红率、股息率分别达101.4%、4.2%。

## 3.2、日本经验：收入增长乏力，累计现金流持续改善

区别于以百威英博为代表的欧美龙头，朝日、麒麟等日本啤酒龙头21世纪以来基本呈现增长乏力态势，在经历持续稳健经营的时间沉淀后，当进入自由现金流明显改善阶段会看到分红率、股息率的同步抬升，因而驱动股息率提升的核心因素仍是持续经营积累带来下一阶段现金流的持续改善。

朝日2002-2010年期间收入CAGR大致在1.0%，期间自由现金流波动提升，分红率变化不大；而在2015年后自由现金流大幅改善，期间朝日分红率从2015年的30.2%提升至2020年的55.1%，同期市盈率中枢维持在20-25倍水平。2020年至今朝日资本开支有所加大，分红率呈现波动下降，2023年最新分红率、股息率分别为37.4%、2.3%。

麒麟2002-2020年期间收入CAGR大致在0.9%，期间自由现金流波动提升，而在2010年后自由现金流明显改善，期间分红率从2009年的49.6%提升至2020年的75.4%，同期市盈率在20-40倍区间波动，股息率从2009年的1.5%波动提升至2020年的2.7%。2020年至今麒麟资本开支有所加大，2023年最新分红率、股息率分别为51.1%、3.4%。

## 4、当前中国啤酒龙头分红率、股息率节奏推演

产业增速边际变化时点研究价值意义重大，复盘中国啤酒产量增速边际趋势来看，2000-2013年行业产量基本维持较好增长态势，2013年行业产量达到高点后经历短期调整，并于2018年后逐步企稳，当前基本维持稳态节奏。当啤酒行业产销量进入稳态阶段后，中档升级、高档扩容成为行业共识，在华润、青啤等行业龙头引领下，盈利能力明显提升带来了现金流质量大幅改善，同时在估值波动加大背景下，龙头公司的分红率明显抬升。

②产业出清后形成寡头垄断格局，收入增速稳定在中低个位数，但产业升级带动龙头净利率实质性大幅提升，驱动自由现金流大幅改善，同时估值水平明显企稳反弹。

③利润持续双位数增长带来现金流量持续积累，龙头逐步提升现金分红率，期间股息率实现同步抬升，同时资本开支逐步回落到稳态水平，持续稳健的自由现金流量积累确保了股息率高兑现度，估值中枢稳定在合理水平。

## 5、投资建议

借鉴海外啤酒龙头，当行业进入收入增速降档或乏力后，主动升级带来的盈利能力提升将驱动自由现金流量持续积累，分红率同步大幅提升，进而带动股息率明显提升。估值节奏参照百威英博、朝日等，如百威英博在股息率明显提升的2010-2017年PE估值从20倍水平抬升至30倍水平，而朝日在股息率明显提升的2015-2020年PE估值中枢维持在20-25倍水平。中国啤酒龙头是攻守兼备的优质主线，进攻层面来自升级的韧性及持续性，防御层面股息率的明显提升已然持续兑现，重点推荐青岛啤酒、燕京啤酒，关注重庆啤酒、珠江啤酒。
