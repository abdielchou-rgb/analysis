<sup>＃</sup>⚫<sup>sum</sup>第<sup>m</sup>一部分：<sup>ary＃</sup> 2024 年以来债市运行的逻辑及债市的新形态

✓ 2024 年债市发生新特征的核心原因：1）定价经济偏弱预期。2）降息侧重于贷款利率与存款利率，绕开 OMO 及 MLF 的限制。3）市场微观结构发生重大变化。4）形成新的一轮金融脱媒和缩表。

⚫ 第二部分：从“地产周期决定模式”向“新质生产力”下的债市新常态转变

✓ 债市“地产周期决定模式”已经弱化。

✓ 新质生产力下的货币政策重心发生了一定的改变：从“以我为主”到“注重内外均衡+预期管理”。

✓ 新质生产力赋予财政政策新的定义：解决部分有效需求+化解风险。

✓ 新质生产力+新旧动能切换，在防范风险中的权衡：降成本是最大的公约数。

⚫ 第三部分：债券市场需要关注哪些扰动项？

✓ 汇率的掣肘：中美周期错位还要多久？1）中美货币政策周期差收敛可能还需要等待一段时间。2）OMO 和 MLF 降息短期受稳汇率压力掣肘，但如果出口走弱导致稳汇率诉求下降，OMO 和 MLF 降息可以期待。4）存款利率受汇率目标约束较弱，调低存款利率反而对稳定汇率有积极作用。

√ 新涨价因素+库存周期是否会对债券市场形成脉冲？1）CPI 不超过政府目标 3%的情况下，难以成为债市主要矛盾。2）关注库存周期对债市的影响。

✓ 央行买卖债券可能是战略顶层设计：1）通过买卖债券来调节市场资金利率；2）通过买卖债券来释放资金，替代 MLF。

⚫ 第四部分：债牛新形态——利率传导机制的重构

✓ 利率形成传导可能在发生变化。阶段性更加重视通过降低存款利率来压降银行负债成本，降低保险产品预定利率防范利差损风险，后续可能逐渐淡化 MLF。

✓ 债券交易的主线仍然是负债成本下降+资金不紧+优质资产稀缺。1）下半年地方债发行可能加速，但可能仍处于优质资产稀缺的环境中。2）对于配置盘而言，重点关注超长期限国债、长期限地方债、超长期限信用债以及非活跃品种的配置机会。3）对于交易盘而言，下半年可重点关注存单、2-7 年利率的修复价值，仍需保持一定的久期。长债、超长债价值可能随后跟进。4）从利率曲线角度，做平曲线的久期中性策略可能是个值得尝试的选择。5）信用债的品种溢价下降，建议投资者以票息为主。

✓ 需要注意的风险点：市场纠结的不是买点，而是什么时候是卖点？1）汇率波动可能通过影响资金面和市场情绪扰动债市（9-11 月需重点关注）。2）稳增长政策进一步加码。3）央行已多次提示长端利率风险，后续不排除央行继续进行预期管理或者创设新的货币政策工具。4）关注负债端的稳定性。

## 第一部分：2024 年以来债市运行的逻辑及债市的新形态

⚫ 2024年市场复盘：

✓ 2024年1月-3月，债牛快速演绎后进入震荡。4-6月债市：央行提示风险下长端超长端区间波动。

✓ 1-6月：利率曲线先平坦后小幅走陡，信用利差维持低位。

✓ 1-6月股债市场：风险偏好底部反弹，但债券并不弱。隐含宽松预期上升，经济增长预期底部反弹。

⚫ 2024 年债市新特征：

✓ 央行宽货币行为克制，但债市利率整体下行。

✓ 市场倾向于抢跑交易，交易诉求提升。

⚫ 造成新特征的核心原因：

✓ 市场仍然定价经济偏弱预期。

√ 没有直接降息，但降息侧重于贷款利率与存款利率，绕开 OMO及 MLF的限制。

✓ 市场微观结构发生重大变化。

✓ 实体收缩下+机构负债成本下降，形成新的一轮金融脱媒和缩表。

引言：2024年初至今，债券市场仍表现出牛市的特征。时至当下，债市看多分歧不大，但投资者最为纠结的是：1、利率还有多少下行空间；2、引导利率下行的逻辑是否发生了本质性变化；3、对交易盘而言，困难的不是寻求买点而是如何寻求卖点，年内是否存在引发阶段性回调的时间及原因。本报告主要围绕以上3 点进行展开论述。

⚫ 2024年 1月-6月中旬，债市整体处于牛市环境中。年初到 6月 18日，10Y国债收益率下行约 30BP，30Y 国债收益率下行约 34BP。资金面平稳偏松+债市处于“资产荒”的环境，是支撑 2024年上半年债牛的重要逻辑。

✓ 2024年1-2月，跨年后，资金面有所转松，债市做多空间打开，叠加大类资产风险偏好较低，债牛行情快速演绎，国债10Y-1Y牛陡，国债 30Y-10Y 牛平。

✓ 2024年3月，债市在快牛后转为震荡，市场交易的主线开始转为基本面的边际利好，以及大类资产风险偏好的小幅修复。

✓ 2024年4-6月，债市在震荡中整体仍然维持牛市的逻辑。4月以来，伴随着中小银行陆续下调存款利率，以及“手工补息”的取消，银行体系整体负债成本继续压降。“手工补息”取消后，部分资金从银行流向非银，非银资金较为充裕，银行间资金面也维持宽松的状态。而政府债供给节奏也不及市场预期，基本面好转幅度偏弱，债市整体仍处于“资产荒”的环境。4 月起，央行多次提示长端利率风险，但市场在4 月下旬明显回调后，收益率仍转为下行。4-6月无论是国债10Y-1Y还是30Y-10Y 利差均有所走阔。

## 第二部分：债市矛盾的转折——从“地产周期决定模式”向“新质生产力”下的债市新常态转变

⚫ 债市“地产周期决定模式”弱化的主要原因：

✓ 地产政策即使放松，但人口增长率、居民杠杆率、城镇化率等指标看，大的周期已经过去，地产链条的经济的贡献率在持续下降。

✓ 地方政府进入“一揽子”化债后，“地产政府”进入杠杆管控时代，投融资冲动受到核心约束。

✓ 居民部门也进入信用扩张的瓶颈期：资产负债表的健康性、资产回报预期、收入预期等等。

✓ 新旧动能转换加速，信用创造机制发生本质性变化：从“拉绳子”到“推车子”，对冲与托底的作用大于刺激。

新质生产力下的货币政策重心发生了一定的改变：从“以我为主”到“注重内外均衡+预期管理”

✓ 货币政策并非单纯的宽松，出于汇率均衡的考虑，维持政策利率不变（OMO、MLF）。

✓ 降息通过存款利率、LPR及贷款利率引导，绕开了政策利率的限制。

✓ 更加注重预期引导，通胀预期及利率走势预期。

✓ 央行买卖债券可能作为货币政策调控的新手段。曲线上从平坦化转向陡峭化，扭转市场通缩预期。

新质生产力赋予财政政策新的定义：解决部分有效需求+化解风险

✓ 中央加杠杆与地方加杠杆的区别：财政资金项目审批更加严格、更加注重实物工作量考核、储备特别国债资金与项目。

✓ 除了货币政策外，财政在防风险层面的重要性也在上升：地方政府化债+财政资金给中小银行注资。

新质生产力+新旧动能切换，在防范风险中的权衡：降成本是最大的公约数

✓ 防风险的重心仍在：地方政府债务+中小银行+地产风险。

货币及财政的组合拳：不仅仅是宽松和财政扩张，更多要类似“增加资本金”。

✓ 降成本是重要的方向：实体融资成本+金融机构负债成本（稳定银行净息差）。

新常态下，货币政策和财政政策的重心也发生转变，债券利率下行也是大势所趋。但需要关注该系统稳定性可能被打破的因素：1）总需求扩张。2）通胀预期回升。3）汇率的不稳定性，均衡从外部打破。目前看以上因素均未出现。

## 1、债市“地产周期决定模式”的主要特点

社融底领先于经济底，“居民+企业+地方政府”是加杠杆的核心。历史复盘来看，社融增速见底往往领先于制造业 PMI 见底，意味着信用周期实际上驱动了经济周期。拆分近年来宏观杠杆率上行的分项，主要是居民、企业和地方政府在加杠杆，而中央政府杠杆率总体平稳，反映出信用周期中，“居民+企业+地方政府”事实上是加杠杆的核心。

⚫ 债市周期实际上是信用周期。经济基本面是债市大周期的核心决定因素，而驱动经济周期的实际上是以实体部门为核心的信用周期变化。总的来看，债市周期的本质是信用周期。

⚫ 央行货币政策的重心在于“地产+基建”。作为宏观总需求的重要变量，“地产+基建”也是央行货币政策的重心。市场层面来看，国债收益率与“地产+基建”投资增速一致；政策层面来看，挂钩中长期信贷的 5 年期 LPR 也与“地产+基建”投资增速较为一致。

⚫ 无论是资产荒还是负债荒都与“地产+基建”密切相关。例如，2015-2016 年上半年以及2021年至今，债券市场均演绎了资产荒的逻辑，国债收益率陡峭下行，与此同时伴随的宏观经济环境特征也是“地产+基建”增速明显下台阶；2016Q4-2017年，债券市场演绎负债荒的局面，国债收益率陡峭上行，与此同时，房地产超预期回暖，地产开发投资增速回升支撑投资增速企稳改善，宽信用效果较为明显。

## 2、债市“地产周期决定模式”弱化的主要原因

⚫ 房地产大的周期已经过去，经济重要性也明显下降。考虑到我国房地产市场供求关系发生重大变化的新形势，即使地产政策放松，地产也恐难像以往一样成为经济支柱。近年来，人口增长率已转负，反映地产需求出现了新的格局，居民杠杆率高企，难以有效支持地产大的周期，城镇化率也已到达瓶颈。综合来看，房地产大的周期已经过去，地产链条的经济的贡献率也在持续下降。

⚫ 地方政府进入“一揽子”化债后，同时也进入杠杆管控时代，投融资冲动受到核心约束。当前地方债务风险已进入稳妥有序化解的阶段，地方政府加杠杆行为也更加规范和理性。从城投债融资情况来看，今年以来持续的显著低于季节性水平，反映地方政府的投融资冲动受到核心约束。杠杆管控时代，城投平台+土地财政的旧模式难以为继，地方政府投资逻辑可能正在发生根本性转变。

⚫ 居民部门也进入信用扩张的瓶颈期。从居民资产负债表来看，当前居民杠杆率已经偏高，叠加居民收入预期依然较弱，或表明居民信用扩张缺乏坚实基础。与此同时，居民的房价上涨预期和未来收入预期双双趋弱，存量博弈时代，居民资产配置也更加多元化和理性化。总体来看，居民部门可能也已经进入信用扩张的瓶颈期。

⚫ 新旧动能转换加速，信用创造机制发生本质性变化：从地产“拉绳子”到财政“推车子”。2020年及以前的地产时代，几乎每轮信用创造都与地产周期紧密相关，地产对经济的刺激作用类比“拉绳子”。2021年以来，新旧动能加速转换，信用创造从地产为重心转向以“货币+财政”为重心，中央政府加杠杆的模式下，信用创造类比“推车子”。政府主导信用创造的显著特征在于，对冲压力与托底经济的作用大于刺激经济。从M2 和社融增速两个指标看信用创造机制的变化：1）M2基本 10年左右切换一次主导因素。2002-2012年 M2 为出口主导模式，为了对冲充裕的外汇占款央行创设央票来回收流动性。2012-2020年M2为“地产+基建驱动信贷”模式，央行创设MLF等工具来投放流动性。2021年至今，M2 为“政府债券”主导模式，需要创新新的工具来对冲政府债券的投放（比如买卖债券）。2）从社融增速看，政府融资及财政支出都在信用创造中发挥愈来愈重要的作用，反映出新旧动能加速转换的背景下，信用创造机制也在发生根本性变化。

⚫ 新旧动能切换加速，信用创造机制的转变，使得货币的投放可能产生 2个重大变化：1）资金从“供给约束”转向“需求约束”；2）货币政策框架从“数量型为主”转向“价格型为主”。

## 3、新质生产力下，政策的侧重点也不同

新质生产力更加注重“质”的发展，信贷从追求数量到追求质量，投向更多倾向于做好“五篇大文章”。习近平总书记明确指出：“新质生产力是创新起主导作用，摆脱传统经济增长方式、生产力发展路径，具有高科技、高效能、高质量特征，符合新发展理念的先进生产力质态。”可以看出，新质生产力驱动经济发展的大背景下，经济发展更加注重“质”的层面。近年来金融支持实体经济也出现新特征，金融机构可能要减少“规模情结”、信贷挤水分、投放也更多倾向于“五篇大文章”领域。

⚫ 财政政策侧重于“提质增效”和注重实物工作量的考核。2024 年《政府工作报告》强调：“积极的财政政策要适度加力、提质增效。”近期特别国债、地方债的发行节奏均有所加快，有效贯彻落实2024年 4 月中央政治局会议要求的“及早发行并用好超长期特别国债，加快专项债发行使用进度，保持必要的财政支出强度”。总的来看，当前财政政策侧重于“提质增效”和注重实物工作量的考核。

新旧动能切换加速，信用创造更多依靠政策推动。历史来看，以往信用创造更多的是靠信贷驱动，尤其是地产部门的信贷需求，这从居民资产负债表扩张与房价走势高度一致可以看出。近年来，地产链条弱化背景下，新旧动能切换加速，财政在信用创造中起到愈发重要的作用。同时，尽管地产仍是负向拖累，但高技术制造业投资增速维持高位，表现新旧动能加速。下一阶段政策的进一步加码，可能出现在高新技术制造业投资转弱的时候。

## 4、新质生产力下的货币政策重心发生了一定的改变：从“以我为主”到“注重内外均衡+预期管理”

⚫ 货币政策并非单纯的宽松以稳定经济，今年以来或出于汇率均衡的考虑，政策利率维持不变。货币政策目标更加多元化，除了稳经济、稳物价之外，还有维持汇率均衡等目标。2024年以来，OMO/MLF 等重要政策利率均维持不变。

⚫ 降息通过存款利率、LPR及贷款利率引导，绕开了政策利率（OMO、MLF）的限制。事实上，尽管政策利率保持不变，货币政策依然通过降低存款利率、降低LPR、降低贷款利率等途径有效缓解金融机构的资产负债压力，进而更好支持实体经济健康平稳运行。从降低银行负债成本、维持银行净息差稳定的角度看，降存款利率的必要性和作用大于OMO与MLF。

⚫ 货币政策更加注重预期引导，包括通胀预期及利率走势预期。或担心长端利率下行过快造成金融机构资产收益和负债成本倒挂，衍生金融风险隐患，2024年以来央行多次通过预期引导的方式影响市场利率走势。这反映出，货币政策更加注重预期引导和实施效率，货币政策调控方式趋于多元化。

⚫ 央行买卖债券可能作为货币政策调控的新手段。从供需关系影响分析，央行买债有利于推动利率下行，而卖债则有助于调整利率下行过快的预期，央行买卖债券可能成为货币调控的新手段。当前市场预期较弱的背景下，利率曲线偏平坦化，央行买卖债券可能有助于扭转市场关于经济下行压力较大的预期，推动利率曲线从平坦化转向陡峭化。

财政政策的防风险重要性上升。除了货币政策外，财政在防风险层面的重要性也在上升。一方面，财政政策支持地方有序化解债务风险，2023 年四季度以来各地陆续发行特殊再融资债券；另一方面，财政资金支持地方中小银行健康发展，专项债起到了较好的支撑作用。

## 6、新质生产力+新旧动能切换，在防范风险中的权衡：降成本是最大的公约数

防风险的重心仍在地方政府债务+中小银行+地产风险。2023 年以来，中央多次强调防范化解重大风险工作，尤其聚焦地方债务、中小金融机构和房地产领域。2024年4月中央政治局会议明确要求：“统筹研究消化存量房产和优化增量住房的政策措施”，“深入实施地方政府债务风险化解方案”，“持续推动中小金融机构改革化险”。

⚫ 货币及财政组合拳，不仅仅是货币宽松和财政扩张，而是更多要发挥类似“增加资本金”的作用。货币政策和财政政策协调配合，不仅停留在传统的扩张性刺激经济的层面，而是在推出系列创新的结构性货币政策工具的基础上，优化落实政策性开发性金融工具实施，在很大程度上起到为重大项目“增加资本金”

的作用。

⚫ 降成本是重要的方向：实体融资成本+金融机构负债成本。目前来看，实体企业的实际融资成本已升至历史高位，而银行的净息差也下降至历史低位。因此，从经济运行系统层面出发，实体融资成本和金融机构负债成本都面临一定压力，也都有降成本的诉求。最近三个季度的央行货币政策执行报告中，也屡次强调“着力稳定银行负债成本”。

⚫ 汇率的掣肘：中美周期错位还要多久？

✓ 中美货币政策周期差收敛可能还需要等待一段时间，这意味着外部均衡是货币政策的核心考虑之一。

✓ OMO 和 MLF 降息短期受稳汇率压力掣肘，但如果出口走弱导致稳汇率诉求下降，OMO和MLF降息可以期待。

✓ 存款利率受汇率目标约束较弱，调低存款利率反而对稳定汇率有积极作用。

⚫ 新涨价因素+库存周期是否会对债券市场形成脉冲？

✓ 近期资源品、电力以及部分城市的公交地铁等出现涨价现象，但短期或难明显推升CPI、PPI读数，长期仍需关注。

✓ 关注库存周期对债市的影响。

⚫ 海外的经验：央行买卖国债对债市影响几何？

✓ 日本YCC 是央行实施量化宽松的特殊阶段，过去 20年以日本央行的 YCC政策最为典型。

✓ 美欧的经验表明，央行购债只有在传统货币政策工具失效的情况下才会使用；

✓ 海外央行购债主要是为了解决持续通缩和总需求不足的问题。

⚫ 中国央行购债的可能性：

央行有可能把债券买卖纳入货币政策工具箱，但与海外不同：1）传统的货币政策工具仍然有空间（包括政策利率和存款准备金率）；2）中国不存在持续通缩的问题。

央行买卖债券可能是战略顶层设计：1）通过买卖债券来调节市场资金利率；
2）通过买卖债券来释放资金，替代MLF。

## 1、汇率的掣肘：中美周期错位还要多久？

⚫ 中美货币政策周期差收敛可能还需要等待一段时间，这意味着外部均衡是货币政策的核心考虑之一。从年初到现在，年内联储降息预期由降息 4 次以上压缩至降息1-2次。背后的驱动因素是美国基本面较强的韧性和通胀粘性。2024年6月美联储点阵图给出的指引是 2024 年只降息一次，这意味着市场目前的降息预期还有再度修正的可能。如果联储宽松预期再度延后，美债利率上行和美元走强可能继续对人民币币值稳定构成压力。

⚫ 央行综合运用宏观审慎政策稳定汇率，稳汇率的压力边际上有所上升。人民币汇率由多种因素决定，但美元指数是美元兑人民币汇率的强贝塔。稳汇率压力直观上可以通过观测两个指标：即期汇率相比中间价的偏离程度，以及在岸人民币与离岸人民币的偏离程度。目前即期汇率贴近波动上限运行，CNH 与 CNY 的价差也出现扩大，这指向强美元对人民币汇率的扰动在增强。此外地缘层面也对人民币稳定构成一定干扰。

⚫ OMO 和 MLF 降息短期受稳汇率压力掣肘，但如果出口走弱导致稳汇率诉求下降，OMO 和 MLF 降息可以期待。央行在稳汇率的过程中，稳定离岸人民币汇率是重要的一环。稳定离岸人民币汇率，意味着离岸人民币利率的显著抬升。离岸人民币利率的抬升，对在岸人民币利率有明显带动作用。CNY 和CNH是“一种货币，两种市场”，如果 CNH 利率显著高于 CNY，会导致跨境套利压力增大。因此在中美货币政策周期差收敛前，OMO 和 MLF 降息受到稳汇率目标的约束。另一方面，降低金融机构负债成本是现阶段央行的政策重心，而OMO和MLF 利率下调对稳定银行净息差、降低金融机构负债成本的帮助作用有限，因此短期看调降 OMO 和 MLF 利率的必要性不强。但是在中期，如果出口走弱导致稳汇率诉求出现边际放松，那么OMO和MLF 降息的空间就会打开。

⚫ 存款利率受汇率目标约束较弱，调低存款利率反而对稳定汇率有积极作用。存款利率不是批发融资利率，也不是基准政策利率，与套利活动的联动性较弱，存款利率下调对汇率的影响不及 OMO 和 MLF 利率下调。降存款利率可以帮助稳定银行净息差，降低金融体系潜在风险，从这个角度而言对稳定汇率反而具有积极意义。另外，在存款规模大幅上升、内需增长乏力的背景下，存款利率下调边际上可以降低居民和企业的储蓄意愿，刺激消费和投资，改善国内基本面预期和金融市场风险偏好，这同样有利于人民币币值保持稳定。

⚫ 总结而言，现阶段降低OMO和 MLF对降低金融机构负债成本作用有限，下调OMO和 MLF利率的迫切性不强，但在中期如果出口出现放缓，OMO和MLF降息的空间可能会打开。降存款利率能帮助稳定银行净息差并增强金融体系的稳健性，且对汇率稳定的冲击并不显著，因此继续推进存款利率下行大概率是央行的政策重心。

## 2、新涨价因素+库存周期是否会对债券市场形成脉冲？

⚫ 近期资源品、电力以及部分城市的公交地铁涨价，但短期或难明显推升 CPI、PPI读数。资源品涨价主要在于全球定价的原油、有色等板块，国内定价的黑色板块仍然受地产拖累，这可能也是商品涨价与PPI 有所背离的原因。资源品涨价主要体现在PPI 回升，但从近几年来的表现来看，PPI难以向CPI有效传导。近期部分地区的电力以及公交地铁涨价，一方面仅部分地区出现类似现象而非全国，另一方面在居民收入预期较弱的背景下，这类生活必需品涨价可能更多的是压缩居民其他支出，最终可能产生抑制总需求的效果，大概率难以推升通胀。

⚫ 总体来看，CPI 不超过政府目标 3%的情况下，难以成为债市主要矛盾，尤其是在结构性通胀的环境下。这里，我们回顾了历史上通胀对债市的脉冲影响，主要聚焦 2017年、2019 年、2021 年。1）2017 年通胀主要源于“三去一降一补”供给侧结构性改革带来的供给端冲击，PPI快速上行但 CPI 总体在低于3%的合理区间变动，央行也认为“生产资料价格涨幅快速上升”，但“居民消费价格温和上涨”（2016Q4 货币政策执行报告）。2017 年期间，货币政策总体稳健。2017年初OMO和MLF利率调升，可能主要与房地产调控和美联储加息有关。2017年债市行情受通胀因素影响较小，总体上金融“去杠杆”加速、海外央行加息等因素，对国债收益率上行起到了主要推动作用。2）2019 年通胀主要源于猪价上行推动 CPI 抬升，具有明显的结构性通胀特征，而非食品CPI、核心 CPI 均表现平稳。央行也认为“物价形势总体可控，通胀预期基本平稳”（2019Q4 货币政策执行报告）。因此，经济增速下行背景下，实际上2019 年期间央行反而多次采取降准、下调 LPR、降低 7 天逆回购操作利率等偏宽松措施。2019年，债市总体呈现震荡格局。一季度国债收益率上行，主要因为宽信用效果显现，社融、PMI等指向经济回升向好；9 月国债收益率上行，主要因为提前部署提前批专项债等措施释放了较强的积极财政和宽信用信号；10 月 CPI 同比在 9 月 3.0%的基础上进一步上行，对国债收益率起到一定的推升作用，但并未成为债市主要矛盾。3）2021 年通胀主要有两方面推力，一是疫情影响下海外央行宽松政策造成了输入性通胀，二是国内“双碳”系列政策起到了类似供给侧改革的影响。不过，2021 年期间，CPI 同比总体都在低于2.5%的区间内。央行也明确表示尽管“PPI 可能维持高位”，但“通胀压力总体可控”。（2021Q3 货币政策执行报告）2021 年债券市场总体呈现震荡慢牛的格局。其中，2021年 1月中下旬债市回调主因宽松政策退出叠加春节流动性缺口，10月环保政策影响下黑色系商品涨价，通胀预期发酵对债市产生一定影响，但同时还有专项债供给压力等多重因素影响。总体来看，CPI不超过政府目标3%的情况下，难以成为债市主要矛盾，尤其是在结构性通胀的环境下。

⚫ 关注库存周期对债市的影响。从库存周期的特征来看，PPI一般领先库存周期2M左右，目前阶段，基于大宗商品市场走势判断，PPI 有进一步上行的可能，因此，关注后续主动补库存是否开启。重点跟踪两方面线索，一是价格（PPI）回升的持续性，二是企业利润的改善情况。2016年以来，库存周期一般领先债市转折点。当前宏观经济基本面稳定，内需不足仍是主要矛盾，库存周期带来的基本面边际变化可能获得较多关注，可能会对债市产生一定影响。

## 3、海外的经验：央行买卖国债对债市影响几何？

<sup>⚫</sup> 日本央行的 YCC 政策：YCC（收益率曲线控制）是日本 QQE（quantitative andqualitative easing）政策的第三阶段，是对极度宽松货币政策的纠偏。2013 年4月日本央行开始实施QQE 政策，但带来两个后果：1、收益率曲线大幅下移，10年国债收益率转负，极大削弱了金融机构盈利能力和金融体系稳定性；2、日本央行资产负债表出现持续扩张。2016 年 9 月日本央行开始实施 YCC，政策操作由盯住货币供应量转向价格型调控。YCC 政策下，日本 10 年国债收益率在 0附近波动，大部分时间在正值区间，直到2022年开始放宽波动区间。YCC政策增强了金融体系稳定性并减缓日本央行扩表幅度。

⚫ 美联储购债（量化宽松）主要发生在政策利率达到零利率下限（ZLB）的阶段，例如 2009-2014年以及 2020-2021 年。政策利率降至零后，传统的货币政策工具失效，如果要进一步加强货币宽松，只能采取非常规的货币政策工具，即扩张资产负债表。量化宽松一定程度克服零利率下限的约束，拓展了货币政策的可能性。欧央行量化宽松的政策逻辑与美联储是一致的。当传统政策利率工具失效（进入负利率），不得不通过央行资产负债表的扩张来实施货币宽松政策。

⚫ 通过对日本YCC和美欧央行购债政策的梳理，我们可以得到以下结论：1）日本YCC 是央行实施量化宽松的特殊阶段，过去 20 年以日本央行的 YCC 政策最为典型。2）美欧的经验表明，央行购债只有在传统货币政策工具失效的情况下才会使用；3）央行购债主要是为了解决持续通缩和总需求不足的问题。

⚫ 我国央行有可能把债券买卖纳入货币政策工具箱，但与海外不同：1）传统的货币政策工具仍然有空间（包括政策利率和存款准备金率）；2）中国不存在持续通缩的问题。央行买卖债券可能是战略顶层设计：一方面通过买卖债券来调节市场资金利率（DR007）；另一方面通过买卖债券来释放资金，替代 MLF。中国央行如果开始买卖债券，更多是作为技术性手段，并不代表货币政策方向改变。

## 第四部分：债牛新形态——利率传导机制的重构

⚫ 债券市场当下交易可能并不算拥挤。

⚫ 利率形成传导可能在发生变化。

➢ 当前基于利率走廊及政策利率的利率传导机制可能有所弱化。

➢ 利率传导机制的新变化：阶段性更加重视通过降低存款利率来压降银行负债成本，降低保险产品预定利率防范利差损风险，MLF 对中期利率的引导作用有所下降，后续可能逐渐淡化MLF。

⚫ 债券交易的主线仍然是负债成本下降+资金不紧+优质资产稀缺。

下半年地方债发行可能加速，但债市可能仍处于优质资产稀缺的环境中。

➢ 对于配置盘而言，需要以票息为核心，重点关注超长期限国债、长期限地方债、超长期限信用债以及非活跃品种的配置机会。

➢ 对于交易盘而言，重点关注负债成本下降带来的机会。下半年可重点关注存单、2-7年利率的修复价值，仍需保持一定的久期。长债、超长债价值可能随后跟进。当下国债15-20年、国开债 8-9年是凸点，可重点关注。

➢ 从利率曲线角度，曲线可能很难长时间维持陡峭，曲线阶段性陡峭后，做平曲线的久期中性策略可能是个值得尝试的选择。

信用债的品种溢价下降，建议投资者以票息为主。城投做底仓、二永债做波段仍可能是最优策略。

⚫ 需要注意的风险点：市场纠结的不是买点，而是什么时候是卖点？

➢ 汇率波动可能通过影响资金面和市场情绪扰动债市（9-11月需重点关注）。

➢ 若稳增长政策进一步加码，债市仍需要给予一定的定价。

➢ 央行已多次提示长端利率风险，后续不排除央行继续进行预期管理或者创设新的货币政策工具。

➢ 债券收益率降低的过程中久期风险往往增加，若市场行情发生波动，关注负债端的稳定性。

## 2、利率形成传导可能在发生变化

⚫ 此前政策利率与市场利率之间的传导，是通过“央行调整政策利率——银行间资金利率中枢、银行同业存单利率中枢/LPR 利率跟随政策利率调整——实体融资成本联动变化”的方式来进行。资金利率围绕政策利率上下波动，存单利率/LPR则锚定MLF。当央行意图通过宽货币来助力稳增长/宽信用时，一般是央行下调OMO 和 MLF 操作利率，DR007 中枢跟随 OMO 利率下行，LPR 也大概率跟随MLF操作利率下调，进而传导至实体融资成本下行。

⚫ 当前，基于利率走廊及政策利率的利率传导机制可能有所弱化，这一利率传导机制可能面临的问题包括：

✓ 1）实体融资意愿对利率的敏感度下降，LPR下调难以带动房地产相关贷款回升。居民中长期贷款的主要构成是房贷按揭，而房贷利率挂钩 5 年期LPR利率。2021年以前，LPR利率下调明显带来居民新增中长期贷款规模中枢抬升，反映出彼时房地产表现为利率敏感部门。但 2021 年以来，伴随房地产供求关系发生重大变化的新形势，房地产新发展模式推进，LPR下调可能难以在短期内带动房地产贷款明显回升。

✓ 2）MLF逐渐滞后于同业存单市场利率走势。2022年以前，银行同业存单利率明显表现出受到 MLF 利率引导的特征，反映政策利率向市场利率传导机制趋于成熟。但是，2022 年以来这一特征发生了明显的逆转，即，MLF 利率演变为滞后于同业存单利率的变化，或表明我国利率传导机制也在发生新的变化。

✓ 阶段性压降存款付息成本可能是压降银行体系负债成本更有效的方式，对汇率的扰动也可能小于直接下调OMO和 MLF操作利率。从其他存款性公司资产负债表来看，负债中对非金融机构及住户负债占比超过60%，是银行体系负债的主要组成部分。降低存款成本对银行负债成本的压降作用可能大于降低商业银行对央行负债的成本。2024年央行发布的 2次《货币政策执行报告》，均把“着力稳定银行负债成本”的表述放在“推动社会综合融资成本稳中有降”，指向政策端阶段性可能把压降银行负债成本尤其是存款成本放在更加重要的位置。2023 年 12月以来，从大行到股份行，再到中小银行陆续下调存款利率，不排除后续仍有新一轮存款利率的下调趋势，存款成本下调的效果可能逐渐显现。

✓ 除了压降存款付息成本以外，降息保险产品预定利率也是降低金融体系负债成本的方式之一。2024 年 6 月金融监管总局局长李云泽在陆家嘴论坛的演讲中强调“进一步健全保险产品定价机制，指导保险机构调整产品结构，有效防范利差损风险”。后续保险产品预定利率有望进一步下行。

✓ MLF对中期利率的引导有所弱化后，政策端可能淡化 MLF的引导作用，而是更加重视短端政策利率。2024 年 6 月央行行长潘功胜在陆家嘴论坛的演讲中强调“未来可考虑明确以央行的某个短期操作利率为主要政策利率，目前看，7 天期逆回购操作利率已基本承担了这个功能。其他期限货币政策工具的利率可淡化政策利率的色彩，逐步理顺由短及长的传导关系”。中期来看，央行可能逐步增加在二级市场的国债买卖，来增强对利率曲线的调控能力。

## 3、新的利率传导机制对债市的影响

⚫ 即使不降 OMO和MLF操作利率，通过下调银行存款利率和保险产品预定收益率，仍有降低金融体系负债成本的作用，对债市而言依旧是利好。

⚫ 存款利率下调后，关注“存款搬家”的演绎和影响。银行存款利息持续下调背景下，部分居民和企业存款可能会转向银行理财、货币基金等收益相对有吸引力的金融产品。我们发现“存款搬家”阶段性缓解可能主要是两种情况：一是，宽信用效果明显，实体经济投融资需求增大，企业更倾向于保留大量的活期存款以应对生产经营需求，进而“存款搬家”速度可能放慢。二是，金融市场阶段性波动有所加剧，资金可能回流至银行存款以实现“避险”的目的，典型代表是 2022年底债券市场调整引发理财赎回，理财资金回流至银行存款（详见 《 <sup>“</sup>存款搬家<sup>”</sup>可能加速下阶段利率下行行情——“存款搬家”历史复盘与现状研判\_20240526》）。目前“存款搬家”仍在持续，这一现象持续演绎可能会对债券交易逻辑产生较大影响。

图表 72：当前处于新一轮“存款搬家”进程中
![](images/4d1fd7f381ba8637aa55c18ccf0eef63aba70f6c328cc4661c810799b16384f8.jpg)
数据来源：Wind，兴业证券经济与金融研究院整理

✓ “存款搬家”的过程可能会增加市场可用资金，进而增加对债券的配置需求，带动市场利率曲线下行。存款搬家”可能使得一般存款转变为非银存款，而非银存款无须缴纳存款准备金。“存款搬家”到资管产品，可能起到类似降息加降准的效果。同时，即使货币基金和理财规模扩容，但考虑到二者的预期回报也在下降，“存款搬家”的进程仍将带动利率曲线下行。

√ 随着“存款搬家”的演绎，可能边际上更加利好中短久期的利率债（尤其是政金债）和高等级信用债，也间接利好中长期限债券。银行买债和非银机构买债的不同点在于：存款利率下降，更加有利于长债及超长债（长期负债对标长期资产）。但存款转化为货币基金及理财，可能更加有利于短债及中短债（短期负债对标中短端资产）。同时，理财申购公募基金，公募基金买债的期限长于理财，起到理财借道公募拉久期的效果。

✓ “存款搬家”也是“双刃剑”，可能在某些时点放大债市波动。存款转化为货币基金及理财，可能会加大非银机构资产与负债的期限错配风险，因而是个“双刃剑”。需要关注两个潜在风险：1）若资金边际收紧，市场波动可能阶段性放大；2）经济回升带来的估值调整压力。

✓ 从传导链条来看，“存款搬家”可能会经历“资金面偏宽松→非银回购放量→机构积极买债”的过程。目前看，非银机构买债积极、但杠杆并不高。这说明买债的资产主要来自申购，但非银是否加杠杆还在观望中。

图表 73：银行理财、货币基金、保险产品均较银行存款更有优势
![](images/cd5ba6798021e002154b21250b98c07ca35a851f4930d4a59b128fe580e52bc4.jpg)
数据来源：同花顺，兴业证券经济与金融研究院整理

✓ “存款搬家”大概率不会加大银行负债压力。首先，“存款搬家”并不意味着存款流失，更多地可能是从一般存款转化为非银存款；其次，非银机构资金宽裕也往往不会导致银行资金面紧张，因为银行理财、货币基金等配置较多的还是存款类产品、同业存单类产品，因此“存款搬家”往往不会造成银行的负债端压力。4月以来，同业存单利率仍在下行通道。

✓ “存款搬家”可能仍未结束，“非银回购放量”或已转向“机构积极买债”阶段，并且非银机构买债仍有较大空间。

⚫ 保单利率下降或有助于进一步降低保险负债成本，进而打开其收益空间，增强保险买债的积极性。若后续保险产品预定利率再次下调，或能在一定程度上压降保险负债端成本，进一步打开其收益空间。对债券市场而言，保险是重要的潜在多头。保险资产端资金运用余额稳定增长，并且债券类资产是其重要投资方向。保险为债券市场重要的配置盘，利率快速下行时买债力量相对中庸，但利率回调则给保险提供较好的配置机会，保险是债券市场的潜在多头。

⚫ 综合来看，利率传导机制发生重要变化，利率下行对 OMO、MLF 下降的依赖度减弱，负债成本下降（存款利率+保险保单预定利率下降）是引导利率下行的

重要通道，即广谱利率整体下行。

## 4、债券交易的主线仍然是负债成本下降+资金不紧+优质资产稀缺

⚫ 展望下半年，负债成本下降仍在进行中，近期潘行长表态央行仍然维持支持性的货币政策，资金大概率不紧，债市仍然处于利多的环境。在负债成本压降的过程中，需要关注资金的流向，关注货基和理财规模的变化。

✓ 下半年地方债发行可能加速，但债市可能仍处于优质资产稀缺的环境中。经济向高质量发展阶段转型的过程中，金融总量增速可能有所下降，信贷和信用债的净融资可能不会明显超季节性。金融体系的资金仍然面临寻找优质资产的问题。虽然下半年地方债发行可能有所加速，阶段性可能缓解“资产荒”的压力。但和债市较为充裕的负债端相比，资产端优质资产稀缺的问题可能仍是主要矛盾。

✓ 对于配置盘而言，需要以票息为核心，在低利率的环境下，重点关注超长期限国债、长期限地方债、超长期限信用债以及非活跃品种的配置机会。

✓ 对于交易盘而言，重点关注负债成本下降带来的机会。下半年可重点关注存单、2-7年利率的修复价值，仍需保持一定的久期。长债、超长债价值可能随后跟进。当下国债15-20年、国开债 8-9年是凸点，可重点关注。

√ 从利率曲线角度，曲线可能很难长时间维持陡峭，曲线阶段性陡峭后，做平曲线的久期中性策略可能是个值得尝试的选择。一方面，若资金面维持宽松状态，而中短久期利率债收益率下行后，反而会凸显长债和超长债的性价比，曲线牛陡可能向牛平转化。另一方面，若债市出现明显扰动，曲线熊平的概率也大于熊陡。当前债市单边策略空间变窄，做平曲线的久期中性策略可能是个值得尝试的选择。

✓ 信用债的品种溢价下降，建议投资者以票息为主。城投做底仓、二永债做波段仍可能是最优策略。

⚫ 需要注意的风险点：市场纠结的不是买点，而是什么时候是卖点？

✓ 1）美元指数偏强的状态预计将维持一段时间，汇率波动可能通过影响资金面和市场情绪扰动债市，9-11月需重点关注（类似 2022Q3和 2023Q3的情况）。

✓ 2）若稳增长政策进一步加码（关注 7 月重要会议的表述变化），债市仍需要给予一定的定价。

✓ 3）央行已多次提示长端利率风险，后续不排除央行继续进行预期管理或者创设新的货币政策工具。从陆家嘴论坛上潘功胜行长的讲话来看，后续央行大概率会将二级市场买卖国债作为货币政策工具的选项（但阶段性可能仍处于和财政沟通的阶段）。若央行开启买卖国债操作，其对收益率曲线的引导作用可能增强。

✓ 4）债券收益率降低的过程中久期风险往往增加，若市场行情发生波动，关注负债端的稳定性。
