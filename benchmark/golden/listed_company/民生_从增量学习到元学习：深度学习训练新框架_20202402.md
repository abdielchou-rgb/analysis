## 从增量学习到元学习：深度学习训练新框架

➢ 增量学习对传统的批量学习提升效果不大。增量学习是指在现有模型的基础上，通过加入新的数据来更新模型的过程。与传统的批量学习不同，增量学习可以更好地适应数据的变化，同时也更加高效，因为只需要处理新增的数据而无需重新训练整个模型。在股票趋势预测的增量学习中，我们通过一系列增量任务来逐步更新模型参数。在每个任务中，我们使用增量数据来微调模型参数，并在测试数据上进行预测并评估模型性能。用这样的方法在 LSTM 深度神经网络上进行训练，IC从 3.6%提升到了4.2%，提升效果不大。

务中表现最好。一个典型的元学习模型 MAML（Model-Agnostic Meta-Learning），即“模型无关的元学习”是 17 年发表在机器学习顶级会议 ICML上的一种通用优化算法，适用于任何基于梯度学习的模型。MAML 旨在为基模型提供初始化参数，以便面对新任务时能快速学习。用MAML对机器学习模型进行适应，应用至增量学习训练框架中，可以显著提升预测因子 IC，LSTM 模型因子的 RankIC从 4.2%提升至6%，效果明显。

➢ 双步适应训练框架对数据与模型都进行元学习，来适应新的在线任务场景。传统的增量学习存在的问题是，在线场景中，新数据会不断到来，而增量数据与历史数据可能具有不同的联合分布，包括条件分布和协变量分布的变化。若数据分布变化较快，则增量学习无法适应。用数据适应器对数据分布进行适应可以解决这一问题。数据适应器也是一种元学习器，包含 2 个对于训练数据进行线性变化的函数，用来学习怎样调整训练数据的分布才能更好的适应分布变化，以获得更好的预测准确率。将数据适应器和模型适应器即MAML一起使用，形成双步适应训练框架 DA，可进一步提升预测效果。

➢ 双步适应训练框架对传统深度学习模型都有提升。实证表明，双步适应训练框架 DA 对于市场中流行的深度神经网络 LSTM 和 GRU 都有明显提升。若只用模型适应器 MAML，可以显著提升预测因子 IC，但多头端收益提升不明显。在加入数据适应器后可以显著提升因子多头端组合表现，其中 LSTM\_DA 因子多头组合在中证500内年化收益14%，年化超额收益17.6%，信息比率2.37，表现优秀。

➢ 风险提示：量化模型基于历史数据，市场未来可能发生变化，策略模型有失效可能。

## 1.1 传统的批量学习法

传统的批量学习法存在一定改进空间。在传统的深度学习方法中，我们常用批量学习，即滚动训练（Rolling Retraining, RR）来进行模型的训练与预测。在这样的框架中，我们常用某固定时间框架的训练数据进行训练与验证，并用未来的一段时间进行预测。下图是批量学习方法的示意。一般来说，在股票历史回测的框架内，因为深度学习计算效率与消耗资源较大，我们常用每半年至一年训练一次模型的方式进行滚动训练与预测，并且用最近一年左右的时间作为验证集。这就导致大多时候，模型无法获取最新数据进行训练，即模型无法包含最近数据分布的信息。且若训练数据随时间增长，模型参数较多，模型计算效率将更加缓慢，超参数的搜索过程将耗费大量时间与资源。

## 2 元增量学习—双步适应训练框架

## 2.1 增量学习存在问题

股票市场的数据分布很容易随时间变化而发生变化，这会对增量学习构成挑战。尽管在在线推断中，新数据会不断到来，但增量数据与历史数据可能具有不同的联合分布，包括条件分布和协变量分布的变化。这意味着在进行增量学习时需要平衡模型更新的程度，以避免过拟合或欠拟合模型。下图展示了 2019 年不同时期的沪深 300 股票量价指标与收益率的联合分布密度函数（构图参见Laurens van der Maaten and Geoffrey Hinton. 2008. Visualizing data usingt-SNE.）。我们用上一期增量数据（图中紫色线）的数据对模型进行微调，从而影响本期期模型在预测集上的预测。在图(a)中的 2019 年 9-10 月，分布由增量数据至测试数据逐渐变化，是增量学习较为适合的应用环境。而在图(b)中的 2019年 4-5 月，增量数据与测试数据的联合分布差异较大，这时增量学习法适用性较弱，参照对比第一节中的因子表现我们就会发现，这时增量学习较传统的批量学习法更差。

除此之外，传统的微调类增量学习在前一个任务的模型基础上更新参数，分布的突然变化（如上图 b 中的 abrupt shift）可能导致模型落入局部优化，从而过拟合增量数据。因此，我们需要寻找一个更优的模型初始化参数，以至于这一参数既保留了历史信息的规律，又可以提取增量数据的信息，即从数据和模型两个部分，对于训练流程进行改进。

基于上述问题，Lifan Zhao 等人在 2023 年的机器学习 KDD会议中发表了论文 DoubleAdapt: A Meta-learning Approach to Incremental Learning并在论文中提出了双步适应训练框架——DA元增量学习（DoubleAdapt)，旨在通过适应数据和模型来解决增量学习中的分布变化问题。该方法包括两个适应器，一个用于数据适应，用来调整数据分布；一个用于模型适应，用来调整增量训练中的模型参数初始化，并通过元学习进行优化。本篇研究在上述论文的基础上进行了改进并复现。

接下来，我们先介绍论文中提到的模型适应器，即 MAML 元学习，再将数据适应器加入到元增量学习框架中，形成双步适应训练框架，作为最终模型。

## 2.2 MAML 元学习

元学习（meta-learning）旨在训练一个 AI 模型，让这个模型能迅速学会训练新数据，并有较好的泛化能力。一个典型的元学习模型 MAML（Model-Agnostic Meta-Learning），即“模型无关的元学习”是 17 年发表在机器学习顶级会议 ICML 上的一种通用优化算法，适用于任何基于梯度学习的模型。MAML 旨在训练输出一组基模型的初始化参数，以便拥有这一初始参数的基模型面对新任务时能快速学习。传统的深度学习模型初始化参数的方式是随机的，而元学习可以为深度学习模型提供一组适合新任务场景的超参数，包括模型的初始化参数，学习率等。从而让这一深度学习模型有更好的预测效果。

相比传统训练，MAML 在数据的划分上更有层次，它引入了训练任务的概念，每一个训练任务都包含自己的训练集与测试集，为了避免混淆，我们将子训练任务的训练集称为 support-set，测试集称为 query-set。并且不同的训练任务可以训练不同的数据类别，有不同的x和y。在本篇研究中，我们将每40个交易日的股票数据作为一个训练任务，其中 support-set 为前 20 天，query-set 为后20 天的数据。

图9：元学习的训练任务
![](images/d30816ee93ccb00b71255b4f9ab966761380287a25014eeee9ffe1c1a58e1acf.jpg)
资料来源：Hung-yi Lee(2019) Lecture of Meta Learning

和机器学习一样，元学习用梯度的方式来更新参数。我们将元学习的函数表示为 F，则元学习旨在找到一个函数𝑭(𝝓)，让𝑭输出一组机器学习模型的最佳初始参数𝜽，以让用𝜽初始化的机器学习模型能够最大化多个训练任务的正确标签概

率之和。则元学习 MAML的流程为：

（1） 定义网络结构𝑭，初始化网络参数𝝓，计算 $\mathbf { \dot { \theta } _ { 0 } } = F ( \phi _ { 0 } )$ 。

（2） 输入训练任务，用 $\mathbf { f } ( \theta _ { 0 } )$ 在 task 1 上的 support set 计算 loss 和梯度，更新参数𝜽，根据 query set 计算𝒍<sub>𝟏</sub>。

（3） 按照相同步骤训练 task2，task3……

（4） 对第一个 meta batch的所有 loss 求和，计算梯度，更新参数𝝓。

（5） 训练下一个 batch，直至所有 meta batch训练完毕。

（6） 取验证集最好的一组𝝓，应用至增量任务𝜽的计算，再用基模型𝒇(𝜽)进行预测。

## 2.3 DA 双步适应训练框架

在前文中，我们提到了增量数据的分布变化可能导致模型落入局部优化，从而过拟合增量数据，影响增量学习的预测效果。因此，我们需要寻找一个更优的模型初始化参数，以至于这一参数既保留了历史信息的规律，又可以提取增量数据的信息，即从数据和模型两个部分，对于训练流程进行改进。在这篇论文中，作者将元学习的概念应用到了增量学习中，发明了双步适应训练框架，包含数据适应器（Data-Adapter）和模型适应器（Model-Adapter）。其中模型适应器就对应了上文介绍的 MAML 元学习，故接下来，我们先介绍数据适应器，再将数据适应器应用到 MAML 元增量学习中，构成 DA双步适应训练框架。

## 2.3.1 数据适应器

数据适应器是一种元学习器，用来学习怎样调整训练数据的分布才能更好的适应增量数据的分布变化，以获得更好的预测准确率。数据适应器旨在通过对于任务中的 X 和 y 进行不同的多重线性变化 G 和 H 来适应数据变化。作者认为，某些分布变化模式会在历史数据中重复出现，可以被学习。例如，股票价格可能会对某些牛市消息和情绪投资过度反应，而价格和趋势模式往往会在未来几周内转向正常。所以，在输入至预测模型前后，我们需要对数据做不同的变化。

由于测试数据的标签在模型推理时是未知的，我们无法直接对齐训练数据集分布和测试数据集分布。数据适应器将分布变化分解为协变量分布变化和条件分布变化并分别进行处理。首先，数据适应器使用映射函数𝐺将训练数据集和测试数据集的特征 X 适应（变换）到代理特征分布，以减轻协变量分布变化。再使用另一个映射函数 H 来适应训练数据集 $D _ { t r a i n }$ 的标签 y，将训练数据集 $D _ { t r a i n }$ 的条件分布 $P _ { t r a i n } ( y | x )$ 适应到可能的未来分布 $P _ { a g e n t } ( y | x )$ 以处理条件分布变化。最后需要将模型输出从代理条件分布 $\mathrm { P _ { a g e n t } ( y | x ) }$ 反向映射到测试数据集 $\mathrm { D } _ { \mathrm { t e s t } }$ 的条件分布$\mathrm { P } _ { \mathrm { t e s t } } ( \mathrm { y } | \mathrm { x } )$ 。通过特征和标签适应，数据适应器缩小了训练数据集 $D _ { t r a i n }$ 和测试数据集 $D _ { t e s t }$ 之间的分布差距，以减轻分布变化问题。

资料来源：Lifan Zhao, et al(2023)，民生证券研究院

为了消除协变量分布变化，一个直观的想法就是对 $X _ { t r a i n }$ 和 $X _ { t e s t }$ 做线性变换${ \hat { x } } = W x + b$ ，从而使得二者得分布能够映射在同一个超平面上。然而单次线性变化可能无法充分转化不同特征的分布变化，故作者提出了对样本 x 进行多次线性变化，并施加不同权重。具体定义 G 为 $\begin{array} { r } { G ( x ) : = x + \sum _ { i = 1 } ^ { N } s _ { i } \cdot g _ { i } ( x ) } \end{array}$ ，其中 $g _ { i } ( \mathrm { x } ) =$ $W _ { i } \mathrm { x } + b _ { i }$ ，而 $\dot { \boldsymbol { s } } _ { i }$ 则是根据初始参数向量 ${ \bf { \bar { \rho } } } p _ { i }$ 与 x 的余弦相似度计算的强度系数，N 为线性变化的层数，本篇研究中我们取 8。对于标签 y 的条件分布，作者也作出类似的操作，即 $\begin{array} { r } { H ( y ) : = \sum _ { i = 1 } ^ { N } s _ { i } \cdot h _ { i } ( y ) } \end{array}$ ，其中 $h _ { i } ( y ) = \gamma _ { i } y + \beta _ { i }$ 。而在在线推断的过程中，我们不知道真实的预测标签 $y ,$ ，这时，我们需要将用x̃预测的𝑦̃作出H 的反向变换，即 $\begin{array} { r } { \hat { y } = H ^ { - 1 } ( x , \check { y } ) : = \sum _ { i = 1 } ^ { N } s _ { i } \cdot h _ { i } ^ { - 1 } ( \check { y } ) } \end{array}$ 。故数据适应器包含的参数集合可以用 $\psi = \{ W _ { i } , b _ { i } , p _ { i } , \gamma _ { i } , \beta _ { i } \} _ { i = 1 } ^ { N }$ 来表示，在元学习阶段中更新。

## 2.3.2 DA双步适应训练框架

在数据适应器对数据进行适应后，我们将适应后的数据输入至模型适应器中。模型适应器即为我们在 2.2 中定义的 MAML 元学习，我们用模型适应器输出模型的初始参数以及学习率，以达到将模型适应为“可以快速学习新数据”的模型，再用适应后的模型对适应后的数据进行学习。在 DA 双步适应框架中，数据适应器与模型适应器共同定义了增量模型的外围训练框架。则最终的训练步骤为：

（1） 给定增量数据 $D _ { t r a i n }$ ，数据适应器通过 G 将特征向量 x 进行转换，并通过 H 转换相应的标签 y，生成一个适应的增量数据集 $\widetilde { \mathbf { \mathcal { D } } } _ { t r a i n }$

（2） 模型适应器通过参数权重 $\phi ^ { k - 1 }$ 初始化预测模型的参数，按照增量学习方法，在适应的增量数据集 $\widetilde { D } _ { t r a i n }$ 上对预测模型进行微调，生成任务特定的参数 $\boldsymbol { { \{ \theta } ^ { k } } $ ，然后将更新后的预测模型 $f ( \theta ^ { k }$ )在线部署。

（3） 对于 $D _ { t e s t }$ 中每个样本的x，数据适应器通过G将特征向量x进行相同的线性变换。然后 $f ( \theta ^ { k } )$ )采用转换后的特征向量 $\mathsf { X } ,$ ，生成一个中间预测 ，该预测将通过 $H ^ { - 1 }$ 转换为最终预测𝑦̂。

（4） 一旦获得所有股价的真实标签，通过计算最终预测误差 $\mathcal { L } _ { t e s t }$ ，在上层优化元学习器，即数据适应器和模型适应器。元学习器的参数从 $\phi ^ { k - 1 }$ 和 $| \psi ^ { k - 1 }$ 更新到𝜙<sup>𝑘</sup>和𝜓<sup>𝑘</sup>，这些参数将用于下一个增量学习任务。元学习过程本质上是一个双层优化问题，其中步骤 2 中的微调是下层优化，步骤4 中的优化是上层优化。

图13：DA 双步适应训练框架示意图

在训练时，训练过程仍然分为离线学习和在线推断。上文中提到，在本篇研究中，我们将每 40 个交易日的股票数据作为一个训练任务，其中 support-set 为前 20 天，query-set 为后 20 天的数据。前一个任务的 query-set 和后一个任务的 support-set 有重叠，保证了训练任务的样本数量。离线学习中我们学习出元学习器的初始参数与基分类器模型，随后应用至增量学习中，在增量训练任务更新模型与参数，预测新一轮因子值。

## 3 元增量学习对传统深度学习模型的增强

在上文中，我们提到了 2 种元增量学习的模式：只对模型进行优化的元学习MAML 与对数据和模型进行双步优化的双步适应训练框架 DA。2 种方法都包含了外部模型元学习与内部的基分类器。前文提到过，元学习可以应用至任何根据梯度进行优化的机器学习模型。接下来我们将对市场中最主流的两个深度神经网络LSTM和GRU分别测试元学习MAML与双步适应训练框架DA对于这2个基模型的增强效果。

训练采用80G内存，V100显卡服务器，MAML框架下基模型的训练时间约为 5小时，DA 框架下基模型训练时间约为 8小时。

## 4 总结与思考

在本篇研究中，我们复现了 Lifan Zhao, et al(2023)于 2023 年在国际顶级机器学习会议 KDD 上发表的论文 DoubleAdapt: A Meta-learning Approach toIncremental Learning for Stock Trend Forecasting，提出从增量学习到元学习的训练框架，用中证 500 内股票的价量信息输入基模型后进行训练框架的优化，最终，论文作者提出的双步适应训练框架 DA 元增量学习取得了最好的效果，并对传统的机器学习模型有较大提升，证明了元增量学习框架在深度学习预测股票收益问题上的可行性。

增量学习对传统的批量学习提升效果不大。增量学习是指在现有模型的基础上，通过加入新的数据来更新模型的过程。与传统的批量学习不同，增量学习可以更好地适应数据的变化，同时也更加高效，因为只需要处理新增的数据而无需重新训练整个模型。在股票趋势预测的增量学习中，我们通过一系列增量任务来逐步更新模型参数。在每个任务中，我们使用增量数据来微调模型参数，并在测试数据上进行预测并评估模型性能。用这样的方法在 LSTM 深度神经网络上进行训练，IC从 3.6%提升到了4.2%，提升效果不大。

元学习旨在学习一个机器学习模型的设定，使得这一模型在所有的训练任务中表现最好。一个典型的元学习模型 MAML（Model-Agnostic Meta-Learning），即“模型无关的元学习”是 17 年发表在机器学习顶级会议 ICML 上的一种通用优化算法，适用于任何基于梯度学习的模型。MAML 旨在为基模型提供初始化参数，以便面对新任务时能快速学习。和机器学习一样，元学习用梯度的方式来更新参数。我们将元学习的函数表示为 F，则元学习旨在找到一个函数F(ϕ)，让 F 输出一组机器学习模型的最佳初始参数θ，以让用θ初始化的机器学习模型能够最大化多个训练任务的正确标签概率之和。

对数据与模型都可以进行元学习，来适应新的在线任务场景。在论文中，作者发明了双步自适应的训练框架，将数据适应器（Data-Adapter）和模型适应器（Model-Adapter），即MAML一起使用。数据适应器是一种元学习器，用来学习怎样调整训练数据的分布才能更好的适应分布变化，以获得更好的预测准确率。所以，在输入至预测模型前后，我们需要对数据做不同的变化，再将变化后的数据输入至模型适应器中，进行分类器的训练。

双步适应训练框架对传统深度学习模型都有提升。实证表明，双步适应训练框架 DA 对于市面上流行的深度神经网络 LSTM 和 GRU 都有明显提升。若只用模型适应器，可以显著提升预测因子 IC，但多头端收益提升不明显。在加入数据适应器后可以显著提升因子多头端组合表现，其中 LSTM\_DA 因子多头组合在中证 500 内年化收益14%，年化超额收益 17.6%，信息比率2.37，表现优秀。
