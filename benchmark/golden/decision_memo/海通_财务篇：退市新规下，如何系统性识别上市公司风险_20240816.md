## 预计出现财务退市风险警示情形：

应当在相应的会计年度结束后一个月内，披露股票可能被实施退市风险警示的风险提示公告

## 出现规定情形：

应当在披露年度报告或者财务会计报告更正公告的同时，披露公司股票交易被实施退市风险警示公告。

公司股票于公告后停牌一个交易日，自复牌之日起，交易所对公司股票交易实施退市风险警示。

## 年报披露前：

至少再披露两次风险提示公告

## 预警1：连续3年亏损，且持续经营能力存在不确定性

• 根据Q3的财报数据，线性预测t年全年净利润：

• 假设Q4维持前3季度的增速，则T年预期净利润=

$$
\begin{array} { r l } { \bullet } & { { } \mathsf { N P } _ { \mathsf { T } } ( \mathsf { Q } 1 - \mathsf { Q } 3 ) + \mathsf { N P } _ { \mathsf { T } - 1 } ( \mathsf { Q } 4 ) + \mathsf { a b s } [ \mathsf { N P } _ { \mathsf { T } - 1 } ( \mathsf { Q } 4 ) ] ^ { \ast } \mathsf { N P } \mathsf { Y O Y } _ { \mathsf { T } } ( \mathsf { Q } 1 - \mathsf { Q } 3 ) } \end{array}
$$
