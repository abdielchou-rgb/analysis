# 无一手数据情况下的顶级打法：二手数据的"极致化"研究框架

> 触发：2hao 缺乏专家访谈/现场调研数据通道，油位报告因此"空"
> 本文档：①正视无一手数据的现实 ②给出行业顶级打法——如何在只有二手数据的情况下，写出有洞察、有信息增量的报告
> 参考：天风证券赵晓光"四位一体"研究体系（调研1.0→研究2.0）、卖方研究数据三角验证法、投行供应链拆解法
> 日期：2026-08-05

---

## 一、核心认知：没有一手调研 ≠ 写不出好报告

**顶级分析师在没有一手数据时，靠的是"二手数据的极致化处理"——把公开数据做出"别人没做过的深度"。**

赵晓光（天风证券副总裁、研究所所长）提出的"四位一体"研究体系，核心是把信息源分成四类：
1. **专家访谈**（一手）
2. **草根调研/产业调研**（一手）
3. **公司公告/财报/招股书**（二手但权威）
4. **产业链数据/行业数据库**（二手但可穿透）

关键洞察：**"四位一体"不是"四者缺一不可"，而是"通过多种信息源交叉验证同一件事"**。当一手数据缺失时，顶级分析师会用**后两类（公告+产业链数据）的极致化**来补偿，并通过**数据三角验证**建立可信度。

换句话说：一手数据解决的是"知道别人不知道的"，但二手数据做到极致，能解决"别人没想清楚的"——后者同样是信息增量。

## 二、无一手数据时的 7 大顶级打法

### 打法 1：数据三角验证（Triangulation）

**原理**：单一数据源不可信，但三个独立数据源指向同一结论，可信度大幅提升。

**顶级做法**（麦肯锡/高盛常用）：
- 同一个市场规模，用三种方法算，互相印证：
  - **自上而下**：全球总量 × 中国占比 × 油位细分占比
  - **自下而上**：加油站数量 × 单站液位仪价值 × 替换周期
  - **对标外推**：美国/日本渗透率 × 中国加油站数量
- 三个数字如果落在同一区间（±20%），就敢写；如果矛盾，说明某层假设错了，**去找错在哪**——这个"找错"过程本身就是深度

**对油位报告的落地**：
- 全球 50 亿美元（自上而下：工业传感器市场 × 物位占比）
- 中国 172 亿元（自下而上：10 万座加油站 × 单站液位仪 5000 元 × 替换周期）
- 三者交叉验证，而不是堆一个孤零零的数字

**关键**：三角验证的**过程**（为什么取这三个数、假设是什么、哪个环节最不确定）写进报告，就是"深度"。读者看到的是"这个数字不是拍脑袋，是三层验证过的"。

---

### 打法 2：供应链穿透拆解（Supply Chain Teardown）

**原理**：不研究"市场有多大"，而是拆"一个产品从原材料到终端，每一层谁在赚钱、谁的议价权大"。

**顶级做法**（瑞银/大摩硬件团队常用）：
- 拆解一个加油站液位仪的 BOM（物料清单）：磁致伸缩丝、ASIC、外壳、密封件、防爆认证费用
- 每一层标注：成本占比、供应商是谁、毛利率、议价权
- 得出"利润池到底在哪层"的**可验证**结论

**对油位报告的落地**：
- 液位仪 3000-8000 元，拆成 BOM：磁致伸缩丝（成本占比 X%，毛利 50-65%）、电子件、结构件
- 中游制造为什么净利率只有 8-12%？因为核心材料被上游卡住 + 认证成本高
- 这个拆解让"利润池在上游材料和售后运维"不再是一句套话，而是有 BOM 支撑的结构性判断

**关键**：供应链拆解是**纯二手可做**的（BOM 可以从招股书、专利、供应商报价单、行业报告拼出来），不需要一手调研，但产出的是"别人没拆过"的深度。

---

### 打法 3：政策-数据-标的传导链（Policy-to-Ticker）

**原理**：不写"政策利好行业"，而是**把政策条文翻译成可追踪的量化指标**，再传导到具体受益标的。

**顶级做法**（中金/国君政策研究组常用）：
- 政策原文 → 拆解出"执行率/招标量/补贴金额"等可量化指标
- 建立传导链：政策发布 → 地方执行 → 招标 → 中标 → 企业订单 → 财报
- 每个环节给"现在在哪一步、下一步看什么信号"

**对油位报告的落地**：
- 2019《加油站防渗改造》政策 → 执行率 62%（如何算出：完成改造站数/总站数，可从环保厅公开数据统计）
- 传导链：政策（已发）→ 地方执行（62%，滞后）→ 招标（2026H2 放量）→ 中标名单（可查集采平台）→ 企业订单（柯力/华虹）
- Bold Call 不再是"政策利好"，而是"执行率从 62% 提到 85% 是招标放量的触发线，跟踪 Q3 招标数据验证"

**关键**：政策传导链的价值在于**给出了"现在观察什么、什么信号出现说明判断对"**——这是有信息增量的，因为大部分报告只写"政策利好"四个字。

---

### 打法 4：对标国/历史类比（Analogous Market）

**原理**：中国市场数据不全时，用成熟市场（美国/日本/欧洲）的历史轨迹做对标，推演中国未来。

**顶级做法**（麦肯锡 TAM 测算常用）：
- 美国加油站液位仪渗透率 90%+，中国 60%——差值就是空间
- 美国防渗改造政策（EPA 2005 年要求）→ 3 年内改造完成 → 中国 2019 政策滞后 14 年，正处同一阶段
- 用美国当年的"改造节奏 × 单价 × 加油站数量"推演中国的"替换高峰时间点"

**对油位报告的落地**：
- 美国 EPA 防渗改造（2005）后，液位仪替换高峰在第 2-3 年——类比中国（2019 政策 + 疫情延期）→ 2026H2 高峰
- 这个类比给了 Bold Call 时间窗口一个**可验证的历史锚**，而非拍脑袋

**关键**：对标国打法把"中国增速 8-10%"从凭空猜测变成"美国当年 8-12%，中国滞后复制"，可信度完全不同。

---

### 打法 5：招投标/集采数据穿透（Procurement Mining）

**原理**：这是**无需一手访谈、但最接近一手**的公开数据——政府采购/企业集采的招标公告、中标公示，全部公开可查。

**顶级做法**（中金/天风产业组常用）：
- 爬取加油站液位仪、危化品液位计的招标公告（中国政府采购网、地方公共资源交易平台、中石化电子招标平台）
- 统计：招标量环比、中标均价、中标厂商分布、中标金额
- 得出"真实价格趋势、真实竞争格局、真实需求节奏"

**对油位报告的落地**：
- "2026Q2 加油站液位仪招标量环比 +18%，中标均价 4200 元，川仪/正星/柯力华虹体系中标占比 35%"
- 这个数据比任何二手研报都硬——它是**真实的钱**在流动的记录

**关键**：招标数据是"公开的一手数据"——不需要访谈，只需要爬虫+整理。这是无一手调研状态下**最应该优先建立**的数据能力。

---

### 打法 6：产业链价格与产能跟踪（Supply-side Signal）

**原理**：不预测需求，而是跟踪供给端的价格、库存、产能利用率——这些是**高频、公开、硬**的信号。

**顶级做法**（大摩/美银周期组常用）：
- 磁致伸缩丝（上游材料）价格指数
- 行业产能利用率、交货周期（VEGA/Siemens 等龙头财报里的 backlog）
- 中国仪器仪表行业协会月度出货量

**对油位报告的落地**：
- "磁致伸缩丝价格 2026H1 环比 +3%，反映需求回暖"
- "行业产能利用率 94%（2026E），接近满产 → 价格压力缓解，中游毛利修复"
- 把"毛利率有望修复"从推测变成"产能利用率 94% + 交货周期延长 = 量价齐升的先行信号"

**关键**：供给端信号是**可验证的硬数据**，不需要访谈，让"行业景气度"判断有实锤。

---

### 打法 7：反向工程财务勾稽（Financial Reverse-engineering）

**原理**：从上市公司财报倒推行业结构——用"行业老大"的报表反推行业总量、增速、利润率。

**顶级做法**（Berenberg 等精品投行常用）：
- 川仪股份（本土龙头）财报里"液位仪表"分部收入 → 反推其在行业中的份额 → 反推行业总量
- 柯力传感"物位传感"分部 → 反推增速
- 多个公司分部收入加总，交叉验证行业规模

**对油位报告的落地**：
- 川仪财报液位仪表收入 5 亿（若有）→ 假设其份额 30% → 行业规模 17 亿
- 与"自上而下 172 亿"比对——若差异大，说明口径不同（窄口径 vs 全口径），**这个"找差异"的过程就是洞察**
- 净利率勾稽：柯力净利率 25% vs 行业中游 8-12% → 说明柯力的平台化溢价来自品类组合，而非油位单品

**关键**：财务反推是**纯公开数据**的深度处理，产出"用上市公司报表反推的行业真相"。

## 三、组合使用：一份无一手数据的深度报告怎么搭

以油位报告为例，7 大打法组合成"深度矩阵"：

| 章节 | 打法组合 | 产出什么 |
|------|---------|---------|
| 市场规模 | 打法1三角验证 + 打法4对标国 | 全球50亿（三法交叉）/中国172亿（自下而上） |
| 竞争格局 | 打法5招标穿透 + 打法7财务反推 | 真实中标格局 + 龙头报表反推份额 |
| 利润池 | 打法2供应链拆解 | BOM 级利润池分布（可验证） |
| 政策驱动 | 打法3政策传导链 | 执行率62%→85%触发线 + 可追踪指标 |
| 行业景气 | 打法6供给端信号 | 产能利用率94% + 磁致伸缩丝价格 |
| Bold Call | 打法3+4 | 时间窗口有历史锚 + 触发线可验证 |

**核心**：每一章都不是"一个结论"，而是"一个结论 + 怎么算出来的 + 看什么信号验证"。这就是"深度"的定义——**不是信息多，而是信息之间的因果关系和验证路径清晰**。

## 四、落地到 2hao 系统（工程方案）

### 4.1 数据层：新增 4 个"公开数据穿透"采集器

| 采集器 | 数据源 | 产出 |
|--------|--------|------|
| `core/procurement_miner.py` | 中国政府采购网/公共资源交易平台/中石化电子招标平台 | 招标量/中标价/中标厂商（打法5） |
| `core/supply_chain_bom.py` | 招股书/专利/供应商报价单 | BOM 级成本结构（打法2） |
| `core/analogous_market.py` | 美国 EPA/欧盟法规/日本经产省数据 | 对标国历史轨迹（打法4） |
| `core/financial_reverse.py` | 上市公司分部报告 | 行业规模/份额反推（打法7） |

### 4.2 分析层：新增 3 个"深度分析"模块

| 模块 | 功能 |
|------|------|
| `core/triangulation.py` | 三角验证：同一指标三法计算，输出交叉区间（打法1） |
| `core/policy_chain.py` | 政策传导链：政策→执行率→招标→订单→财报（打法3） |
| `core/supply_signal.py` | 供给端信号：产能利用率/价格指数/交货周期（打法6） |

### 4.3 Gate 层：新增"深度质量"检查

| 检查 | 检测什么 |
|------|---------|
| `_check_triangulation` | 关键市场规模指标是否三法交叉验证（≥2法） |
| `_check_policy_chain` | 政策结论是否有"执行率/招标量"等可追踪指标 |
| `_check_bom_depth` | 利润池结论是否有 BOM 级拆解支撑 |
| `_check_analogous` | 中国增速预测是否有对标国历史锚 |
| `_check_procurement` | 竞争格局结论是否有招标数据支撑 |

### 4.4 报告层：新增"深度方法论"注入

- section_writer 注入：每个关键判断要标注"用什么方法得到的"（三角验证/供应链拆解/对标国/招标穿透/财务反推）
- 报告显式写出"数据方法"小节：本节市场规模 = 自上而下 + 自下而上 + 对标国，三者交叉区间 X-Y 亿美元

## 五、为什么这些打法能替代（部分）一手调研

| 维度 | 一手调研解决 | 二手极致化解决 |
|------|------------|---------------|
| 独家信息 | 知道别人不知道的 | — |
| 深度理解 | 访谈中的 nuance | 数据交叉验证出的结构 |
| 可信度 | 专家背书 | 三角验证 + 可追踪指标 |
| 时效 | 最新动态 | 招标/价格高频数据 |
| 验证 | 一手确认 | 传导链 + 触发线 |

**核心洞察**：一手调研提供"信息优势"，二手极致化提供"分析优势"。两者都构成信息增量。在没有一手数据的现实约束下，**把分析优势做到极致，是唯一的、也是正确的前进方向**——这正是赵晓光说的"研究 2.0：不是信息多少，而是把信息加工成判断的能力"。

## 六、给 Marvis 的执行建议（按优先级）

1. **P0（1-2天）**：先建 `procurement_miner.py`（打法5）——招标数据是"公开的一手数据"，性价比最高，能立刻让油位报告有硬数据
2. **P0（1-2天）**：建 `triangulation.py`（打法1）——让市场规模不再孤零零，而是三法交叉
3. **P1（1周）**：建 `policy_chain.py`（打法3）+ `analogous_market.py`（打法4）——让政策驱动和增速预测有锚
4. **P1（1周）**：建 `supply_chain_bom.py`（打法2）+ `financial_reverse.py`（打法7）——让利润池和格局有结构
5. **持续**：Gate 加"深度质量"检查，从"查格式"升级到"查有没有用这些打法"

**验收标准**：油位报告重跑后，应看到"全球市场规模 = 三角验证区间 X-Y""政策传导链含执行率/招标量触发线""竞争格局含招标数据支撑""利润池含 BOM 拆解"——每一章都有方法、有验证、有可追踪信号，而不是孤零零的结论+套话。
