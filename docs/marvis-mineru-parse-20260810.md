## 一、为什么需要你执行（环境边界）

当前 Claude 沙箱：无 GPU、无 Ollama、无法装本地 MinerU（模块冲突）。你在用户 Windows 机，可访问真实文件系统，可装本地引擎，质量最高。

## 二、任务 1：安装本地 MinerU 引擎

```powershell
# 在 2hao-analyst 项目根目录执行
cd D:\2hao-analyst
python -m pip install mineru --break-system-packages   # 本地引擎
mineru --version                                       # 验证
```

> ⚠️ 若之前装过 `mineru-open-sdk`（云 SDK），两者**模块名冲突**（都叫 `mineru`）：
> 本地引擎优先，云 CLI 改走 `uvx mineru-open-mcp`（不冲突）。
> 首次运行会下载模型 ~3GB，请确保磁盘空间（建议 10GB+）。

**验证**：`mineru --version` 有输出即成功。
