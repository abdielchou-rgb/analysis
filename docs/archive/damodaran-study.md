## 一、核心方法论：Narrative + Numbers

达摩达兰估值模型的核心是「用叙事驱动数字」，与投行标准模型（数字驱动）形成互补。

### Uber模型的决策链

1. 选择潜在市场 (A1-A4)
   - A1: Urban car service / A2: +Rental / A3: +Logistics / A4: +Mobility
2. 选择对市场增长的效应 (B1-B4)
   - B1: 不改变 / B2: +25% / B3: +50% / B4: 翻倍
3. 选择网络效应强度 (C1-C5)
   - C1: 无(5%市占) / C2: 弱本地(10%) / C3: 强本地(15%) / C4: 弱全球(25%) / C5: 强全球(40%)
4. 选择竞争优势 (D1-D4) -> 决定抽成率
5. 再投资强度 -> Sales/Capital Ratio
6. 风险 -> WACC（按行业百分位）
7. 失败概率 -> 调整最终估值

### 核心公式链
TAM x 市场增速 = 未来市场规模
未来市场规模 x 市场份额 = 总交易额
总交易额 x 抽成率 = 营收
营收 x 利润率 = 营业利润
营业利润 x (1-t) + 再投资调整 = FCFF
FCFF折现 + 终值 = 运营资产价值
运营资产价值 x (1-失败概率) = 调整后价值

## 二、对中国A股估值的三个关键注入

### 1. 失败概率调整
对Uber设了10%失败概率。对于亏损公司应有5-15%的调整。
IB标准模型中通常缺失此项。

### 2. 中国国家风险溢价
成熟市场ERP = 5.96%（2019年基准，需更新）
中国评级 A1 -> 违约利差 0.79%
中国CRP = 0.98%
中国总ERP = 6.94%

### 3. 市场驱动的营收预测
芯联集成这类成长型公司：
先估算TAM（全球SiC市场、AI电源芯片市场）
再估算市场份额（基于产能占比）
最后估算营收
