# 投喂基准报告操作指南

## 一、要求

### 来源机构（任一即可）

中金 / 中信 / 高盛 / 摩根士丹利 / 麦肯锡 / BCG / 学术论文

### 报告类型（任一即可）

- 公司深度分析（15-30 页）
- 行业深度研究（20-40 页）
- 业绩点评 / 财报点评（5-8 页）
- 策略报告（10-15 页）

### 硬性条件

| 条件 | 要求 |
|------|------|
| 篇幅 | ≥ 5 页正文（不含封面、目录、免责声明页） |
| 时效 | 2024-2026 年 |
| 语言 | 中文（高盛等外行可用中译版或英文，优先中文） |
| 格式 | PDF，文字层可复制（非纯扫描图片） |
| 完整度 | 正文完整，图表保留 |

## 二、下载后三步处理

### ① 建目录

在 `D:\BaiduNetdiskDownload\` 下新建：

```
D:\BaiduNetdiskDownload\投喂基准报告\
├── cicc\               ← 中金
├── goldman_sachs\      ← 高盛
├── citic\              ← 中信
├── morgan_stanley\     ← 摩根士丹利
├── mckinsey\           ← 麦肯锡
├── bcg\                ← 波士顿咨询
└── academic\           ← 学术论文
```

### ② 命名

```
[机构缩写]_[关键词]_[年月].pdf
```

举例：

```
中金_宁德时代深度_202505.pdf
高盛_腾讯业绩点评_202603.pdf
中信_AIGC行业深度_202507.pdf
摩根士丹利_茅台首次覆盖_202504.pdf
```

### ③ 检查

快速打开，确认三条：

- [ ] 正文页数 ≥ 5（封面/目录/免责声明不计）
- [ ] 是完整报告，不是摘要/简报
- [ ] 文字可选中复制（不是纯图片扫描）

## 三、数量建议

**先投 15-20 份。** 不要求覆盖全部风格。

推荐分布：

## 五、常见问题

**Q：找到的报告有些页图片多文字少，能投吗？**

A：可以，但优先选文字层完整的。纯扫描件我可以用 OCR 提取但质量下降，不建议超过总量的 20%。

**Q：高盛的报告只有英文版，要投吗？**

A：可以投。我可以处理中英文混合。但中文风格的校准需要中文报告。

**Q：报告中带目标价和评级，有用吗？**

A：非常有用。这是 L3-1 时序验证（预测回头看）的关键数据。

**Q：有些报告标注了"禁止转载"，能投吗？**

A：用于内部系统回测对标，不公开发布，不违反版权。如果你不方便，跳过即可。

**Q：找到 5 份就投还是攒够 20 份再投？**

A：有多少投多少。5 份够首轮验证跑通管线。
