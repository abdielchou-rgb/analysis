## 一、核心理念：三层同心圆（Onion Architecture）

`
外层：叙事弧（Persuasion Architecture）
  让报告有说服力——Hook → Context → Analysis → Counter → Conclusion → CTA
  
  中层：SAC 维度（方法论框架）
  让报告有深度——12 维 MECE + Serenity 9 步
  
  内层：数据证据链（数据基座）
  让报告可信——血统追溯 + 置信度评分 + 多源交叉验证
`

当前 V51.5 状态：
- 内层（数据）：65/100 —— 有 130 家估值模型 + 投行数据，但管线不完整
- 中层（SAC）：90/100 —— 方法论框架全球领先
- 外层（叙事）：40/100 —— 缺乏说服力架构设计

## 三、系统升级工程（7大模块）

### Track A: 说服力架构（Persuasion Architecture）
**目标**：每份报告有 Hook → Build → Convince → Act 的叙事弧线

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| A1: Hook Generator（首段抓人） | 1天 | P0 |
| A2: CTA Generator（结语行动项） | 0.5天 | P1 |
| A3: 说服力检查器（完整性验证） | 0.5天 | P1 |

### Track B: 图表优先设计（Chart-First Design）
**目标**：每份报告至少 5-8 张专业图表，图表驱动叙事

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| B1: ChartPlanner（自动规划图表类型和位置） | 2天 | P0 |
| B2: 图表类型扩展（增加散点图、热力图、树图） | 2天 | P1 |
| B3: 图表判断标注系统（标注关键数据点） | 3天 | P0 |
| B4: 机构配色系统（已基本完成） | 0天 | Done |

### Track C: Report Blueprint（报告蓝图）
**目标**：每种报告类型有确定的篇章结构模板

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| C1: Industry Deep Blueprint（30-50页） | 1天 | P0 |
| C2: Listed Company Blueprint（20-30页） | 1天 | P0 |
| C3: Unlisted Company Blueprint（15-25页） | 1天 | P1 |
| C4: Executive Summary Blueprint（1-2页） | 0.5天 | P0 |

### Track D: Consensus Dialogue（共识对话）
**目标**：每份报告有"市场共识 vs 我们判断"的对比

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| D1: 共识数据对接 | 1天 | P0 |
| D2: Consensus vs Our View对比表 | 1天 | P0 |
| D3: Where We Differ章节模板 | 0.5天 | P1 |
| D4: What Would Change Our Mind | 0.5天 | P1 |

### Track E: 风格DNA深化
**目标**：7种机构风格可感知差异化

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| E1: 风格DNA配置增强 | 2天 | P1 |
| E2: 风格差异化检测工具 | 1天 | P2 |

### Track F: 数据血统 + 置信度系统
**目标**：每个数据点可追溯、有置信度标注

| 子模块 | 工作量 | 优先级 |
|--------|-------|--------|
| F1: 数据血统追踪器 | 2天 | P0 |
| F2: 置信度评分生成 | 1天 | P0 |
| F3: 数据源标准化 | 1天 | P1 |

### Track G: 标准化附录
**目标**：每份报告附方法论说明+财务摘要+风险因素+评级体系

| 子模块 | 工作量 | 优先级 |

每份报告必须通过以下门禁：

| 门禁项 | 合格线 | 检测方式 |
