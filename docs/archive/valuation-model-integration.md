## 二、标准投行估值模型管线

历史财报 -> 三表重构 -> 收入驱动力拆解 -> WACC -> DCF -> 可比 -> 敏感性 -> 结论

### 1. 三表重构
- 资产负债表：经营资产/非核心资产分类重构
- 利润表：EBIAT/NOPLAT口径调整
- 现金流量表：直接法转间接法
- OWC经营性营运资金单独计算

### 2. WACC
- Re = Rf + ERP x Beta
- Rd = 短债利率x占比 + 长债利率x占比 + 债券利率x占比
- WACC = We x Re + Wd x Rd x (1-t)

### 3. DCF
- FCFF = EBITx(1-t) + D&A - CapEx - DeltaOWC
- 两阶段：预测期 + 终值
- EV -> 减净债务 -> 股权价值 -> 每股价格

### 4. 可比分析
- PE/PB/PS/EV/EBITDA/EV/EBIT 六组倍数
- 同业折溢价分析

### 5. 敏感性矩阵
- 5x5矩阵，核心变量变化对目标价的影响

## 三、分工
