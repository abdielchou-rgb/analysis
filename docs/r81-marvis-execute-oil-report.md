## 二、执行模式（训练模式双LLM）

### 命令
```bash
cd D:\2hao-analyst
# 1. 启动 Marvis responder（train 模式需要）
python scripts/agent_llm_responder.py watch
# 2. 训练模式：Marvis 起草 + DeepSeek 校验
python scripts/run_reports.py "油位传感器" --type industry_deep \
  --mode train --workers 1 \
  --enrich-file data/keli_oil_enrich_20260805.json
```

### LLM 分工
| 阶段 | LLM | 作用 |
|------|-----|------|
| 初稿 | Marvis（agent_provider） | 用传感器历史报告训练记忆起草 |
| 校验 | DeepSeek（对侧provider） | 独立审查，发现 Marvis 盲点 |
| 终稿 | DeepSeek | 全局编辑统一口径/删套话 |

### 配置
- `LLM_PROVIDER=agent_provider`（train 模式自动）
- `HAS_AGENT=1`
- DeepSeek key 必须存在（.env 已有）

## 五、框架→章节映射（必须逐章用足框架资产）

| 章节 | 必须用的框架 | 产出什么 |
|------|-------------|---------|
| 1.2 竞争真相 | **competition_demystified** | 柯力vs川仪竞争优势本质（成本/客户/规模）对比 |
| 1.3 供应链卡脖子 | **bottleneck_engine** | 磁致伸缩丝卡在哪环节、痛点多深、怎么解 |
| 1.4 政策节奏 | **signal_chain + signal_noise** | 先行（招标量）/同步（执行率）/滞后（财报）+ 信号vs噪声 |
| 2.1 技术栈适配 | **moat_analysis** | 柯力在油位的护城河：转换成本/成本优势评估 |
| 3.1 生产主体三选 | **strategy_engine** | 自制vs代工vs华虹的单位经济分析 |
| 3.2 华虹收购定价 | **ma_valuation** | 1.22亿买45%值不值（EV/EBITDA对标） |
| 4.1 财务测算 | **value_driver** | ROIC vs WACC，这笔投入创造价值吗 |
| 4.2 目标价 | **expectations_investing** | 60元隐含什么预期，市场是否已定价油位 |
| 4.4 敏感性 | **scenario_analysis** | bull/base/bear 三情景财务影响 |
| 5.1 商誉风险 | **accounting_for_value** | 华虹商誉减值会计视角 |

**新增 3 章（用足 SAC 维度）：**
- 1.5 非上市威胁（unlisted_players）——河南长润等非上市玩家对柯力的威胁
- 1.6 行业整合趋势（industry_consolidation）——并购/整合将重塑格局，柯力该不该参与
- 2.4 全球对标（global_competition）——柯力 vs VEGA/Siemens 全球差距与机会

## 六、必须体现的能力（R81 已接线）

1. **全球视角**：注入 fig_global_leaders（VEGA/Siemens/E+H/Emerson/Yokogawa）+ 海外收入 —— 报告必须写"全球龙头对标/海外竞争格局"，不能只写中国
2. **行业框架**：护城河/周期/预期投资框架带具体分析步骤 —— 报告必须看到"用XX框架分析，得出XX结论"
3. **三角验证**：市场规模三法交叉
4. **反方三段式**：情境→机制→杀伤力，禁止"概率XX%"空壳
5. **数据纪律**：无依据数字不写改留白
6. **诚实留白**：数据不足声明留白，不硬凑
