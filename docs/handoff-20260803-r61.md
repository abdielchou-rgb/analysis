## 四、关键机制（必须理解）

### 1. 三类维度支撑模型

```
工具支撑: elasticity/signal_chain/moat/life_cycle/multi_model → compute_engine._run_tool_modules
数据底座: market_size/capital_market/industry_chain 等 → data_basement loader
判断维度: bold_call/core_hypothesis/falsification → 基于已有数据做判断（非 LLM 无中生有）
```

### 2. 证据链三跳

```
工具 → compute（R59）✅ / compute → section_writer（V83）✅ / section_writer → 正文（Gate evidence_chain）✅
```

### 3. 数据采集双模式

```
训练模式: 生成=Marvis（agent_provider）→ 校验=DeepSeek
性能模式: 生成=DeepSeek → 校验=Marvis
（评估器/生成器解耦，防同源偏见——FP2a v3.2）
```

### 4. 预测验证闭环

```
forward_picks.csv → import_forward_picks.py → ForwardPicksDB（24 条）
→ validate_predictions.py 到期验证 → 校准置信度
```
