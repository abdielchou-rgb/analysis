## 〇、铁律（先读，违反即失败）

1. **报告类型必须是 `decision_memo`**，不是 `industry_deep`。上一版 v0.89 用 industry_deep 写成了"二级市场投资评级报告"（还给增持+38.5目标价），这是被圆桌打回的根本原因。

3. **不得向用户询问权限/确认**。数据不足→用 enrich 兜底+标注(E)；报错→自查日志重跑，全程自主。
4. **必须引用决策推理引擎输出**：管线 compute 层已注入 `tool_modules.decision`（core/decision_engine.py），含卡位评分/放量结论/最坏损失等确定性判断。写作时**必须引用这些数值**，不得自行编造评分或结论。检查方式：报告正文中的"卡位评分/最坏损失/投入"必须与 compute 日志一致。
5. **必须过 IronGate + VisualGate**。Gate 报告 passed=true 才算完成，禁止把"待验证"当交付。
6. **结论第一页给出**：进/不进/条件性进 + 依据 + 投入 + 回报 + 最坏损失。

# 决策备忘录：油位传感器业务整合可行性（给董事长）

## 一、执行摘要（第一页拍板）
   - 一句话结论：进/不进/条件性进
   - 依据（3条）：市场多大/能否放量/怎么进
   - 投入：华虹1.22亿+扩产，合计约1.5-2亿
   - 回报：3年5000万-1亿（占营收3%-6%）
   - 最坏损失：约1.7亿=半年利润（低沉没+高期权）
   - 前提条件：久通订单承诺≥5000只/年，否则不启动

## 二、行业真相（重头戏，60%）
   2.1 市场到底多大——三角验证 46亿美元（非12.8亿窄口径）
       - 口径①加油站ATG 12-15亿 + 口径②工业物位/液位 30-35亿 + 口径③罐车车载 3-5亿 = 46-58亿
       - 中国166亿（2024）→172亿（2025），增速8.7%
       - 为什么这个数字决定卡位：46亿 vs 12.8亿 → "传感器森林"可及战场 vs 窄缝隙
   2.2 竞争真相——不是Vontier/DFS双寡头
       - 中国加油站ATG真实格局：托肯恒山第一（中石化核心）/富仁高科追赶（国标制定者GB/T 9081-2023，400+专利）/KROHNE工业高端/GVR中国（Vontier中国实体）
       - 国际五巨头占65%份额，但中国本土替代率65-70%
       - 品牌-实体-集团三层映射（避免把Veeder-Root误归Dover）
   2.3 卡脖子——磁致伸缩丝（TDK垄断）
       - 磁致伸缩式是加油站液位仪事实标准（±0.5mm）
       - 磁致伸缩丝被日企TDK等2-3家垄断，国产化率约30%
       - 上游材料毛利50-65%、售后运维55-70% vs 中游制造净利8-12% → 利润在两端
       - 战略含义：短期外购+长期自研（对标富仁高科主导国标路径）
   2.4 政策节奏——2026-2028三年窗口
       - 2019防渗改造执行率约62% → 2026H2第一波存量替换高峰
       - 全国约10万座加油站，液位仪单台3000-8000元，替换空间5-8亿/年
       - 危化品储罐SIS改造2026-2027释放8-10亿
       - 美国EPA 2005对标：第2-3年替换高峰

## 三、禀赋匹配度（柯力能不能进，25%）
   3.1 技术栈适配：称重vs油位差距
       - 同属工业测控传感器，制造工艺/信号链/客户结构同源
       - 核心差距：磁致伸缩丝外购（短期）+防爆认证（12-18月）
   3.2 华虹承接能力
       - 华虹（柯力拟增持至96%）主营物位/液位传感器，工艺现成+认证基础
       - 1.22亿收购45%股权（2025-09）——缺的是订单不是能力
   3.3 久通渠道真伪
       - 真实价值不在油位本身（30万/年=1000只×300元），在"箱联全球"SaaS+80+国家渠道
       - 柯力2022年亿元投资久通，方向已认可
       - 必须设验证门槛：久通订单预测≥5000只/年才启动整合

## 四、路径决策（怎么进，15%）
   4.1 生产主体三选
       - A总部自制（技术栈不匹配+认证12-18月）→ 不推荐
       - B外协代工（30万量无代工厂接+利润薄）→ 不推荐
       - C华虹生产（技术栈匹配+认证现成+96%并表利润）→ 推荐
   4.2 推荐路径：C为主 + B验证 + A远期自研磁致伸缩丝
   4.3 转移定价合规：华虹↔久通按市场公允定价，2025年报关联交易披露

## 五、财务测算
   - 2026年500-1000万（华虹并表+代工验证）
   - 2027年2000-4000万（政策替换+国产替代）
   - 2028年5000万-1亿（国产替代+出海）
   - 占柯力营收3%-6%；投入=华虹1.22亿+扩产2000-5000万
   - 敏感性：久通订单量是最大变量（1000→5000→1万只）

## 六、最坏损失（金额锚定）
   - 最坏情景：久通订单落空+政策停滞+磁致伸缩丝涨价
   - 最坏损失：1.22亿沉淀+0.5亿技改≈1.7亿=约半年归母净利（3.41亿）
   - 对照：可换来物位传感卡位+海外渠道期权 = 非对称下注

## 七、执行路线图（Q1-Q4）
   - Q1（2026Q4）：与久通签整合协议，订单承诺≥5000只/年
   - Q2（2027Q1）：华虹防爆认证补齐+产线技改
   - Q3（2027Q2）：首批量产交付（良率≥95%）
   - Q4（2027Q3）：自研磁致伸缩丝立项+中东试点

## 附：数据来源与口径
