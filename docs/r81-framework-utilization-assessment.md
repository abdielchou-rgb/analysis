> 问题：r81-marvis-execute-oil-report.md 是否充分利用了2hao的行业分析框架？

## 二、执行指令实际用到的 vs 应该用到的

### 指令明确用到的（约 4-5 个）
| 框架 | 体现位置 |
|------|---------|
| triangulation 三角验证 | 市场规模 |
| 政策传导链 | 1.4 政策节奏 |
| 护城河（隐含） | 2.1 技术栈适配 |
| 财务反推 | 4 财务测算 |

### 指令应该用但没明确的（约 8-10 个）——真正的浪费
| 框架 | 应该用在报告哪里 | 漏掉的影响 |
|------|-----------------|-----------|
| **bottleneck_engine** | 1.3 磁致伸缩丝卡脖子——这是最关键的！ | 供应链卡点分析没有专门框架，会写成"存在风险"而非"卡在哪、多痛、怎么解" |
| **ma_valuation** | 3.2 华虹收购定价——1.22亿买45%值不值 | 并购估值没有框架，董事长的钱没算清 |
| **strategy_engine** | 3.1 生产主体三选——单位经济分析 | 自制vs代工vs华虹的经济性比较缺方法论 |
| **competition_demystified** | 1.2 竞争真相 | 竞争优势三本质（成本/客户/规模）没用来分析柯力vs川仪 |
| **scenario_analysis** | 4.4 敏感性/5 风险 | 多情景（bull/base/bear）没做，风险上限拍脑袋 |
| **expectations_investing** | 4.2 柯力60元目标价 | 没有反推"60元隐含什么预期、市场是否已定价油位" |
| **value_driver** | 4.1 财务测算 | ROIC vs WACC 没算，不知道这笔投入是否创造价值 |
| **signal_noise** | 1.4 政策信号辨别 | 没有区分"真信号vs噪声"，政策执行率可能被误判 |
| **accounting_for_value** | 5.1 华虹商誉 | 商誉减值没从会计角度评估 |
| **signal_chain** | 1.4 政策传导链 | 先行/同步/滞后指标没结构化 |

### SAC 维度可能漏掉的
- **global_competition**（全球竞争）——新指令提到全球视角，但没明确用 global_competition 维度
- **unlisted_players**（非上市威胁）——油位行业非上市玩家（河南长润等）威胁没分析
- **industry_consolidation**（行业整合）——并购/整合趋势没分析

## 三、为什么框架"存在但没用上"

1. **框架注入是自动的，但指令没指明"用哪个框架分析哪章"**——Marvis 执行时 LLM 按 prompt 注入的框架名写，但指令没把"瓶颈引擎→磁致伸缩丝卡脖子"这种映射显式告诉它
2. **框架注入只取前4个**（`frameworks[:4]`），油位/传感器行业可能匹配到的瓶颈引擎/并购框架不在前4
3. **R81 刚接的行业动态匹配**只提升了匹配优先级，但 LLM 是否真的"用"取决于 prompt 和指令
4. **执行指令是给 Marvis 的，不是给 LLM 的**——Marvis 要主动把框架映射到章节，但指令没列映射表

## 四、改进：把框架资产"全量利用"到油位报告

### 框架→章节映射表（补充到执行指令）

| 章节 | 必须用哪个框架 | 产出什么 |
|------|---------------|---------|
| 1.2 竞争真相 | **competition_demystified** | 柯力vs川仪的竞争优势本质（成本/客户/规模）对比 |
| 1.3 供应链卡脖子 | **bottleneck_engine** | 磁致伸缩丝卡在哪环节、痛点多深、怎么解（三问） |
| 1.4 政策节奏 | **signal_chain + signal_noise** | 先行指标（招标量）/同步（执行率）/滞后（财报）+ 信号vs噪声辨别 |
| 2.1 技术栈适配 | **moat_analysis** | 柯力在油位的护城河：转换成本/成本优势评估 |
| 3.1 生产主体三选 | **strategy_engine** | 单位经济分析：自制vs代工vs华虹的单位成本/毛利 |
| 3.2 华虹收购定价 | **ma_valuation** | 1.22亿买45%值不值（EV/EBITDA对标） |
| 4.1 财务测算 | **value_driver** | ROIC vs WACC，判断这笔投入创造价值吗 |
| 4.2 目标价 | **expectations_investing** | 60元隐含什么预期，市场是否已定价油位 |
| 4.4 敏感性 | **scenario_analysis** | bull/base/bear 三情景财务影响 |
| 5.1 商誉风险 | **accounting_for_value** | 华虹商誉减值会计视角 |
| 6 路线图 | **signal_chain** | 里程碑按先行/同步/滞后信号设 |

### 新增章节（用足 SAC 维度）
| 章节 | SAC维度 | 内容 |
|------|---------|------|
| 1.5 非上市威胁 | unlisted_players | 河南长润等非上市玩家对柯力的威胁 |
| 1.6 行业整合趋势 | industry_consolidation | 并购/整合将重塑格局，柯力该不该参与 |
| 2.4 全球对标 | global_competition | 柯力 vs VEGA/Siemens 全球差距与机会 |

### 技术改动（让框架真被用上）
1. **框架注入从前4扩到前6-8**，且瓶颈引擎/并购估值优先
2. **prompt 加"每个框架必须给出具体应用结论"**——"用护城河框架分析柯力，得出：转换成本中等，成本优势强"
3. **执行指令加框架→章节映射表**（如上），Marvis 明确知道每章用什么框架

## 五、一句话总结

**执行指令利用了约 4-5 个框架，但 2hao 有 19 个可用框架 + 26 个 SAC 维度。最该用的瓶颈引擎（磁致伸缩丝卡脖子）、并购估值（华虹定价）、情景分析（敏感性）、战略引擎（生产主体）、竞争优势（竞争真相）都没被指令明确映射。**

**改进**：①执行指令补"框架→章节"映射表 ②框架注入扩到前6-8且关键框架优先 ③prompt 强制"每个框架给出具体应用结论" ④补 unlisted_players/industry_consolidation/global_competition 三章。

这样油位报告才能从"结构正确的模板"变成"用满框架资产的深度分析"——董事长看到的不是泛泛的"竞争格局"，而是"用竞争优势三本质分析的柯力vs川仪对比""用瓶颈引擎拆解的磁致伸缩丝卡脖子三问"。
