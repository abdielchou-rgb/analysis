## 一、升级内容

在写作 prompt 中新增两段强制指令：

### 1. [竞争真相强制]

**原文注入**：
```
## [竞争真相强制] 竞争格局分析必须基于具体玩家名单（来自【可用数据】的fig_players/竞争数据），
逐家评估：威胁等级、客户结构、技术壁垒、集团归属。禁止泛泛"竞争激烈/格局清晰"，必须点名：
如'托肯恒山是中石化核心供应商(Dover体系)'。品牌与实体要分清（如Tokheim品牌 vs 托肯恒山中国实体）。
```

**作用**：
- 竞争分析从"泛泛而谈"升级为"基于玩家名单逐家点名"
- 利用 R69 审计数据（14家玩家/必补级7家/品牌映射断裂）
- 品牌与实体分离（Tokheim品牌 vs 托肯恒山实体）

### 2. [框架应用结论强制]

**原文注入**：
```
## [框架应用结论强制] 每个注入的分析框架必须给出针对本报告标的具体应用结论，
格式：'用XX框架分析本标的下：具体结论X、Y、Z'。禁止只提框架名不分析。
```

**作用**：
- 框架从"名字注入"升级为"必须应用"
- 解决"框架存在但 LLM 不用"的根因
- 格式明确："用XX框架 → 结论X、Y、Z"

## 二、升级后写作指令闭环

```
数据层：
  R69竞争真相（玩家名单/威胁分级/品牌映射）→ fig_players 注入
  全球对标（VEGA/Siemens等）→ global_str 注入
  三角验证（市场规模三法）→ tri_str 注入
        ↓
prompt 层（写作时强制）：
  竞争真相强制 → 必须点名玩家逐家分析
  框架应用结论强制 → 必须给框架应用结论
  反方三段式 → 情境→机制→杀伤力
  数据纪律 → 无依据不写改留白
  诚实留白 → 数据不足声明留白
        ↓
产出：
  有玩家、有分析、有全球视野、有框架应用 的决策报告
```

## 五、效果预期

新报告将体现：
