# 柯力传感·油位传感器进入决策报告——全新架构设计

> 定位调整：从"行业深度报告"改为"给董事长的决策情报报告"
> 核心原则：**只写董事长不知道的**——柯力自我分析压到背景，篇幅让给油位市场真相+进入决策+财务测算+风险上限
> 参考：麦肯锡 Executive Summary 金字塔、高盛/中金决策报告、MBB 战略假设驱动
> 日期：2026-08-06

---

## 一、报告定位的根本转变

| 维度 | 旧报告（油位_重做） | 新报告（本架构） |
|------|---------------------|-----------------|
| 读者 | 投资人/分析师 | **柯力董事长** |
| 目的 | 行业研究 | **辅助决策**（进/不进/怎么进） |
| 信息 | 柯力自我分析+行业全景 | **信息增量**（市场真相+对手+财务+风险） |
| 结论 | "行业值得卡位" | **明确建议**（进，按X路径，Y投入，Z回报） |
| 篇幅 | 464行，行业占290行 | 决策占70%，行业只留必要证据 |

**董事长要的**：不是"行业多大"（他可以请人调研），而是"**我进去能不能赚钱、怎么赚、亏了最坏亏多少**"。

## 二、全新报告结构（金字塔式）

### 金字塔原理（麦肯锡核心）

```
        顶部：一个结论（一句话）
         │
    三个支撑（三大依据）
         │
    每个支撑下的证据（数据/事实）
         │
    底部：执行建议 + 风险上限
```

---

### 完整章节设计

```
┌─ 0. 一页决策（Executive Summary）——董事长只看这页
│    ├─ 结论：进。按"华虹生产+久通渠道"路径，3年目标X亿
│    ├─ 三大依据：市场值得/柯力能进/对手挡不住
│    ├─ 投入：并购X亿+扩产X亿
│    ├─ 回报：3年营收X亿，EPS增厚X%
│    └─ 风险上限：最坏亏X亿（华虹整合失败）
│
├─ 1. 这个市场值不值得进（只留董事长不知道的）
│    ├─ 1.1 市场真实规模（三角验证，一句话结论）
│    ├─ 1.2 竞争真相：谁在赚钱（招标穿透数据）★新
│    ├─ 1.3 上游供应链：磁致伸缩丝卡脖子真相 ★新
│    └─ 1.4 政策真实节奏：哪年放量（不是"利好"）
│
├─ 2. 柯力能不能进（去掉自我分析，只留判断）
│    ├─ 2.1 技术栈适配性：称重vs油位的真实差距 ★新
│    ├─ 2.2 华虹承接能力尽调 ★新（产能/技术/认证）
│    └─ 2.3 久通渠道真实性验证 ★新（80+国家含金量）
│
├─ 3. 怎么进（生产主体决策——核心新增）★新
│    ├─ 3.1 生产主体三选：总部自制/外协代工/华虹生产
│    │    └─ 五维对比表（技术栈/认证/毛利/投资/周期）
│    ├─ 3.2 推荐：华虹生产为主+总部自制核心部件+代工验证
│    ├─ 3.3 内部转移定价（久通→柯力→华虹关联交易合规）★新
│    └─ 3.4 放量路径：三浪拆解+里程碑
│
├─ 4. 财务测算（董事长最想要但最缺的）★新
│    ├─ 4.1 3年收入/毛利/净利测算表
│    ├─ 4.2 对柯力EPS增厚测算
│    ├─ 4.3 投入产出：并购+扩产 vs 3年回报
│    └─ 4.4 敏感性：政策不及预期的财务影响
│
├─ 5. 风险与最坏情况（每条给损失上限）★新
│    ├─ 5.1 华虹整合失败=商誉减值X亿
│    ├─ 5.2 政策延期=放量推迟X年
│    ├─ 5.3 磁致伸缩丝断供=替代方案
│    └─ 5.4 竞争对手反击=份额损失上限
│
└─ 6. 执行路线图（第一年做什么）
     ├─ Q1: 华虹并表 + 久通代工试点
     ├─ Q2: 认证 + 招标投标
     └─ Q3-Q4: 放量启动 + 里程碑验证
```

## 三、顶级报告给我们的启发

### 启发1：麦肯锡金字塔——结论先行，一页决策
- **旧报告**：结论埋在 464 行后面
- **新报告**：第一页就是一页决策，董事长只看这页能拍板
- **启发**：报告是"辅助决策"，不是"学术论文"

### 启发2：MBB 假设驱动——先给判断，再给证据
- **旧报告**：铺完行业数据，最后才"因此我们判断"
- **新报告**：开头就说"进"，然后用数据支撑
- **启发**：董事长的注意力有限，先给结论他才知道该关注什么

### 启发3：高盛/中金的决策报告——只写"投资判断所需"
- **旧报告**：行业全维度（生命周期/弹性/地缘），很多是凑深度
- **新报告**：只保留影响"进不进/怎么进"的维度
- **启发**：信息增量 > 信息量。砍掉凑数的，深挖关键的

### 启发4：MBB 的"所以呢？"（So What）层层追问
- 市场大 → 所以呢？→ 值得进 → 所以呢？→ 怎么进 → 所以呢？→ 生产主体 → 所以呢？→ 华虹
- **启发**：每一层都要回答"这对董事长意味着什么"，而不是堆数据

### 启发5：咨询报告的数据可视化
- 竞争格局 → 份额图
- 三浪放量 → 瀑布图
- 财务测算 → 收入/利润柱状图
- 敏感性 → 矩阵热力图
- **启发**：董事长不看长表，看图表一眼懂

### 启发6：德勤/普华的风险量化
- 每条风险给**最坏损失上限**（不是"存在风险"）
- **启发**：董事长决策要"知道最坏亏多少"

### 启发7：MBB 的"执行可落地"
- 不只是建议"进"，而是**第一年 Q1/Q2/Q3 做什么**的具体路线图
- **启发**：报告的价值在"能执行"，不是"方向对"

## 四、关键新增内容（董事长不知道的信息）

### 4.1 招标穿透数据（最硬的信息增量）
- 中石化/中石油电子招标平台，加油站液位仪招标量、中标均价、中标厂商分布
- 回答："川仪到底占多少？正星呢？价格在降还是在涨？"

### 4.2 磁致伸缩丝供应链真相
- TDK/日企垄断格局，国产替代（河南长润）进度，断供风险
- 回答："核心部件被卡脖子，柯力进去会不会也被卡？"

### 4.3 华虹产能尽调
- 华虹现有产线、产能利用率、能否承接油位、扩产投入
- 回答："让华虹生产，它吃得下吗？要花多少钱扩产？"

### 4.4 久通渠道真实性验证
- 80+ 国家的客户质量：多少是海关大客户（高价值），多少是边缘客户
- 回答："久通的海外渠道是真金白银还是宣传话术？"

### 4.5 财务测算表
- 3 年收入/毛利/净利，对柯力 EPS 增厚，投入产出比
- 回答："这单生意 3 年能给我赚多少？"

## 五、与旧报告的关系

旧报告的行业深度（市场/供需/政策/竞争）**不是全废**，而是：
- **保留**：市场规模三角验证、政策传导链、利润池 BOM——这些是董事长不知道的
- **压缩**：柯力自我分析（产能/毛利/战略）——董事长知道，压到背景
- **删除**：凑深度的维度（弹性分析/地缘/ESG 如果与决策无关）
- **新增**：生产主体决策、财务测算、华虹尽调、久通验证、风险上限、执行路线图

## 六、一句话总结

**全新报告的定位从"行业研究报告"变成"决策情报+作战地图"。**

- 只写董事长不知道的：招标真相/供应链卡脖子/华虹能力/久通真伪/财务测算/风险上限
- 结论先行：第一页就"进，按X路径，Y投入，Z回报"
- 核心新增：生产主体三选（华虹生产为主）、财务测算、风险量化、执行路线图
- 参考顶级：麦肯锡金字塔、MBB假设驱动+So What、高盛决策导向、德勤风险量化、MBB执行可落地

**给董事长一份他"看完就能拍板"的报告，而不是一份"看完还要再找人分析"的行业论文。**
