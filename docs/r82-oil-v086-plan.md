## 二、加速工程方案（走B管线）

### 为什么能加速
1. **数据零采集**：全部存量数据合成 enrich-file（14项+），管线跳过网络
2. **底稿预置**：用我手写文案作 scaffold 注入，管线在其上校验修订（非从零生成）
3. **checkpoint 续跑**：沙箱 45s 限制用 resume_driver 分段跑
4. **训练模式双 LLM**：Marvis 起草（有传感器历史记忆）+ DeepSeek 校验

### 执行步骤
```
Step1 合成 enrich-file：存量数据 → data/keli_oil_enrich_v086.json（含R69竞争数据/柯力财务/全球对标）
Step2 启动 responder（train模式需要）→ 或退化 perf 模式（DeepSeek直出）
Step3 resume_driver 分段跑：preflight→data(enrich注入)→charts→write→assemble→gate
Step4 IronGate 全量（含R82新检查：单一事实源/来源实体/估值纪律）
Step5 export_report 导出 docx → output/油位传感器_行业深度报告_v0.86.docx
```

### 关键配置
```bash
cd D:\2hao-analyst
# 数据注入（跳过网络采集）
python pipeline/scheduler.py "油位传感器" --type industry_deep \
  --enrich-file data/keli_oil_enrich_v086.json
# 若 responder 不可用 → 性能模式
LLM_PROVIDER=deepseek python pipeline/scheduler.py ...
```

### 验收
- IronGate passed + 无 AI 标注 + 数字一致（渗透率/份额单一事实源）
- 含 R69 竞争玩家（托肯恒山/KROHNE/富仁高科）
- 行业报告无虚构个股 EPS（估值纪律）
- docx 含图、空段<5%
