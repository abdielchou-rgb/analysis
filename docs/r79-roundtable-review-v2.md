## 一、总体结论

**R79 整改部分成功——最刺眼的模板污染已根除，但报告仍不是交付态。** 三个核心缺陷（模板句/Bold Call/口径）已修复，但暴露了三个新的、更深的未解决项（反方空壳/硬凑数据/排版空白页）。**从"结构满分、灵魂缺失"进步到"结构正确、数字待考、排版带伤"。**

整改有效性：✅ 方向正确、部分生效
交付状态：❌ 仍需再修一轮才能给董事长

## 三、独立核验发现的未解决项（Marvis 自检也承认了）

### 3.1 反方论证仍全空壳（P1-2 未达标）

**独立实测：DES=0/3 强（0%），阈值 30%。**

重做报告 3 个反方段落仍是"概率空壳"模式——"政策执行不及预期（25%概率）"这种**无机制、无杀伤力评估**的反方。R79 P1-2 的要求是反方必须有**具体机制+杀伤力**（"国际巨头设中国厂+降价15%→目标价下调X%"），本版没做到。

**为什么**：section_writer 的 prompt 还是让 LLM 写"反方论证（概率XX%）"，没有强制"条件+杀伤力"。R79 的 Gate 检查能拦截（DES=0%），但**生成端没被约束**，写出来又被拦。

### 3.2 硬凑数据 51 处（P1-3 诚实留白未达标）

**独立实测：51 处具体数字无来源标注。**

执行报告自己承认"honest_gap=0.1（51 处数字无来源）"。这正好是 R79 P1-3 要治的"无来源硬凑数字"。Marvis 建议"批量补 (E) 标注"——**这方向就错了**：补个 (E) 标签不解决"这个数字哪来的"，反而给幻觉数字披上"有来源"外衣，是表演严谨。

### 3.3 排版空白页（P0-4 产物卫生未达标）

**独立实测：docx 空段落率 16%（46/594）+ 连续 55 个空段落 → 会出空白页。**

这是 R78 油位 v8 就修过的排版问题，又回来了。Marvis 用报告lab fallback 导出 PDF（25KB 无图），且 docx 空段率高。**说明导出链路仍有问题，四件套里有水。**

### 3.4 PDF 是"假四件套"

**PDF 25KB 无图**（Marvis 自认 LibreOffice 未装，走 reportlab fallback）。给董事长的 PDF 没图表，等于核心证据缺失。这不是"未解决项"，是**交付物不合格**。

### 3.5 洞察质量勉强及格

**独立实测：有锚点判断 11/46（24%）。**

比上版（17/48=35%）还低。说明判断密度降了但"有信息增量的判断"仍然偏少——大部分还是数据陈述+少量判断。方向对了，但"洞察密度"这个核心指标还没起来。

## 四、对比上版的深度反思

| 维度 | 上版（模板机） | 本版（整改后） | 反思 |
|------|--------------|--------------|------|
| 表象 | 套话连篇 | 套话根除 | ✅ 激励结构有效 |
| 结构 | 段落均匀机械 | Exec Summary+决策表 | ✅ 有主次了 |
| 数据 | 双口径冲突 | 三角验证交叉 | ✅ 有方法了 |
| 反方 | 概率空壳 | 仍是空壳 | ❌ 生成端没约束 |
| 硬凑 | 41 处无来源 | 51 处无来源 | ❌ **没解决还略增** |
| 洞察 | 35% 有锚点 | 24% 有锚点 | ❌ 判断深度下降 |
| 排版 | 图表堆附录 | 图表随文（11/11） | ✅ 但空白页新问题 |

**核心反思**：R79 的 Gate 检查**能拦截**模板/口径/Bold Call 了，但**生成端（section_writer prompt）没有同步改造**。所以被拦的问题是"写出来→被打回"，而不是"根本不这么写"。模板句能根治是因为有黑名单直接改写了；反方空壳/硬凑数据只靠 Gate 拦，LLM 还在照旧写。

**这印证了"激励结构是根"——但激励不只是 Gate 检查，还包括 prompt 侧的写作约束。**

## 六、给 Marvis 的整改指令

1. **P0 PDF**：安装 LibreOffice，重导含图 PDF（不能交无图 PDF）
2. **P0 排版**：跑 R40 空段清洗，docx 空段率压到 <5%
3. **P1 反方**：改 section_writer 反方 prompt——强制"若X发生→则Y（量化杀伤力）"结构，禁止"概率XX%"空壳
4. **P1 数据**：删掉无来源的具体数字，改为"数据不足留白"（不是补(E)标签）
5. **P1 洞察**：抽 5 个最关键的判断，每个补"为什么非显而易见+可证伪条件+数据锚点"
6. **重跑**：IronGate + VisualGate 全量，确认 DES≥30%、honest_gap 不报硬凑、空段率<5%、PDF 含图

## 七、结语

R79 证明了一件事：**激励结构是有效的**——模板句从 44 处降到 0，Bold Call 从 4 处不一致到单一，口径从冲突到统一。这套"Gate 拦截"思路是对的。

但第二轮也暴露了**新的边界**：光有 Gate 拦截不够，生成端 prompt 必须同步约束；光有格式检查不够，交付物（PDF 含图/排版）必须走真链路。**第三轮的方向不是再加 Gate 检查，而是：改 prompt 让 LLM 一开始就别那么写，以及把交付链路做扎实。**

当前状态：**战略内容（Exec Summary+三浪放量+以点打面）是可用的，但反方空壳/硬凑数据/无图PDF这三处不修，不能给董事长。** 建议按第六节指令再修一轮。
