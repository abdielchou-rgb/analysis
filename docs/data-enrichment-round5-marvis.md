## 通用规范（延续前几轮，加强版）

- **source 标注**：每条必须带 URL 或接口名
- **幂等**：重跑合并去重（同 URL+同句首）
- **质量优先**：宁可少几条也要每条真实（FP2 数据零编造）
- **验证**：每任务写读回验证 + 更新状态表
- **SQLite 列序纪律**：写入前对照 DDL，写后抽查数据正确性
