## 二、三类沉默缺陷（质检不会被拦截）

### 缺陷 1：模板句重复——合并引擎的把合变成了拼合

R54 引入的语义重复检测在 Gate 中查的是"同一个句子的逐字重复"，但 v6 出现了更隐蔽的"同义模板重复"——同一个句意用略有不同的措辞重复多次：

| 模板句子 | 出现次数 | 变体 |
|---------|---------|------|
| 「后续…将成为验证这一判断的关键观测点」 | 4 | 后续跟踪中最重要的边际变量 / 后续机会的必要条件 / 后续估值重估能否成立的前提 |
| 「上述变化对盈利预测的传导…」 | 3 | 存在路径与时滞上的不确定性 / 存在系统性上移的可能 / 仍面临下行风险扰动 |
| 「这一趋势若被证实…」 | 2 | 将显著改变我们对行业格局的既有认知 / 有望成为全年行情演绎的主线 |
| 「在此背景下…」 | 多处 | 竞争壁垒的强化将构成公司中长期价值的核心支撑 |

**根因**：dim-parallel 将 26 个 SAC 维度分成 6 组并行写，各组 LLM 独立生成 So What 链和过渡句。合并编辑时，编辑 LLM 只做了章节拼接，没有做语义去重。平行生成的各组各自产出了类似的"格式过渡句"，合并后形成"同一个意思用不同措辞说了 2-4 遍"的碎片感。

**严重程度**：不影响数据准确性和逻辑完整性，但严重影响阅读体验（读者会觉得"这报告在同一个观点上绕来绕去"）。这是 R54 语义重复检测的缺口——检测查的是逐字重复，未查同义变体重复。

### 缺陷 2：催化剂日历只写了 3 行——整个"资本市场映射"章节在 5.2/5.3 段严重缩水

这是 v6 最严重的内容缺口：

- 5.1 估值倍数写了一个完整段（有数据、有 So What、有反方、有结论）
- 5.2 一致预期差写了约 10 行（勉强完整）
- **5.3 催化剂日历只写了 3 行**——表格只有 0.5 行内容（一行 2026Q3 中报），后面整整 3 个空行然后直接跳到第六章

催化剂日历是 SAC capital_market 维度的核心 sub_question（"3/6/12 个月事件驱动"），应该是季度级时间轴表格——至少 4 行（2026Q3, Q4, 2027Q1, Q2）。v6 的催化剂日历被截断在 1 行。

**根因**：LLM 生成时触发了 token 预算或截断逻辑，导致催化剂日历段被过早截断。编辑合并时没有检查段落完整性（Gate 有 `check_required_elements` 但不查段落是否被截断）。

### 缺陷 3：报告末尾的 AI 免责声明复活——R42 修复被覆盖

v6 报告末尾第 532 行：`*（内容由AI生成，仅供参考）*`

这是 R42（2026-08-02）已经根除的问题——R42 要求清除所有 AI 免责声明注入（style 删 + export 加的矛盾）。但 v6 的 Marvis 手动修复补全过程没有走管线 export 链路，所以 R42 的修复在这个路径上无效。

**说明这是系统性激励问题**：Marvis 在手动修复时，自然地加上了免责声明——因为"这是负责任的做法"。管线的出口链路拦截了这个声明，但手动路径绕过了出口链路。

## 三、SAC 100% 覆盖率的真相——14 个维度是软覆盖

自评报告说"26/26 维度全部覆盖"，但圆桌审计发现覆盖质量差异悬殊：

### 硬覆盖（12/26）——有数据、有判断、有 So What

| 维度 | 证据 |
|------|------|
| market_size | TAM/SAM/SOM 三层拆解 + 表格 |
| life_cycle | 双指标框架 + 生命周期表格 |
| competitive | 三层分化 + CR3/CR5 + 利润池 |
| policy | 四维度评分 + 加权计算 |
| industry_chain | 上下游表格 + 传导时滞 |
| profit_pool | 价值链毛利率表 + 迁移方向 |
| bold_call | 四要素（方向/窗口/变量/证伪）清晰 |
| supply_demand | 渗透率曲线 + 饱和点判断 |
| technology | 磁致伸缩/雷达/浮子/TDR 四路线 |

### 软覆盖（14/26）——关键词命中但无实质分析

| 维度 | v6 写了什么 | 缺失什么 |
|------|-----------|---------|
| **capital_market** | 一节估值倍数 + 半节预期差 + 3 行催化剂日历 | 戴维斯双击/双杀判断（SAC sub_question 5）、赔率评估（sub_question 6）、均值回归风险（sub_question 7）、催化剂日历只写了 1/4 |
| **signal_chain** | 先行/同步指标列表 | 缺滞后指标层（三级信号链应该有 3 层的完整框架），缺信号链触发/未触发的状态判定 |
| **elasticity_analysis** | "IED 0.5-0.8"定性判断 | 缺 PED（需求价格弹性）、PES（供给价格弹性）、XED（交叉价格弹性）——SAC 要求的是弹性矩阵，不是单一 IED |
| **peer_benchmarking** | 国内外对手对比表 | 缺同行业全球对标矩阵（VEGA/Siemens/E+H 的关键财务指标、估值、技术路线对比） |
| **global_market_sizing** | 全球 50 亿美元（一句话） | SAC 要求三段式（全球俯瞰/区域透视/渗透率错位），报告只给了全球总量 |
| **global_competition** | 工业物位仪表 CR5 + 三层分化（嵌入竞争章节） | 缺"中国 vs 国际"的独立对比框架 |
| **geopolitical_risk** | 写了一个完整章节 | 但地缘风险评估模式偏"学术综述"——缺少"对投资的含义是什么"的具体映射 |
| **investable_standouts** | 提及川仪股份/汉威科技 | 没有形成"行业判断→受益标的→财务验证→评级目标价"的完整选股传导链 |
| **industry_consolidation** | "CR5 从 2018 年 58%→2025 年 65%" | 缺并购估值倍数（EV/EBITDA）、ROIC vs WACC、整合者画像——这些正是 R70 ma_valuation 模块的定义内容 |
| **esg_materiality** | 关键词命中 0 次 | 报告中完全没有 ESG 相关内容（GRI/SASB/TCFD/碳排/治理全部空白），SAC 有 esg_materiality 维度但报告无对应段落 |
| **core_hypothesis** | Bold Call 中有假设语句 | 但不是 MBB 式的"如果我们是对的，应观察到 X；若 X 未发生，假设就错"——缺少先行指标和失效触发线的结构化写法 |
| **falsification** | Bold Call 有证伪条件 | 只有 1 条证伪条件（SAC 要求至少 3 条） |
| **decision_gate** | 开头一句"三个决策门中至少 2 个为 GO" | 没有列出哪三个决策门、各自的评估基准、通过/不通过的理由 |
| **unlisted_players** | 非上市玩家威胁地图（图表覆盖） | 正文只有 1 处提及托肯恒山/GVR——12 家完全遗漏玩家中有 9 家仅图表覆盖 |

**关键发现**：SAC 覆盖率 100% 是"关键词搜索命中"层面的覆盖，不是"实质分析"层面的覆盖。14 个维度有名称但无深度，平均每个维度缺少 2-3 个 sub_question。

## 五、Marvis 手动修复路径的系统性问题

v6 是 Marvis 多轮打磨的产物，而非纯管线产物。这暴露了 2 个系统级问题：

### 问题 1：手动修复绕过 IronGate

v6 的"26/26 SAC 覆盖率"和"13 张图"是通过手动逐项补全达成的，没有经过 IronGate 的结构化校验。结果是：
- 表面质检全部通过
- 深层缺陷（段落截断、弹性矩阵缺维度、ESG 空白）未被拦截

这不是 Marvis 的问题——Marvis 做了它能做的最好的。问题是：**一旦输出路径绕过管线，等于放弃全部质量门禁**。

### 问题 2：R42 免责声明复活证明"修复根因未到位"

R42 的修复是在 style_compiler 和 export 链路中拦截免责声明。但 Marvis 手动修复 v6 时，LLM 自然地在末尾加上了"内容由 AI 生成，仅供参考"——因为 LLM 的生成偏好就是这样。管线的 style_compiler 删掉了，但 Marvis 手动编辑时又加回来了。

这意味着：**R42 的修复只在管线出口链路有效，不在手动路径有效**。根治方案是让这个声明在"报告元数据"中标注（如 frontmatter），而非由 LLM 在正文中自由输
