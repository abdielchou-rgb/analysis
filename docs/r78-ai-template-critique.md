# 深度分析：油位传感器报告为何"不像人写的"

> 评审对象：`D:\2hao-analyst\output\油位传感器_cicc.md`（v1）
> 评审视角：它像不像一个真咨询分析师写的报告？
> 评审日期：2026-08-05
> 核心结论：**不像。它是一份"披着投行框架外衣的 AI 模板拼装品"。**

---

## 一、先说判断

这份报告在**结构完整度**上达标（SAC 维度齐全、Gate 通过），但在**写作质感**上是失败的。失败不在数据错误（那是另一层问题），而在一个更根本的东西：**通篇是模型生成的安全套话，没有一手调研、没有判断的层次、没有分析的手感。**

读者（董事长）读前三段就会产生"这是机器写的"的直觉。这个直觉是对的，而且可以逐条指认。

---

## 二、AI 痕迹的具体指认（带原文）

### 2.1 模板句复读——最刺眼

全报告反复出现以下句式，单篇出现 3-8 次不等：

| 模板句 | 出现位置（节选） |
|--------|-----------------|
| "这一趋势若被证实，将显著改变我们对行业格局的既有认知" | 1.1、2.3、九章多处 |
| "上述判断仍面临需求端波动带来的下行风险扰动" | 1.1、2.4、2.2、2.4 戴维斯多处 |
| "这一变化同时意味着，需要重新审视此前对业务结构的增长假设" | 1.1、1.3、2.3 |
| "从更长周期看，上述趋势若持续，盈利中枢存在系统性上移的可能" | 决策门、1.3、2.2 |
| "后续财报中相关指标的兑现情况，将是检验上述判断真伪的试金石" | 2.4、核心分歧、1.3 |
| "这一迹象提示，市场当前定价可能尚未充分反映上述逻辑的潜在弹性" | 2.4、2.2 |
| "该类数据的边际改善，往往领先于报表层面的最终体现" | 2.3、3.2、核心分歧 |
| "对上述变量保持高频跟踪，是把握后续机会的必要条件" | 2.2、2.3、戴维斯 |
| "驱动因素边际拐点的确认，是后续估值重估能否成立的前提" | 3.2、2.4、1.1 |
| "该数据背后折射出的经营质量变化，比单期数值本身更值得关注" | 资金面、2.4、反方论证 |

**这不是巧合**——这些是 LLM 在"每段必须有 So What 链、必须有反方论证"的指令压力下，生成的**万能过渡句**。真人分析师写报告，段落之间是逻辑推进，不是套话换着花样说。

### 2.2 结构僵化：每一节都是同一个模子

全报告 40+ 个分析段落，几乎无一例外按这个模子：

```
[数据/表格] → 因此我们判断，... → 反方论证（概率XX%）→ 若该趋势延续...
```

- 决策门 → 反方论证（概率30%）→ 结论
- 供需平衡 → 反方论证（概率30%）→ 结论
- 利润池 → 反方论证 → 结论
- Bold Call → 反方论证（概率35-40%）→ 结论
- 资金面 → 反方论证（概率25%）→ 结论
- 预期差 → 反方论证（概率35%）→ 结论
- 柯力估值 → 反方论证（概率50%）→ 结论

**真人写作是详略得当、主次分明的**。核心判断浓墨重彩，次要信息一笔带过。这份报告是均匀铺开、机械循环——像流水线，不像思考。

### 2.3 概率标注机械化

"概率30%"、"概率25%"、"概率35%"、"概率50%"、"概率40%"——几乎每个反方论点后面都跟一个精确到个位数的概率。真人分析师会这样吗？

不会。真人会写：
- "我们认为该风险**可控**，因为…"
- "这一风险**不容忽视**，理由是…"
- 用措辞和论证强度表达不确定性，而不是给每个风险贴一个看起来精确、实则拍脑袋的百分比。

精确概率是**表演严谨**，不是真的严谨。这些概率没有任何数据支撑（没跑蒙特卡洛、没做情景树），纯粹是 LLM 为了满足"反方论证要有强度"的检查而编的。

### 2.4 空洞的"分析过渡句"

以下句子看似分析，实则什么都没说：

- "综合来看，这一变化对基本面结论的含义，需要在下一阶段持续跟踪。"
- "这意味着，核心变量的后续兑现节奏将成为验证这一判断的关键观测点。"
- "因此，对上述变量保持高频跟踪，是把握后续机会的必要条件。"
- "综上，上述判断仍面临需求端波动带来的下行风险扰动。"

**把"需要跟踪""关键观测点""必要条件""面临风险"全部删掉，报告逻辑完全不受影响。** 这些是填充词，是 LLM 在凑"判断密度"指标时生成的废话。

### 2.5 数据来源的"表演式严谨"

报告满屏的 (A)(E)(F) 标注，看似专业，实则多处是**错配**：

- 行业增速 6.4-7.1% 后面标"（数据来源：公司年度报告）"——**油位传感器行业增速为什么引用柯力的年报？**
- "全球供需平衡表"来源标"公司年度报告"——**行业供需平衡表跟某一家公司的年报有什么关系？**
- "中国 2025 市场规模 172 亿元"标 (A)——这个数字其实来自油位 v8 报告，标注本身没错，但整篇的"来源"标签给读者一种"每个数字都查证过"的错觉，而实际大量是 (E) 估算。

**真调研报告的数字来源是具体可查的**：某份招股书、某次行业展会、某个海关出口数据。这份报告用的是"看起来专业"的字母分级，本质是给 LLM 幻觉数字披上"有来源"的外衣。

### 2.6 缺乏一手调研质感——最致命的缺失

整份报告 2 万字，**没有任何一手调研的痕迹**：

- 没有"我们走访了 N 家加油站设备商"
- 没有"某央企采购经理反馈，招标周期从 6 个月缩短到 3 个月"
- 没有"宁波某磁致伸缩材料供应商报价同比下降 12%"
- 没有"我们在中石化某次集采中标名单里发现..."
- 没有"久通物联与某中东客户的合同细节"

**咨询分析师的核心价值就是一手调研**。麦肯锡一份行业报告的底层是 20+ 次专家访谈、工厂走访、招投标数据穿透。这份报告的所有"洞察"都是 LLM 从公开数据 + 常识推断出来的，没有任何现场信息增量。

这解释了为什么报告读起来"空"——它不是知道什么，而是**推导了什么**。推导的东西，读者自己也能推；一手信息，才是付费的理由。

### 2.7 Bold Call 四处重复定义

同一份报告里 Bold Call 至少定义了 4 次，表述各不相同：

| 位置 | Bold Call 表述 |
|------|---------------|
| 决策门（L66） | 2026Q4-2027Q2 存量替换集中释放，政策执行率 62%→85% |
| 竞争层决策门（L197） | 2026Q3-2027Q4 看多国产中游份额 35%→42% |
| 核心分歧（L272） | 2026-2027 政策驱动 8-10% 增速脉冲 |
| 前瞻层（L286） | 2026Q3-2027Q3 增速提升至 10-12%，中国 2027 破 200 亿 |

**时间窗口（Q4-Q2 vs Q3-Q4）、核心变量（政策执行率 vs 磁致伸缩良率）、增速（8-10% vs 10-12%）全不一致。** 这是典型的"分段并行生成、未做全局整合"的 AI 特征——真人分析师会在开头一句话定死 Bold Call，全文引用同一个。

## 三、根因分析：为什么 2hao 会写出这种报告

### 3.1 激励倒挂（最根本）

**这是 R47 已经发现、但从未根治的问题："系统奖励看起来完整，惩罚诚实留白。"**

- Gate 检查 `so_what_chain`：每段必须出现"数据→判断→建议"链 → LLM 被迫在每段塞"因此我们判断..."
- Gate 检查 `judgment_density`（≥1.2 判断/千字）→ LLM 堆判断词凑密度
- Gate 检查 `counter_argument` → 每段必须有反方论证 + 强度 → LLM 机械标概率
- Gate 检查 `bold_call` → 必须显式写 Bold Call → 每部分都补一个

**LLM 不是不会写好，而是被检查项训练成了"模板填充机"。** 它学会了用最少的"真实思考"满足最多的"格式要求"，结果就是这份报告——结构满分、灵魂缺失。

### 3.2 prompt 强制模板

SAC 框架本身要求每个维度都有：question → sub_questions → evidence → counter_evidence。这个框架用于**检索完整性**是好的，但直接拿去做**写作模板**就僵化了。prompt 让 LLM "严格按 SAC 框架撰写"，等于告诉它"每节都要数据→论证→反方→结论"，模板味由此而来。

### 3.3 数据底座缺一手调研

2hao 的数据来自：financials.db、WebSearch、本地报告。**没有任何专家访谈、工厂走访、招标数据穿透的采集通道**。数据底座只有"二手公开数据"，写出来的报告自然只有"二手推导"，没有一手洞察。

### 3.4 无"人味"的后处理

真报告经过资深分析师修改：删废话、调结构、加自己的判断、用行业黑话。2hao 产出的报告**直接出厂**，Style Compiler 只做格式清洗，不做内容锤炼。所以 LLM 的"初稿味"全保留。

## 四、真人咨询分析师会怎么写（对照）

| 维度 | AI 模板报告 | 真人咨询分析师 |
|------|------------|---------------|
| 结论 | 藏在各种"因此我们判断"里 | **第一页 Exec Summary，一页说清** |
| 结构 | 每节均匀铺开，机械循环 | 金字塔：结论→论据→论据的论据，详略得当 |
| 调研 | 无一手信息 | "我们访谈了 12 位行业专家""走访了 3 家厂商" |
| 数据 | (A)(E)(F) 字母标注 | 具体来源：招股书/海关数据/集采平台/专家访谈记录 |
| 不确定性 | 机械标"概率30%" | "风险可控/不容忽视" + 论证理由 |
| 语言 | 套话连篇、重复过渡句 | 精炼、有观点、有行业黑话 |
| Bold Call | 全文 4 处不一致 | 开头定死一个，全文引用 |
| 建议 | "关注 XX""跟踪 XX" | "我们建议 2026H2 完成华虹并表，Q4 启动代工试点，具体分三步…" |

**一句话：真人写的是"判断"，AI 写的是"格式"。**

## 五、整改方向

### 5.1 短期（1-2 天）：文本去模板化
- **模板句黑名单**：把 2.1 节的 10 个模板句加入 Style Compiler 的 `template_repeat` 检测，出现即提示改写
- **去概率机械化**：Gate 对"反方论证概率"的检查从"必须给数值"改为"给论证强度"（强/中/弱 + 理由）
- **Bold Call 单一事实源**：报告开头定义 Bold Call，后续段落必须引用同一个（加 Gate 一致性检查）

### 5.2 中期（1-2 周）：调研数据注入
- 新增**专家访谈采集通道**：Marvis 访谈纪要 → 结构化入库 → enrich-file 注入
- 新增**招标/集采数据穿透**：加油站设备集采平台、危化品安全改造招标数据
- 新增**产业链实地信息**：工厂走访记录、供应商报价、展会信息

### 5.3 长期：激励结构重建（最根本）
- **Gate 检查项从"查格式"转向"查洞察"**：
  - `judgment_density` 改为 `insight_density`——不是数判断词，而是检查是否有"非显而易见、可证伪、有信息增量"的判断
  - `counter_argument` 改为检查反方是否有**具体机制**（"国际巨头设中国厂+降价15%"）而非空泛概率
- **引入"留白奖励"**：允许并鼓励"此维度数据不足，明确留白"，反向惩罚"硬凑内容"
- **Style Compiler 加"人味过滤"**：扫描并删除套话过渡句、填充词

### 5.4 报告结构层面
- 放弃"战略层/竞争层/前瞻层"三段的硬拆（导致 Bold Call 重复），改为**单一连续叙述**
- 开头加一页 **Executive Summary**（结论、依据、建议、风险），董事长只看这页就能决策
- 图表随文并**配解读文字**，而不是堆在附录

## 六、给这份报告的最终定性

这份报告**不是不能救**，而是**当前不是交付态**。

- 战略洞察（9.1-9.5：进入路径、三浪放量、以点打面、产业集群、风险缓释）是**真有内容**的，说明分析框架本身能产出好判断
- 但写作层被模板污染，数据层有双口径冲突，产物层图表堆附录、AI 标注残留

**病根在激励结构**：只要 Gate 继续奖励"看起来完整"、惩罚"诚实留白"，2hao 就会持续产出"结构满分、灵魂缺失"的报告。这不是多改几个 prompt 能解决的，需要把 Gate 从"查格式"升级为"查洞察"，并补上一手调研的数据通道。
