## 二、为什么"该用未用"——根因

### 根因 1：工作台路径绕过了框架注入
2hao 的管线模式（section_writer）会**自动注入**这些框架（framework_injector / methodology_injector / knowledge_injector）。但油位报告走的是**工作台路径**（Claude 直接写 docx）——context_compiler 只注入了意图/数据/计算摘要，**没注入 2hao 分析框架**。

```
管线模式：section_writer → 注入 geopolitical/macro/bottleneck 框架 → LLM 用 → Gate 查
工作台模式：Claude 直接写 → 没注入框架 → 只凭 LLM 常识 → 框架缺失
```

### 根因 2：框架"有代码"≠"有内容"
`geopolitical_engine` 需要 `data/geo_events.json`（中美事件库），`macro_context` 需要宏观数据——**如果这些数据没采集，引擎跑出来是空的**。检查是否真有数据。

### 根因 3：报告定位偏差
报告本质是"决策备忘录"（柯力老板拍板接不接油位），不是"行业深度报告"。但用户期望看到 2hao 的行业分析深度——**决策备忘录 ≠ 跳过行业框架**，恰好相反，决策需要更深的行业理解（中美风险/宏观周期都影响"接不接"）。

## 三、2hao 引擎能给油位报告增加什么（具体价值）

### 1. 中美竞争（geopolitical_engine）
```
分析：油位传感器核心部件波导丝由日本爱知制钢/德国VAC供应——
  · 若中美科技摩擦升级，日德供应是否受影响？（出口管制/供应链安全）
  · 国产替代（武汉利又德/博尔森）是否是"卡脖子自主可控"的政策受益方向？
  · 加油站防渗改造是内需驱动，受中美影响小；罐箱出口受贸易摩擦影响？
结论价值：给"接不接"增加地缘风险维度——波导丝断供是已有红线，但国产替代的"政策受益"是加分项
```

### 2. 宏观传导（macro_context）
```
分析：油位设备需求与宏观的传导链——
  · 原油价格 → 加油站盈利 → 防渗改造投资意愿
  · 利率 → 基建/危化品投资节奏
  · 贸易周期 → 罐箱运输量 → 罐箱监测需求
结论价值：给"2026-2027 政策窗口"增加宏观共振判断——若油价/利率不利，窗口可能缩窄
```

### 3. 利润池（bottleneck_engine Profit Pool）
```
分析：油位传感器产业链利润池分布——
  · 上游材料（波导丝）毛利 50-65%
  · 中游制造（装配）净利 8-12%
  · 下游集成（认证+渠道）毛利？
结论价值：给"做哪一环"决策——中游代工净利薄，应向上游材料或下游认证延伸（柯力卡位）
```

### 4. 产业生命周期（life_cycle_mapper）
```
分析：明确阶段定位——
  · 油位传感器整体：成熟期（增速5%，降本竞争）
  · 罐箱监测：成长期（增速10-15%，跑马圈地）
  · 政策驱动段：抢位期（先发优势2-3年）
结论价值：给"资源怎么投"——成长期投扩张，成熟期投降本，抢位期投速度
```

### 5. 瓶颈/卡点（bottleneck_engine）
```
分析：波导丝是产业链卡点（卡位评级）——
  · 卡点集中度：爱知制钢/VAC 双寡头
  · 柯力进入油位，波导丝是最大外部依赖
  · TOC 五步：识别→挖尽→服从→提升→回头（自研突破）
结论价值：给"波导丝红线"增加卡位分析——不只是"涨价30%退出"，而是"卡点决定了业务天花板"
```

## 四、系统修复建议

### 1. context_compiler 注入框架检查清单
按报告类型自动注入框架要求：
```
行业深度报告 → 强制注入：产业生命周期/波特五力/利润池/中美竞争/宏观传导/信号链
决策备忘录 → 强制注入：上述 + 卡位/瓶颈/风险
缺框架 → Gate warning："报告未覆盖 X 框架，需补充或说明不适用"
```

### 2. 数据前置
`geopolitical_engine` 需 `geo_events.json`、`macro_context` 需宏观数据——**跑报告前先 `--data-check-only` 查这些引擎的数据是否齐备**，缺则 enrich 补采。

### 3. 报告补强（v4.6）
按 P0 补 3 块：
- **2.6 中美竞争与宏观传导**：波导丝供应地缘风险 + 原油/利率传导链
- **2.7 利润池定位**：上游/中游/下游利润占比图 + 柯力应卡哪一环
- **2.8 生命周期定位**：油位成熟/罐箱成长/政策抢位 + 对应策略

## 五、一句话总结

**用户完全正确：油位 v4.5 用了约 10/14 框架，但 2hao 的"高级分析引擎"几乎全未启用——中美竞争（geopolitical_engine）、宏观传导（macro_context）、利润池（bottleneck_engine Profit Pool）、生命周期（life_cycle_mapper）全部缺席或浅覆盖。根因是工作台路径绕过了框架注入（section_writer 会自动注入，Claude 直接写不会）。修复：①context_compiler 按报告类型注入框架检查清单；②报告补 P0 三块（中美/宏观传导、利润池、生命周期）；③数据前置查 geo_events/宏观数据。** 决策备忘录也需要行业框架深度——恰好相反，决策更需要。
