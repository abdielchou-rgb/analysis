## 二、WorkbenchExecutor 工作台执行器【新模块】

### 新增 `core/workbench_executor.py`
人机协作工作台六步：
```
① 意图对齐：intent_parser → 必答问题 + 报告结构
② 数据准备：读 data_dict（带分级标注）
③ AI 直接写：上下文工程 prompt（业务命题+分级数据+约束+示例）
④ 程序校验：intent_gate 意图符合 + verify
⑤ 人类门禁：高险文档强制（决策审计落盘）
⑥ 迭代沉淀：报告落盘 + 纠偏 → fact_base
```
- `run()`：无 report_text → 返回上下文 prompt 供 LLM 写；有 → 完成校验/门禁/落盘
- CLI：`python -m core.workbench_executor "柯力" --type decision_memo --requirement "..." --human-gate`

### 验证
- 全流程：意图 7 必答问题 + 上下文 prompt ✅
- 校验：coverage 1.0 passed ✅ + 人类门禁记录 ✅
