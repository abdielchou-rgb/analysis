## 一、系统升级（2hao 能力）

### 1. business_logic_gate（Codex 建议）
新增 `core/business_logic_gate.py`，检测**业务逻辑断点**（语义级）：
- **双价格带冲突**：报告出现两个价格带（如 300 vs 5000）但未说明双轨关系 → error 阻断
- **跨章节毛利率口径冲突**：盈亏平衡 30% vs 中高端 40-50% 未说明 → error
- **声称无量化的价值**：协同/期权/战略价值声称但无数值 → warning

验证：v2.3 式（无说明）→ error 拦截；v3.0 式（有双轨说明）→ warning 通过。已接入 IronGate。
