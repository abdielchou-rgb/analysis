## 关键发现与决策

1. **模块名冲突**：本地引擎 `mineru` 与云 SDK `mineru-open-sdk` 都注册 Python 模块 `mineru`，同环境不可共存 → 用接口差异（`process` vs `MinerU`）区分，auto 模式自动降级；推荐全局装本地引擎 + MCP 走 uvx 隔离云。
2. **MCP Server 官方形态**：`uvx mineru-open-mcp`，Flash 模式免 token（≤20页/10MB），`parse_documents` 工具，Claude 桌面配置 `claude_desktop_config.json`。
3. **2hao 接入价值**：现有 PDF 提取（pdfplumber 文本层）对扫描版/复杂版面失效，MinerU 补强；三场景（研报知识提取/年报解析/通用文档转MD）均有对应命令与接线建议。
