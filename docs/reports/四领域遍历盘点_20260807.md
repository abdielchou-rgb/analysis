# 四领域遍历盘点：知识库/方法论/分析框架/计算模块

> 日期：2026-08-07
> 目的：遍历四个领域现状，对照同行顶级启发找盲区
> 结论先行：**四领域覆盖度高（约 75%），但对照 FP0 意图驱动 + 同行启发，有 5 个明确盲区——意图层缺、审计怀疑缺、非上市深度缺、代工/合作生产测算缺、上下文工程模板缺。计算模块是四领域里最扎实的。**

## 第三部分 盲区清单（5 个明确缺口）

### 盲区 1：意图层全缺（最严重，FP0 落地阻断）
```
现状：无 intent_parser / 无委托方问题清单 / 无意图符合性检查
影响：柯力场景无法"回答老板的问题"，只能"写满模板"
补：core/intent_parser.py（必答问题 → 报告结构）
    core/intent_gate.py（必答问题是否被回答）
    docs/workbench-context-template.md（上下文工程模板）
```

### 盲区 2：审计怀疑未显性化
```
现状：反方论证有三段式，但"写手默认怀疑"未成姿态
影响：写手仍可能自信地写错（R47 教训）
补：IS-CoT 反思升级为"专业怀疑"——写手任务加"你写的数据可能哪里错"
    复用四大"重大错报风险导向"→ 优先查最可能错的点
```

### 盲区 3：代工/合作生产测算缺失（柯力场景直接需要）
```
现状：valuation 强，但无"代工成本/盈亏平衡/转移定价/期权价值"
影响：柯力接不接久通代工，算不出投入产出比
补：core/compute/contract_manufacturing.py
    - 代工成本拆分（设备/产线/认证/良率爬坡）
    - 盈亏平衡量（固定成本/单位毛利）
    - 转移定价合规（关联交易）
    - 战略期权价值（进入油位的真实期权）
```

### 盲区 4：咨询/战略方法论未显性化
```
现状：价值投资框架 7 个，但问题树/金字塔/假设驱动未成方法论 yaml
影响：结构化思考靠 LLM 临场，不靠框架
补：core/frameworks/issue_tree.yaml（问题树）
    core/frameworks/pyramid_principle.yaml（金字塔）
    core/frameworks/hypothesis_driven.yaml（假设驱动）
```

### 盲区 5：非上市深度不足
```
现状：有 unlisted_reverse_valuation / reference_class，但深度弱
影响：非上市标的（久通）估值/尽调深度不够
补：可比融资分析 / 股权结构 / 退出路径概率 / 里程碑估值
    参考 MBB 的单元经济（unit economics）
```

## 第五部分 一句话总结

**四领域覆盖约 75%：计算模块最扎实（估值/财务/质量门全有）、知识库吸收强但缺结构化事实库、方法论价值投资类强但缺咨询/战略类、工具链广但缺意图层。对照同行启发，5 个明确盲区——意图层全缺（最严重，FP0 落地阻断）、审计怀疑未显性化、代工/合作测算缺失（柯力场景直接需要）、咨询方法论缺失、非上市深度不足。P0 立即补 intent_parser + contract_manufacturing，柯力任务即用。**
