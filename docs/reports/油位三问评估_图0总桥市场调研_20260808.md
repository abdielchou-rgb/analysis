## 问题一：图0 总览排版诊断

### 现状勘察
- 图0 实际是 `image1.png`（1800×930px，1.7MP），嵌入 docx 尺寸 14×7.2cm
- 有效显示 dpi ≈ 327（1800px / 5.5英寸），**分辨率本身够**，但：
  - **内容密度过高**：一张图塞了"市场总览 + 承接机会 + 战略卡位"全部信息 → 字号被迫压小
  - **排版紧凑**：BCG 风格矩阵图，四象限挤在一起，无留白
  - **嵌入尺寸偏小**：14cm 宽在 A4 正文里只占 60%，边距浪费

### 顶级报告怎么处理总览图
高盛/大摩的**图0/首图**通常是"一页一图、留白充足、字号 ≥8pt"：
- **单图单信息**：总览图只画"市场 + 机会"的骨架，细节放正文
- **分图呈现**：市场总览（饼/柱）与承接机会（逻辑链）分两张图
- **大图大字**：全幅宽（16cm+），字号 ≥9pt，可读性优先

### 修订方案
```
图0 拆两张：
  图0a 油位传感器市场总览（饼图/柱图，全球46亿→65亿 + 中国166亿→172亿 + 细分占比）
  图0b 承接久通机会逻辑链（久通渠道 + 我方制造 → 油位入口 → 衍生价值）
  两张图各自全幅宽、字号≥9pt、留白充足
```

## 问题二：推导总桥展开方案

### 现状
图12 推导总桥只是 1 张图（image3.png），正文只有"核心逻辑链见下图"，**没有展开论述**。

### 顶级报告怎么处理推导总桥
投行深度报告的**估值推导桥**是"图 + 文字双展开"：
- 图上画桥：市场总量 → 可竞争市场 → 份额 → 收入 → 成本 → NPV
- 图下文字：**每一步的假设 + 计算 + 敏感性**

### 展开方案（图12 + 新增文字段落）
```
图12 推导总桥（重画，7 步桥，每步标数字）：
  全球油位市场46亿美元 → 中国可竞争40-50亿元 → 中端机会带占比
  → 久通渠道可及份额 → 基准收入 → 毛利率→净贡献 → NPV 3116万/IRR 57%

新增"推导总桥论述"文字段（紧随图12）：
  第1步 市场规模：全球46亿→65亿（CAGR 5%），中国可竞争40-50亿（口径：排除外资聚焦的高端大项目）
  第2步 目标细分：罐箱监测6-9亿美元（占15%），增速10-15%——选择罐箱作为切入点
  第3步 渠道可及：久通80国客户网络，目标渗透率X% → 可及收入Y
  第4步 收入测算：自下而上（海外线+国内线）→ 基准情景收入曲线
  第5步 毛利率：40-50%（海外）→ 净贡献
  第6步 成本：固定月费用45万 + 盈亏平衡月收入150万
  第7步 NPV/IRR：经营期NPV 3116万/IRR 57%，三情景加权 3200万
  每步标注敏感性：哪步对NPV影响最大（毛利率+渗透率=80%）
```

## 问题三：市场调研圆桌讨论（对标顶级报告）

### 角色评价

**Feynman（反自欺）**：
- 市场规模"46亿美元全球 vs 166亿中国"**口径不一致已诚实标注**（好事），但 166 亿是"油位水位广义"，与决策相关的窄口径（油位）中国规模没算清楚
- "加油站10万座×5-10万=50-100亿"是**战略部测算**——来源是内部假设，未交叉验证

**Taleb（反脆弱）**：
- "2028年后政策红利回落"已提示，但**没纳入财务测算**——乐观/基准情景假设了持续增长，政策回落只口头警告
- 罐箱 6-9 亿美元"增速10-15%"是**最高增长但规模最小**——把宝押在最小细分上，需说明为什么

**工程师（可落地）**：
- 两大合规窗口（加油站防渗/SIS改造）**驱动逻辑清晰**，但"执行率5-8%未完成"的具体数据来源未标
- 波导丝"国产化率25-30%"来源模糊（"行业供应链调研"），是红线依据却不够硬

**产品（决策质量）**：
- **市场调研深度明显好于竞争对手章节**——有规模/增速/驱动/风险，这轮补了竞对表后均衡多了
- 但"中国可竞争市场40-50亿元"这个核心数字**缺推导过程**——怎么从166亿到40-50亿的？要展示排除法

**审计师（数字一致性）**：
- 全球46亿美元（2024）与 2025年50亿美元——CAGR 从2024到2030是5%，但2024→2025是+8.7%（46→50），**增速不一致**，需解释（首年提速？）
- 中国166亿(2024)→172亿(2025) +3.6%，与全球5%增速不同步，口径差异需说明

### 圆桌结论
**市场调研整体评分 7.5/10（补竞对表后从6.5升）**：
- ✅ 好的：规模/增速/驱动/风险/口径诚实标注，比竞对章节扎实
- ❌ 缺的：① 中国"可竞争市场40-50亿"缺推导过程 ② 政策回落未进财务情景 ③ 增速口径不一致（46→50 vs CAGR 5%） ④ 部分来源模糊（波导丝国产化率/执行率）

### 修订建议
| 优先级 | 修订 |
|--------|------|
| P0 | 推导"中国可竞争市场40-50亿"的排除法（从166亿减外资聚焦/水位监测等） |
| P0 | 政策回落纳入悲观情景（2028后收入降速） |
| P1 | 增速口径统一（解释2024→2025 8.7% vs CAGR 5%的差异） |
| P1 | 波导丝国产化率/执行率来源加固（标(E)或补调研） |
