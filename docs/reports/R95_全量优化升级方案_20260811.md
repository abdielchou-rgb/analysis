## 五、双模式架构（设计）

### 训练模式（质量优先）
```
串行执行 → 每步 checkpoint + 详细日志
→ Gate 92项全量 + 失败定向修复
→ 假设驱动验证器介入
→ 全链路 trace
→ 适合：首份报告 / 高险决策 / 新类型
```

### 性能模式（速度优先）
```
DAG 并行执行 → 无损确定性模块 + 弹性 LLM Agent
→ 关键 Gate (error级快速) + 缓存命中
→ 熔断 / 降级 / 跳过
→ 聚合指标 + 异常告警
→ 适合：批量标准报告 / 定期更新
```

### 编排载体：LangGraph
```python
state = {
    "asset": "...",
    "report_type": "...",
    "data": {},
    "charts": [],
    "sections": {},

# 节点
```
