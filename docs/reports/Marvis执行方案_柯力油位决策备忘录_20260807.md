## 三、Marvis 执行命令链（核心交付）

### 3.1 训练模式跑（Marvis 主写 + DeepSeek 终审）

```bash
cd D:\2hao-analyst

# STEP 1 补数据（Marvis 采集，我审核后写 enrich JSON）
python scripts/agent_backfill.py template "柯力传感" --out enrich_oil_20260807.json
#   → Marvis 填 7 个锚点数据 + 来源，我复核 source 合规

# STEP 2 回流管线（train 模式：Marvis 写 + DeepSeek 终审合并）
python scripts/run_reports.py "柯力传感" \
    --type decision_memo \
    --mode train \
    --max-attempts 5 \
    --enrich-file enrich_oil_20260807.json \
    --workers 1

# STEP 3 若需要付费快出（perf 模式：DeepSeek 主力）
python scripts/run_reports.py "柯力传感" \
    --type decision_memo \
    --mode perf \
    --max-attempts 3 \
    --enrich-file enrich_oil_20260807.json
```

### 3.2 升级版路由实际生效的节点（train 模式）

| 节点 | provider | 说明 |
|------|----------|------|
| write（论点单元） | **Marvis**（agent_provider） | 免费训练，大量产草稿 |
| skeleton | **Marvis** | 骨架 Marvis 出 |
| merge（合并组装） | **DeepSeek** | 质量红线，永不 Marvis |
| revise（Gate 反馈修订） | Marvis + DeepSeek 抽检 | R67 护栏过滤劣稿 |
| roundtable | **DeepSeek** | 异于训练源 Marvis，防同源偏差 |
| L0 计算 | Python | 图表/排版/校验 0 token |

### 3.3 关键保障（防 R83 事故复发）

```
① 对象锚定：CUSTOM_REQUIREMENT 或 enrich 注入"决策主体=柯力×久通"
② 决策引擎：卡位评分 X.X/5 + 三年投入 1.5-2亿 + 最坏损失≈2亿(0.6倍归母净利)
   → DecisionEngine 已接入，禁止 LLM 自编结论
③ 禁投资评级：R83 最高优先级禁令（增持/买入/目标价/EPS 全禁）
④ 执行摘要强制：进/不进/条件性进 + 卡位评分 + 三年投入 + 最坏损失 + 执行前提
⑤ Gate 门禁：IronGate + 圆桌（异源）双门禁，passed=true 才交付
```

### 3.4 Marvis 需要额外做的（决策备忘录特有）

| 维度 | Marvis 要产出 | 依据 |
|------|--------------|------|
| 市场规模 | 全球+中国油位传感器市场三角验证（46亿美元/166亿元口径交叉） | SAC market_size |
| 投入产出比 | 收入三浪 + 投入拆分 + 敏感性（当期利润 vs 战略期权） | SAC financial_projection |
| 战略卡位 | 卡位评分 X.X/5 + 生产主体三选（自制/外协/子公司承接） | DecisionEngine |
| 衍生价值 | 相邻品类/上游卡脖子延伸（磁致伸缩丝国产化机会） | SAC adjacent_expansion |
| 最坏损失 | 沉没成本金额锚定（≈2亿=0.6倍归母净利） | SAC worst_case_loss |
| 路线图 | 分季度里程碑 + 验收标准 | SAC roadmap |
