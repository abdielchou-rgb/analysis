# 2hao Skill 体系落地（7个skill覆盖全报告类型）

> 日期：2026-08-08
> 触发：用户要求 skill 体系覆盖上市公司/非上市公司等全部报告类型
> 结果：**7 个 skill 创建完成，覆盖 5 类报告 + 2 个共享方法论**

---

## 一、Skill 体系全景

### 报告类型 skills（5 个，对应 SAC）
| Skill | 报告类型 | 核心内容 |
|-------|---------|---------|
| **listed_company_research** | 上市公司研究 | SAC 14维 + 估值纪律（NPV唯一主指标/IRR限定）+ 财务三表 + 护城河/生命周期/五力 |
| **unlisted_company_research** | 非上市公司研究 | 可比融资/股权治理/退出路径/里程碑估值 三口径 + 稀缺性判断 |
| **decision_memo** | 决策备忘录 | FP0意图 + 禁投资评级/目标价 + 决策引擎 + 人类门禁强制 |
| **earnings_notes** | 业绩点评 | 快速响应 + 财务验证 + 预期差 + 单季vs全年口径 |
| **industry_analysis** | 行业深度（共享框架） | 生命周期/波特五力/利润池/竞争/中美竞争/宏观传导/商业模式 七框架 |

### 共享方法论 skills（2 个）
| Skill | 作用 |
|-------|------|
| **author_pose** | 作者姿态：禁止元评论/工作过程/版本迭代语言，只陈述事实结论 |
| **roundtable_review** | 圆桌评审：4角色独立批判（投行/MBB/券商/审计），复算+框架审计+AI扫描 |

## 二、Skill 覆盖矩阵

```
报告类型 → 加载的 skill
├── 上市公司 → listed_company_research + industry_analysis + author_pose + roundtable_review
├── 非上市   → unlisted_company_research + industry_analysis + author_pose + roundtable_review
├── 行业深度 → industry_analysis + author_pose + roundtable_review
├── 决策备忘录 → decision_memo + industry_analysis + author_pose + roundtable_review
└── 业绩点评 → earnings_notes + author_pose
```

## 三、每个 skill 的关键纪律（实战沉淀）

- **估值**：经营期 NPV 唯一主指标、IRR 加限定、悲观情景算术自洽
- **框架**：生命周期/五力/利润池按行业适配注入（防漏/防错配）
- **写作**：author_pose 禁三类 AI 痕迹，用 verify_report 一键校验
- **评审**：roundtable_review 独立 Subagent 多角色批判，复算覆盖"披露值之间隐含关系"

## 五、一句话总结

**2hao Skill 体系落地：5 个报告类型 skill（上市/非上市/决策备忘录/业绩点评/行业框架）+ 2 个共享方法论 skill（作者姿态/圆桌评审），覆盖全部 SAC 报告类型。** 每个 skill 打包方法论 + 纪律 + 校验，解决"框架靠记性"（油位 v4.6 漏波特五力）和"圆桌手动触发"（Marvis 三轮才查全）两个实战痛点。后续写报告自动加载对应 skill。
