## 三、最值得的 5 个（一句话）

1. **MinerU**：研报/财报 PDF → 结构化数据，数据源质变
2. **numpy-financial**：IRR/NPV 用标准库，告别手写（替换 uncertainty/vc_return 的 IRR）
3. **Qlib**：量化因子/回测，2hao 已有 qlib_bin 可深化
4. **Plotly**：图表从静态升级交互式（投委会可操作）
5. **sentence-transformers**：fact_base 从 ngram 升级真 embedding（语义检索）

## 四、开源项目生态（awesome-quant 等）

- **awesome-quant**：量化库大全（wilsonfreitas）——2hao 可扫描补充缺失的量化能力
- **backtrader/vnpy**：回测框架（对比 Qlib）
- **jquantstats**：组合绩效分析（夏普/回撤）
