## 二、PE/VC 视角：缺什么（按重要性）

### 缺口1：投资论题（Investment Thesis）——最重要
**PE/VC 第一问**：为什么这家公司能赢？市场多大、为什么是它、壁垒多深、3-5年后什么位置。
**2hao 现状**：有 SAC 维度但无"论题假设"结构。
**缺**：
- 论题假设（3-5 条"我们相信X"）
- 证伪条件（什么数据会推翻论题）
- 独特性（为什么不是别人）

### 缺口2：里程碑-资金链（Runway / Capital Needs）
**VC 核心**：公司账上现金能撑多久（runway）？到下一里程碑要烧多少、何时融资、融资后稀释多少。
**2hao 现状**：无。
**缺**：
- 现金消耗率（burn rate）/ 账上现金 / runway（月）
- 融资需求表（到里程碑需多少钱、何时融）
- 稀释测算（融多少轮、每轮稀释多少 → 当前持股最终被稀释到多少）

### 缺口3：资本结构（Cap Table / 优先股/清算）
**PE/VC 决策**：看 cap table（谁持股、优先股条款、清算优先权、参与分红）。
**2hao 现状**：只算"创始人持股/质押"，无资本结构。
**缺**：
- Cap table（创始人/团队/机构/期权池 各占多少）
- 优先股条款（清算优先倍数/参与权）
- 稀释后创始人控制权（是否还能控制）

### 缺口4：下轮融资假设（Next Round）
**VC 回报模型核心**：这一轮估值 vs 下一轮估值 = 回报倍数。下一轮上不去，本轮回报归零。
**2hao 现状**：有"下一轮融资"退出路径，但无"下一轮估值假设"。
**缺**：
- 下一轮估值区间（可比融资/市场倍数）
- 本轮到下一轮的回报倍数（MOIC）
- 如果下一轮估值持平/下降（down round）→ 回报归零/为负

### 缺口5：创始人尽调（Founder Diligence）
**PE/VC 隐形决策**：投的是人——创始人动机、能力、历史、诚信。
**2hao 现状**：无。
**缺**：
- 创始人背景（行业经验/连续创业/技术出身）
- 动机（为何创业/为何融资）
- 历史（过往项目结果/声誉）
- 诚信风险（财务造假/关联交易/隐瞒）

## 三、PE/VC 回报模型：2hao 缺的"决策引擎"

顶级 PE/VC 的回报判断 = **本轮投入 / 终局价值 × 概率**：

```
VC 模型：
  投入 = 本轮金额 × 稀释后持股
  终局价值 = 退出时估值（IPO/并购/下轮）
  回报 MOIC = 终局价值 × 持股 / 投入
  风险 = 1 - 退出概率

2hao 有：估值区间、退出路径概率
2hao 缺：投入×稀释、终局价值、MOIC、概率调整回报
```

**缺一个 `vc_return_model`**：把估值+资本结构+退出概率整合成"回报倍数 MOIC + IRR"——这才是 PE/VC 拍板的依据。

## 四、补齐建议（对标顶级 VC 方法）

### P0（最核心）
1. **投资论题模块**：3-5 条"我们相信X"假设 + 证伪条件 + 独特性
2. **Runway 资金链**：burn rate / cash / runway（月）+ 融资需求 + 稀释测算
3. **VC 回报模型**：投入×稀释×终局估值×概率 → MOIC/IRR

### P1
4. **资本结构分析**：cap table + 优先股 + 清算优先权 + 稀释后控制权
5. **下一轮估值假设**：下轮区间 + 本轮回报倍数 + down round 情景

### P2
6. **创始人尽调**：背景/动机/历史/诚信四维评分
7. **里程碑融资映射**：每个里程碑对应"需融资多少/稀释多少"
