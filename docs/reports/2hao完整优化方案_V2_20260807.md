## 第一编 升级总纲：一句话 + 三大转变

**一句话**：从"系统对自己负责"（数据真/分析深/像人/可审计）升级为"**系统对用户负责**"（答对题 + 数据真 + 可回溯 + 用户纠偏）。

**三大转变**：

| 转变 | 从 | 到 |
|------|-----|-----|
| ① 意图 | 写满 SAC 模板 | **回答委托方必答问题**（FP0） |
| ② 架构 | 单管线 | **光谱选择**（管线/工作台/门禁） |
| ③ 供能 | 单通道 | **三通道 + 节点级路由** |

## 第二编 宪法层升级（FP）

### 2.1 新增 FP0：意图第一公民（最高优先级）
```
谁读 / 决策点 / 必答问题 清单确认 → 报告结构由必答问题驱动
Gate 加意图符合性检查（必答问题被回答）
用户纠偏 > 任何自动评审
否决：结构正确但没回答用户问题 = 未通过
```

### 2.2 新增 FP8：路径光谱化
```
批量/标准化 → 确定性管线（E2E+SAC+IronGate）
深度/个性化 → 工作台（数据层+Claude直接写+用户审核）
高险决策   → 工作台+强制人类门禁+双向溯源
选择必须可解释
```

### 2.3 升级现有 FP
- **FP2a**：数据加 intent 归属（每条标注回答哪个必答问题）
- **FP5**：加纠偏学习（用户纠偏 → 规则 → 下次少犯）
- **FP6**：加意图回溯（结论 → 必答问题 → 数据源）
- **FP7**：加意图不确定降级（必答问题不明 → 出问题清单而非硬写）

## 第三编 架构层升级

### 3.1 任务路由器（TaskRouter）
```
输入：报告类型 / 意图强度 / 风险等级 / 批量 or 单份
输出：执行路径（管线 / 工作台 / 工作台+门禁）
decision_memo + 老板拍板 → 工作台+门禁
批量 listed → 管线
```

### 3.2 工作台执行器（WorkbenchExecutor）
```
① 意图对齐（委托方问题清单）
② 数据准备（数据层算好，分级标注）
③ AI 直接写（上下文模板：业务命题+数据+约束+示例）
④ 程序校验（verify_report：算术/实体/一致性/渲染）
⑤ 人类门禁（强制：进/不进 + 修改意见 → 决策审计）
⑥ 迭代沉淀（纠偏 → fact_base）
```

### 3.3 共享底层（两路径复用）
```
数据层：akshare / enrich / 决策引擎 / 财务模型 / R87 分级
校验层：verify_report（算术/实体/一致性/渲染）
记忆层：learning_loop + fact_base + 纠偏规则
```
