## 三、P3-3 圆桌信誉机制【已落地】

### 新增 `core/reviewer_reputation.py`
- `record_review(role_id, report_id, score, claims)`：记录各角色评审 + 关键判断
- `update_from_backtest(report_id, accuracy)`：回测后更新信誉分
  - accuracy ≥0.6 → 加分（+5）
  - accuracy <0.4 → 扣分（-8，扣比加多防乱猜）
  - 0.4-0.6 → 不调整
- `get_weight(role_id)`：信誉加权（0.5-1.5 倍）
- 信誉分下限 20（保留参与）

### 接线 `core/tools/critic_panel.py`
- `ConsensusOrchestrator.evaluate`：每角色评审记录进信誉库
- 最终分用信誉加权（信誉高权重高，修正激励倒挂）
- 失败静默回退等权平均

### 验证
- record_review / update_from_backtest / get_credit / 防重复验证 ✅
- stats 正确（reviews=1 / correct=1 / credit=105）✅
