# Skill 框架深度优化：对照顶级报告/论文找缺口

> 日期：2026-08-08
> 方法：盘点 2hao 现有框架（16 YAML + 5 SAC + 8 方法论）vs 顶级投行报告 + 2026 论文框架
> 结论先行：**2hao 框架体系"广度够、深度不足"——价值投资/竞争框架齐全，但缺 4 类顶级框架：①决策级（情景规划/实物期权/决策树）②质量级（M-Score/盈余质量/审计核查）③增长级（S曲线/渗透率模型/平台网络效应）④量化级（预期差/因子/回测验证）。**

## 一、现有框架 vs 顶级报告的差距

### 已覆盖（广度够）
| 类别 | 框架 |
|------|------|
| 价值投资 | 护城河/质量投资/价值驱动/安全边际/预期投资 |
| 竞争分析 | 竞争优势三维/波特五力/竞争格局 |
| 咨询方法 | 问题树/金字塔/假设驱动 |
| 行业分析 | 生命周期/利润池/商业模式/信号与噪声 |

### 缺失（深度不足）
| 类别 | 顶级框架 | 2hao 状态 |
|------|---------|----------|
| **决策级** | 情景规划（Shell/麦肯锡 3-5 情景）、实物期权、决策树 | ❌ 有"三情景"但非正式框架 |

| **资本运作** | 并购协同量化、DCF敏感性、概率加权估值 | 🟡 有 DCF 但并购协同弱 |

## 二、顶级报告用而 2hao 缺的框架（按价值）

### 1. 情景规划（Scenario Planning）
**顶级用法**：高盛/大摩用 3-5 情景 + 概率 + 触发信号，不是简单"乐观/基准/悲观"拍概率。
**2hao 缺口**：三情景概率是拍的（30/50/20），缺"触发信号"（什么数据会导向哪情景）。
**优化**：情景加**触发指标**（政策执行率/订单/渗透率），情景概率由信号驱动而非拍脑袋。

### 2. M-Score 盈余操纵检测（Beneish）
**顶级用法**：四大会所查盈余质量用 M-Score（8 变量：应收/存货/毛利率/资产质量/折旧/费用/杠杆/应计）。
**2hao 缺口**：有审计核查模块，但无 M-Score 量化。
**优化**：财务章节加 M-Score 计算（应收增速/存货增速/毛利率异常/应计比率），量化盈余操纵风险。

### 3. S曲线/技术采用
**顶级用法**：BCG/麦肯锡用 S 曲线判断渗透率阶段（导入/起飞/饱和）。
**2hao 缺口**：有生命周期四阶段，但无渗透率 S 曲线量化。
**优化**：行业分析加渗透率 S 曲线（当前渗透率/增速→阶段定位），比"成熟/成长"定性更精确。

### 4. 实物期权（Real Options）
**顶级用法**：大摩对多阶段投资用实物期权（扩张/放弃/延迟/转换期权）而非单点 NPV。
**2hao 缺口**：油位用 BS 期权近似，但未区分期权类型。
**优化**：估值加**四类实物期权**（扩张/放弃/延迟/转换）——油位"进入新市场"本质是扩张期权+放弃期权组合。

### 5. 并购协同量化（McKinsey）
**顶级用法**：并购分析把协同拆 revenue/cost/tax 三源，逐项量化。
**2hao 缺口**：consolidation 模块有并购估值，但协同量化弱。
**优化**：并购场景加协同三源拆分 + 整合风险概率。

### 6. 预期差/一致预期模型
**顶级用法**：中金/高盛用"市场预期 vs 实际"量化预期差（EPS 修正/目标价隐含增长）。
**2hao 缺口**：consensus 数据有，但无预期差框架。
**优化**：个股研究加**预期差量化**（一致预期 EPS/目标价隐含增速 vs 我们的测算）。

## 三、论文级框架（2026 前沿）

| 论文/方向 | 核心 | 2hao 优化 |
|----------|------|-----------|
| **Reflexion/自我反思** | agent 从失败中学习 | learning_loop 加"失败-反思-规则"闭环（已有雏形） |
| **Tree of Thoughts** | 多路径推理+评估 | 决策分析加"多假设并行+评估剪枝" |
| **Retrieval-Augmented Reasoning** | 检索增强推理链 | 事实库接入推理链（每步引用来源） |
| **Uncertainty Quantification** | 输出不确定性校准 | 预测加置信区间 + 校准（如预测区间 vs 实际） |

## 四、优先级建议

| 优先级 | 优化 | 解决 | 成本 |
|--------|------|------|------|
| **P0** | 情景加触发信号 | 三情景概率是拍的 | 低 |
| **P0** | M-Score 盈余质量 | 财务缺量化质量检测 | 中 |
| **P1** | 渗透率 S 曲线 | 生命周期定性 | 中 |
| **P1** | 实物期权四类 | 油位期权近似 | 中 |
| **P2** | 预期差量化 | 一致预期未用 | 中 |
| **P2** | 并购协同三源 | consolidation 弱 | 中 |
| **P2** | 不确定性校准 | 预测无区间 | 高 |

## 六、一句话总结

**2hao skill 框架"广度够、深度不足"——价值投资/竞争框架齐全，但缺 4 类顶级框架：决策级（情景触发/实物期权）、质量级（M-Score/盈余质量）、增长级（渗透率 S 曲线）、量化级（预期差/不确定性校准）。** 优先级最高的是**情景加触发信号**（油位三情景概率是拍的）和 **M-Score 盈余质量**（财务缺量化质量检测）。补上这些，skill 从"框架清单"升级为"顶级机构级分析工具箱"。
