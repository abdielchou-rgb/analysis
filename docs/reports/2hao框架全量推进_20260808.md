## 一、新引擎清单

### 1. scenario_engine（情景触发）
```
顶级打法：高盛/大摩用"触发指标"驱动情景概率，非拍脑袋
实现：三/多情景 + 每情景触发信号 + 信号值 → 概率修正
验证：悲观信号命中 → 悲观概率 20%→45%；乐观信号 → 乐观 30%→52.5%
```

### 2. mscore_engine（Beneish M-Score 盈余质量）
```
顶级打法：四大会所查盈余操纵用 M-Score（8 变量）
实现：DSRI/GMI/AQI/SGI/DEPI/SGAI/LVGI/TATA → M-Score，> -1.78 疑似操纵
验证：正常样本 -2.34（正常）；操纵样本 -0.87（高风险，应收/应计异常提示）
```

### 3. s_curve_engine（渗透率 S 曲线）
```
顶级打法：BCG/麦肯锡用 S 曲线定位渗透阶段
实现：渗透率+增速 → 导入(<10%)/起飞(10-50%高增)/扩张(50-80%)/饱和(>80%) + 策略
验证：罐箱(5%,15%) → 导入期；油位整体(70%,5%) → 扩张期
```

### 4. s_curve_engine real_option（实物期权）
```
顶级打法：大摩区分扩张/放弃/延迟/转换期权
实现：BS 近似——扩张/延迟=看涨，放弃=看跌，转换=价差
验证：油位场景扩张期权 1449 万、放弃期权 141 万、延迟期权 1277 万
```
