# 2号分析师 胜任力自查报告（R95）

> 日期：2026-08-11 · 对标五个专业角色：顶级投行分析师 / 顶级券商分析师 / MBB 咨询顾问 / 四大会计师 / 顶级律所合伙人

---

## 核心结论

> **2hao 在"分析框架+计算+门禁"层面已达到可交付水平，但在"商业判断+策略建议+合规判断"层面仍有本质缺口。**

- 可胜任：投行/券商 **初级到中级分析师**（80% 产能可自动化）
- 有条件胜任：MBB **分析岗**（框架层面，缺商业直觉）
- 不可胜任：四大**审计经理**/ 律所**合伙人**（职业判断/专业怀疑/合规裁量不可算法化）

---

## 对标矩阵

### R1: 顶级投行分析师（高盛/摩根/摩根士丹利）

| 核心能力 | 2hao 水平 | 差距 | 根因 |
|----------|----------|------|------|
| 行业深层研究框架 | ✅ | 完整（SAC + 方法论库） | - |
| 估值建模（DCF/M&A/LBO） | ✅ | 完整（DCF/可比/SOTP/期权/EVA） | - |
| 财务三表/勾稽/预测 | ✅ | 完整 | - |
| 反共识/多维判断 | ✅ | R93 判断驱动框架 | - |
| **交易层级判断（买/卖/时点/仓位）** | ⚠️ | 缺执行层面决策 | 没有模拟盘/交易记录验证 |
| **客户沟通/路演/Q&A 准备** | ❌ | 不可替代 | 这需要人类判断力+语境感知 |
| **网络/关系/信息流优势** | ❌ | 不可替代 | 这是人类的护城河 |

**结论**：可替代投行分析岗 80% 产能（报告/建模/数据），不可替代 VP/MD 层级（关系/判断/谈判）。

---

### R2: 顶级券商分析师（中金/中信）

| 核心能力 | 2hao 水平 | 差距 | 根因 |
|----------|----------|------|------|
| 产业链深度拆解 | ✅ | 供应链/瓶颈/利润池全覆盖 | - |
| 政策传导链 | ✅ | 政治周期/执行率/补贴阶段 | - |
| 上市公司财务诊断 | ✅ | Dupont/AltmanZ/EVA/M-Score | - |
| **推荐标的的跟踪验证** | ⚠️ | 缺少"推荐→回顾→改评级"闭环 | prediction_loop 有骨架未运转 |
| **实地调研/管理层触达** | ❌ | 不可替代 | 人获取的信息不可被替代 |
| **行业人脉/产业链验证** | ❌ | 不可替代 | 这是核心壁垒 |

**结论**：可替代 70% 案头工作，不可替代 30% 的调研/关系/跟踪验证。

---

### R3: MBB 顶级咨询顾问

| 核心能力 | 2hao 水平 | 差距 | 根因 |
|----------|----------|------|------|
| 问题树/MECE 拆解 | ✅ | SAC 问题树 + FP8 元认知选择 | - |
| 利润池/价值链分析 | ✅ | McKinsey 方法论注入 | - |
| So What 三层链 | ✅ | Gate 检查 + writing_rhythm | - |
| **假设驱动的结论先行** | ✅ | HypothesisVerifier + Bold Call | - |
| **CEO-ready 建议/战略决策** | ⚠️ | 缺"战略可行性与组织能力"判断 | LLM 无法评估组织的执行能力 |
| **同理心/政治敏感性** | ❌ | 不可替代 | 组织动力学不可算法化 |

**结论**：可替代分析岗（85%），不可替代合伙人/总监层级（15% 战略性判断）。

---

### R4: 四大会计师事务所（审计/税务/咨询）

| 核心能力 | 2hao 水平 | 差距 | 根因 |
|----------|----------|------|------|
| 财务报表审计程序 | ⚠️ | 有 M-Score/fraud_signals 但无完整审计程序 | 缺底稿结构/实质性程序 |
| 收入确认质量判断 | ⚠️ | 有 business_logic_gate 但不够 | 缺乏合同审查/行业惯例知识 |
| 内部控制评估 | ❌ | 无模块 | 无法评估控制环境/控制活动 |
| **职业怀疑/专业判断** | ❌ | IAS 标准的"职业判断"不可被算法替代 | 法律/审计的责任归属问题 |
| **底稿/证据链/审计轨迹** | ❌ | 有 evidence_chain 但无审计级要求 | 需要满足监管要求 |

**结论**：不可替代。审计的核心是**职业怀疑+责任归属**，不是分析框架。

---

### R5: 顶级律所合伙人（PE/并购/资本市场）

| 核心能力 | 2hao 水平 | 差距 | 根因 |
|----------|----------|------|------|
| 交易结构分析 | ❌ | 无模块 | 法律文件审查不可自动化 |
| 尽职调查 | ❌ | 无法律尽调管线 | 合同条款/合规风险需人工判断 |
| 监管合规判断 | ❌ | 无模块 | 监管裁量/案例法不可预测 |
| 谈判策略 | ❌ | 不可替代 | 这是人类的核心能力 |

**结论**：完全不可替代。法律判断的核心是**案例法推理+裁量权+谈判**，不是分析框架。

## 系统性缺口总结

| 缺口类型 | 严重性 | 能否修复 |
|----------|--------|----------|
| **预测跟踪闭环**（推荐→回顾→改评级） | P1 | ✅ 接线 prediction_loop |
| **审计级底稿结构** | P2 | ✅ 可扩展 |
| **交易执行/模拟盘** | P2 | ✅ 可接 QMT |
| **多模型辩论（独立判断收敛）** | P1 | ⚠️ 需要接线 |
| **战略执行可行性判断** | P0 | ❌ LLM 不具备组织经验 |
| **职业怀疑/专业判断** | P0 | ❌ 责任归属问题 |
| **客户关系/谈判/路演** | P0 | ❌ 人类核心壁垒 |

---

## 最终一句话

> **2hao 可以替代"分析师"（分析+建模+写作），但替代不了"顾问/审计/律师"（判断+关系+责任）。这是好事——意味着目标市场清晰、可衡量、可交付。**
