## 一、新增模块

### core/compute/llm_cache.py
```
cached_llm(prompt, cache_key, ttl)   # diskcache 缓存 LLM 响应，命中免调（省 token）
retry_llm(prompt, max_retries, delay) # tenacity 重试，LLM 调用容错
```

### 用途
- **省 token**：同 prompt 命中缓存免重调（如重复的评分/分类调用）
- **容错**：LLM 瞬时故障自动重试（3次，间隔1s）
