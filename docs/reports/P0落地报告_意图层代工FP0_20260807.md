## 二、intent_gate 意图符合性门禁【新模块】

### 新增 `core/intent_gate.py`
- `check_intent_compliance(text, plan)`：必答问题是否被回答（≥60% 算通过）
- `intent_gate_node()`：E2E 管线节点（挂 validate 后）
- CLI 入口：`python -m core.intent_gate --report x.md --requirement "..."`

### 接线 `pipeline/e2e_orchestrator.py`
- validate 节点：IronGate 后跑意图符合性
- **decision_memo → 阻断**（意图不过 = 未通过，进 failures）；其他类型 → advisory
- 意图计划从 context/requirement 重新派生（不依赖 section_writer 状态）

### 验证
- 缺失投入产出 → coverage 0.33 → **阻断** ✅
- 覆盖全部 → coverage 1.0 → 通过 ✅

## 三、contract_manufacturing 代工测算【新模块】

### 新增 `core/compute/contract_manufacturing.py`
柯力油位场景直接需要的投入产出测算，四块：
1. **成本拆分**：单位贡献/贡献毛利率
2. **盈亏平衡**：平衡量 + 产能利用率（固定成本/单位贡献）
3. **转移定价合规**：ALP 独立交易原则合理价格区间
4. **战略期权价值**：Black-Scholes 近似（进入新市场的真实期权）

含：NPV(5年)/IRR/静态回收期/爬坡曲线/结论+依据。

### 验证（柯力假设：年产5万只/单价2000/变动1400/固定投入3000万）
```
盈亏平衡量: 33,333只/年（67%产能）
NPV(5年): 5,113万元, IRR: 56.4%
静态回收期: 2.8年
战略期权价值: 2,130万元（总价值 7,243万）
结论: 建议进入（条件性：订单承诺≥盈亏平衡量）
```
