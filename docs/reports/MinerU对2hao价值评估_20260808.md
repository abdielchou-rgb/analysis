# MinerU 对 2hao 的价值评估

> 日期：2026-08-08
> 对象：opendatalab/MinerU（顶级 PDF 解析工具）

---

## 一、MinerU 是什么

**opendatalab/MinerU**：把复杂文档（PDF/Office）转成 LLM 就绪的 markdown/JSON，服务 Agentic 工作流。

核心能力：
- **PDF 解析**：版面分析 + 文本提取 + **表格识别** + 公式
- **OCR**：扫描版文档
- **输出**：markdown/JSON（LLM 直接用）
- **MinerU-Ecosystem**：配套 skill 生态
- **MinerU2.5-Pro**：专用解析模型（1.2B）

---

## 二、对 2hao 的价值（高）

### 价值点 1：研报/财报 PDF 解析（数据源关键）
2hao 痛点：`baseline_pdf_extractor` / `report_extractor` 中文研报 OCR 弱，表格/公式解析差。
MinerU 解决：
- **券商研报 PDF** → markdown（含表格结构）
- **上市公司财报** → JSON（三表/数据点直接提取）
- 扫描版年报 → OCR

**直击 2hao 数据源瓶颈**——研报/财报是分析的事实基础，解析质量决定分析质量。

### 价值点 2：表格/公式识别（财务数据关键）
- 三表（资产负债表/利润表/现金流）是表格，MinerU 表格识别强
- 财务公式（DCF/EPS 计算）识别
- → 直接喂给 data_caliber / three_statement 勾稽

### 价值点 3：Agentic 就绪输出
- markdown/JSON 直接进 enrich-file / fact_base
- 比现有 extractor 的"文本+正则"高一个量级

---

## 三、对比 2hao 现有方案

| 维度 | 现有 baseline_pdf_extractor | MinerU |
|------|---------------------------|--------|
| 文本提取 | 基本 | 强（版面+OCR） |
| 表格识别 | 弱（正则） | 强（结构保留） |
| 公式 | 无 | 有 |
| 扫描版 | 弱 | 强（OCR） |
| 输出格式 | 文本 | **markdown/JSON（LLM 就绪）** |

**差距**：MinerU 在研报/财报解析上全面领先 2hao 现有方案。

---

## 四、接入建议

### P0：研报解析增强
```
用 MinerU 替换/增强 baseline_pdf_extractor：
  券商研报 PDF → markdown → 提取数据点 → fact_base
  上市公司财报 PDF → JSON → 三表勾稽
```

### 实施路径
1. 接入 MinerU（本地部署或 API）
2. 写适配层：MinerU markdown/JSON → 2hao enrich-file schema
3. 研报解析管线：PDF → MinerU → 数据点 → fact_base/data_basement

**MinerU 对 2hao 价值高（🔴）——它是研报/财报 PDF 解析的顶级方案，直击 2hao 数据源瓶颈（现有 extractor 中文研报/表格/OCR 弱）。接入后：券商研报→markdown、财报→JSON，直接喂 fact_base/data_basement，数据质量质变。** 建议 P0 接入，写适配层转 enrich-file schema。
