## 一、report_generator（Claude 全量调用入口）

`core/report_generator.py` 统一编排：

```
1. task_router 选路径（管线/工作台/门禁）
2. 按报告类型加载 skill 清单
3. 按报告类型注入框架引擎（compute_summaries）
4. context_compiler 组装上下文（含作者姿态+框架适配）
5. 写作（Claude 用 ctx 生成）
6. verify_report 门禁（工作过程/元评论/身份/下行）
7. LLM rubric 软质量评分
8. 圆桌评审（roundtable_ready）
```

## 二、skill 清单（按报告类型全量加载）

| 报告类型 | skill |
|---------|-------|
| listed_company | listed+industry+author+roundtable |
| unlisted_company | unlisted+industry+author+roundtable |
| decision_memo | decision+industry+author+roundtable |
| industry_deep | industry+author+roundtable |

## 三、框架引擎（按报告类型全量注入）

| 报告类型 | 引擎 |
|---------|------|

## 四、门禁 + 圆桌串联

- `verify_report_text()`：写作后门禁（工作过程/元评论）+ LLM rubric
- `roundtable_review` skill 自动加载（roundtable_ready=True）
