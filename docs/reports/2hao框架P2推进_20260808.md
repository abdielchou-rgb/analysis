## 一、新引擎清单

### 1. expectation_gap_engine（预期差量化）
```
顶级打法：中金/高盛用一致预期 vs 我们的测算量化预期差
实现：多指标 {consensus, ours, weight} → 综合预期差 + 市场低估/高估判断
验证：EPS+目标价 我们的高于市场 → 市场低估（+15%）
```

### 2. ma_synergy_engine（并购协同三源）
```
顶级打法：McKinsey 拆收入/成本/税三源逐项量化
实现：交叉销售收入协同 + 成本节省 + 税节省 + 整合风险 + 协同NPV
验证：目标收入1亿场景 → 收入协同30万+成本200万+税50万/年，NPV 561万
```

### 3. uncertainty_calibration（不确定性校准）
```
顶级打法：预测给置信区间 + 历史命中率校准
实现：forecast_interval（z×base×uncertainty）+ calibrate（命中率 vs 声明置信度）
验证：油位NPV 3116±20% → 2091~4141；历史100%命中 → 区间过宽可收窄
```
