## 二、本轮修复（3 项检查器 bug + 2 处报告标注）

### 1. data_traceability 来源覆盖 7% → 75%（修复检查器）
- **根因**：报告 73% 实质段落带 `(A)/(E)/(F)/(B)` 四元组标注（STANDARDS.md 要求），
  但检查器只认"来源/据/年报"等旧式词 → 覆盖率仅 7%
- **修复**：`_check_data_traceability` 来源识别正则加入 `(A)/(E)/(F)/(B)` 标注识别，
  `(A)` 实际标注深度计 3（官方/年报级）

### 2. honest_gap 54 → 14 处（修复检查器）
- **根因**：来源标注正则只认半角 `(A)`，不认全角 `（A）`（报告 40 处全角标注）
- **修复**：`_check_honest_gap` 来源正则兼容全角括号
- **报告补标注**：蓝箭航天估值补 `（220亿元，E）`

### 3. layout docx 空段落 4/9 → 0（修复检查器）
- **根因**：`_check_layout_quality` 用 `self_closing_empty` **总数**当"连续空段"，
  把全文分散的表格后空段（每个表格后一个 `<w:p/>`）误判成"连续 N 个"
- **修复**：按 XML 中自闭合空段的**实际连续位置**计算 max_run

### 4. 重新导出 docx
- 旧 docx（7/26）与修复后 md 不同步，用 `scripts/md_to_docx.py` 重新生成
