## 三、MinerU 扫描版 OCR 的质量分层（实测诚实评估）

1. **中文印刷清晰扫描版 → 优秀**（中金汽车业，表格完美还原）
2. **英文扫描版 → 噪声大**（高盛清华MBA，OCR 乱码如 "TheGoldmnhps..."）
3. **含内嵌广告页的扫描版 → 广告文字被当正文**（中金估值方法，混入"海途内推包offer"）

**原因**：云 flash 用轻量 OCR 模型（免token限20页）。对高价值/英文/含噪扫描版，应换 **Precision 模式**（需 MINERU_API_TOKEN）或**本地引擎**（`pip install mineru`，质量最高）。
