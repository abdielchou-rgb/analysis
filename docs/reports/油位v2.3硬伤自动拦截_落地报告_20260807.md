## 一、新增三项检测（core/data_caliber.py）

### 1. 下行一致性检测 `detect_downstream_conflicts`
拦截"最坏敞口 vs 止损线 vs 悲观NPV"口径不一致。
```
规则：止损触发点 > 最坏敞口 × 1.10 → error
      悲观NPV 为正但与最坏敞口并存 → warning
油位v2.3实例：最坏敞口2100万 < 止损线2450万 → 拦截 ✅
```

### 2. 时间线矛盾检测 `detect_timeline_conflicts`
拦截"认证周期 vs 盈亏平衡/量产"时间线冲突。
```
规则：认证月数 > (启动→盈亏平衡间隔月数 + 3) → error
      支持 中文季度（一二三四）+ Q1-4 + 12-18个月区间（取中值15）
油位v2.3实例：认证15个月 vs 2026Q3→2027Q2 仅9个月 → 拦截 ✅
```

### 3. 假设集中度检测 `detect_assumption_concentration`
识别"少数假设驱动大部分价值"，强制压力测试。
```
规则：价值 ≥60% 由少数假设驱动 → warning（需压力测试+季度复核）
油位v2.3实例：项目价值80%由毛利率+罐箱渗透率驱动 → 拦截 ✅
```

### 一站式入口 `run_downstream_checks`
三个检测合并，任一 error → passed=False。

## 二、接线 IronGate 门禁
