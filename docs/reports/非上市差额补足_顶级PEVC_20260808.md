> 结论先行：**2hao 非上市分析是"财务估值"（PS×营收），顶级 PE/VC 是"十大维度打分"（市场20%/痛点15%/团队20%/数据15%/壁垒10%...）。差额最大在 4 处：投资论题、团队尽调、产品运营数据、资本结构/回报模型。**

## 二、顶级 PE/VC 评估维度（调研结果）

### 红杉/高瓴/IDG 等 VC 十大评估维度（权重）

| 维度 | 权重 | 评估 |
|------|------|------|
| **市场空间** | 20% | TAM够大？增速>GDP 2倍？结构性变化？ |
| **痛点-方案匹配** | 15% | 痛点真实高频刚需？方案好10倍（非10%）？ |
| **商业模式** | 15% | 赚钱方式？LTV/CAC>3？单位经济模型？ |
| **团队** | **20%** | 创始人洞察力/领导力/学习力；团队完整；共事经历；股权合理 |
| **产品运营数据** | 15% | 用户增长/留存/转化/ARR/NDR（成长期硬道理） |
| **竞争壁垒** | 10% | 护城河：专利/网络效应/规模/品牌/迁移成本 |
| **融资用途与估值** | 5% | 融资额支撑18-24月？估值与阶段匹配？ |
| **退出路径** | 5% | IPO/并购/老股转让；5-7年 |
| **风险应对** | 3% | 坦诚风险+应对 |
| **呈现质量** | 2% | 15-25页，逻辑清晰 |

### 大摩/华平（PE）补充
- **资本结构**：cap table、优先股、清算优先权、稀释
- **回报模型**：投入×持股×终局估值×概率 → MOIC/IRR
- **Runway**：烧钱率/账上现金/能撑多久

## 三、差额补足（2hao 缺 vs 顶级有）

### 缺口1：投资论题（为什么赢）——VC 决策核心
**顶级**：3-5 条"我们相信X"假设 + 证伪条件 + 独特性
**2hao**：无论题结构
**补**：`vc_thesis` 模块——论题假设 + 证伪条件 + 独特性

### 缺口2：团队尽调（投的是人，权重最高 20%）
**顶级**：创始人洞察力/领导力/学习力；团队完整；共事经历；股权合理
**2hao**：无团队维度
**补**：`founder_diligence`——创始人四维评分（背景/动机/能力/诚信）

### 缺口3：产品运营数据（成长期硬道理 15%）
**顶级**：用户增长/留存/转化/ARR/NDR
**2hao**：无（只有财务数据）
**补**：`product_metrics`——用户/留存/转化/ARR 指标

### 缺口4：资本结构 + 回报模型（PE 决策依据）
**顶级**：cap table + 优先股 + 清算 + MOIC/IRR
**2hao**：只算创始人持股/质押
**补**：`cap_table` + `vc_return_model`（MOIC/IRR）

### 缺口5：Runway 资金链（VC 风控）
**顶级**：burn rate / cash / runway（月）+ 融资需求 + 稀释
**2hao**：无
**补**：`runway`——现金消耗/账上现金/融资需求
