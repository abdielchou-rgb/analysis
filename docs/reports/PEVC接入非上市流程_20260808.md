# PE/VC 模块接入非上市报告生成流程

> 日期：2026-08-08
> 结果：**7 个 PE/VC 模块接入 workbench_executor，非上市报告自动含投资决策框架，回归全绿**

---

## 一、接入点

`core/workbench_executor.py` step2_data：report_type 为 `unlisted_company` 时自动注入 7 个 PE/VC 模块。

## 二、接入模块

| 模块 | 注入内容 |
|------|---------|
| unlisted_deep（已有） | 可比融资/治理/退出/里程碑估值 |
| **vc_thesis** | 投资论题（市场/壁垒/团队假设 + 证伪条件） |
| **founder_diligence** | 创始人四维评分（背景/能力/动机/诚信） |
| **product_metrics** | 产品运营（用户/留存/ARR/NDR/LTV-CAC） |
| **cap_table** | 资本结构（cap table/优先股/控制权） |
| **vc_return** | VC 回报模型（MOIC/IRR/风险调整） |
| **runway** | Runway 资金链（现金/烧钱/融资缺口） |
| **vc_scoring** | PE/VC 十大维度权重评分 |

## 三、验证

| 项 | 结果 |
|----|------|
| 非上市报告 compute_summaries | ✅ 8 个（估值+7 PE/VC） |
| 各模块注入 | ✅ 全自动 |
| 回归测试（12项） | ✅ 全过 |

## 四、效果

非上市报告现在自动包含 PE/VC 决策框架：
```
投资论题（为什么赢）→ 创始人（投的是谁）→ 产品数据（PMF验证）
→ 资本结构（优先股/控制权）→ VC回报（MOIC/IRR）→ Runway（能撑多久）
→ 十大维度综合评分（投/不投）
```

## 五、一句话总结

**PE/VC 模块已接入非上市报告生成流程：workbench_executor 在 unlisted_company 报告自动注入 7 个 PE/VC 模块（论题/创始人/产品/资本/回报/Runway/十大维度），非上市报告从"财务估值"升级为"完整 PE/VC 投资决策"。** 数据通过 data_dict 传入（缺省用合理默认值），回归全绿。
