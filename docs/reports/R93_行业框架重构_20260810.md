# R93 行业分析框架重构 + 商业航天报告判断驱动重写

> 日期：2026-08-10 · 用户指出行业报告两大错位（开篇预期差分歧、行业报告给个股目标价），要求全面修复

## 一、核心洞察：行业分析的逻辑关系

**行业分析 = 一套行业判断 + 公司作论据验证，不是公司信息堆砌。**

- **上市公司 = "现在"的论据**：行业景气是否已传导到报表？哪个环节先兑现？（铖昌+91%验证"元器件先受益"，中国卫星净利率0.6%验证"整机利润后于元器件"）
- **非上市公司 = "未来"的论据**：一级市场融资/估值/技术押注是行业方向的先行指标（蓝箭220亿+天兵225亿重押回收→验证"2027回收分水岭"判断）
- **两者是行业判断的证据链，不是独立章节**

## 二、框架重构（SAC + skill + Gate）

### SAC industry_deep YAML
- `investable_standouts`：从"选股传导链+评级目标价" → "上市公司作为行业判断的论据验证"
- `unlisted_players`：从"非上市威胁清单" → "非上市作为行业未来信号的论据"
- `core_disagreement`：从"page_2 强制共识vs我们" → "可选，融入资本市场映射"
- `writing_rhythm`：新增 R93 原则——行业评级+受益环节排序（非个股目标价）、公司是判断论据、非上市是未来信号、开头是行业判断非预期差分歧

### industry_analysis skill
- 新增"R93 判断驱动结构"——上市公司验证/非上市前瞻/禁止项

### Iron Gate 同步
- `explicit_conclusion`：industry_deep 加独立分支——行业评级+受益环节+核心判断，不要求个股目标价
- `forecast_presence`：行业报告改判断驱动——有 Bold Call/行业判断即视为有明确观点
- `so_what_chain`：chain_patterns 加判断驱动词（验证/印证/兑现/传导），跳过标题/元信息段

## 三、商业航天报告重写
