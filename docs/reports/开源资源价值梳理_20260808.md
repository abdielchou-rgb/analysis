# 开源资源梳理：对 Claude 有价值 vs 对 2hao 有价值

> 日期：2026-08-08
> 对象：Anthropic knowledge-work-plugins（2.3万星）+ 10 个 skill + awesome-selfhosted + Unlimited-OCR + awesome-design-md
> 方法：逐项判断价值归属（对 Claude 通用 / 对 2hao 分析系统）

---

## 一、整体判断

| 资源 | 对 Claude 通用价值 | 对 2hao 分析价值 |
|------|-------------------|-----------------|
| **Anthropic knowledge-work-plugins** | 🔴 高（通用技能范式） | 🔴 高（参考组织方式，非直接采用） |
| **skill 生态 10 个** | 🟡 部分 | 🟡 少量 |
| **awesome-selfhosted** | 🟡 中（自托管工具库） | 🟢 高（数据源/部署参考） |
| **Unlimited-OCR** | 🟢 高（文档解析） | 🔴 高（研报/财报解析） |
| **awesome-design-md** | 🟡 中（设计规范） | 🟢 高（报告排版） |

---

## 二、对 Claude 有价值（通用能力）

### 1. Anthropic knowledge-work-plugins（最值得学）
**价值**：官方开源的多职能 skill 范式——"无需写代码按公司工具栈定制"。
**2hao 启示**：
- 它证明 **skill 是 Claude 能力扩展的标准方式**（验证了我们 skill 化方向）
- 11 职能覆盖（产品/销售/客服）→ 2hao 应类比覆盖"分析/尽调/写作/评审"
- 定制化思路 → 2hao 的 skill 体系已按报告类型定制（上市/非上市/决策备忘录）

### 2. Unlimited-OCR（百度）
**价值**：无限制 OCR，文档解析能力强。
**2hao 启示**：
- 2hao 有 baseline_pdf_extractor / report_extractor，但**中文研报/财报 OCR 是痛点**
- 接入 Unlimited-OCR → 研报/年报 PDF 解析质量大幅提升
- **对 2hao 高价值**（研报数据提取是数据源关键）

### 3. awesome-design-md
**价值**：Markdown 设计规范。
**2hao 启示**：
- 报告排版规范化（标题层级/图表/表格）
- 2hao 油位 v4.7 已做表格化，此规范可参考

---

## 三、对 2hao 有价值（分析系统增强）

### 1. awesome-selfhosted（自托管工具库）
**价值**：大量自托管工具（数据库/搜索/可视化）。
**2hao 启示**：
- 数据源自托管（避免 akshare 依赖外部）
- 搜索/知识库自托管（替换/增强现有 data_basement）
- **对 2hao 高价值**（数据基础设施）

### 2. skill 生态 10 个（逐项）

| Skill | 对 Claude | 对 2hao |
|-------|----------|---------|
| guizang-social-card | 🟡 卡片生成 | ❌ 不相关 |
| ian-xiaohei-illustrations | 🟢 插画 | ❌ 不相关 |
| dbskill | 🟡 数据库操作 | 🟡 数据访问参考 |
| notebooklm-skill | 🟢 笔记/问答 | 🟡 研究问答参考 |
| html-anything | 🟡 HTML生成 | ❌ 不相关 |
| **humanizer-zh** | 🔴 中文去AI化 | 🔴 **高价值——2hao 去AI化可借鉴** |
| khazix-skills | 🟡 综合 | 🟡 参考 |
| guizang-ppt-skill | 🟢 PPT生成 | 🟡 报告导出参考 |
| baoyu-skills | 🟢 综合 | 🟡 参考 |
| content-research-writer | 🟢 研究写作 | 🟢 **研究写作参考** |

**重点**：humanizer-zh（中文去AI化）——2hao 有 metacomment/工作过程黑名单，可借鉴其更细的中文去AI规则。

## 四、价值矩阵（总结）

```
🔴 高价值：
  对 Claude：knowledge-work-plugins（skill范式）、humanizer-zh（去AI化）
  对 2hao：Unlimited-OCR（研报解析）、awesome-selfhosted（数据自托管）、
          humanizer-zh（去AI增强）、content-research-writer（研究写作）

🟡 中价值：
  对 Claude：awesome-design-md（排版）、notebooklm-skill（问答）
  对 2hao：dbskill（数据访问）、baoyu-skills（综合）

❌ 低价值：
  social-card / illustrations / html-anything（非分析相关）
```

## 六、一句话总结

**对 Claude 最有价值：Anthropic knowledge-work-plugins（skill 是能力扩展标准范式）+ humanizer-zh（中文去AI化）。对 2hao 最有价值：Unlimited-OCR（研报解析，数据源关键）+ humanizer-zh（去AI增强，直接并入黑名单）+ awesome-selfhosted（数据自托管）+ content-research-writer（研究写作）。** 最高优先吸收：**Unlimited-OCR 研报解析 + humanizer-zh 去AI规则**——两者直击 2hao 数据解析和去AI两个核心痛点。
