## 一、fact_base 行业事实库【新模块】

### 新增 `core/fact_base.py` + `data/fact_base.json` 结构
把"行业事实点"结构化沉淀为可检索事实库：
- `add(fact_id, value, level, source, intent, tags)`：新增事实点（R87 分级 verified/corrected/unverified）
- `correct(fact_id, value)`：**用户纠偏** → 旧值入 history，新值标 corrected
- `search(query, intent)`：关键词/意图检索，**corrected > verified > unverified** 排序
- `build_prompt()`：生成注入写作 prompt 的事实库块（分级标注）
- `stats()`：分级分布统计

### 验证

## 二、非上市深化模块【新模块】

### 新增 `core/compute/unlisted_deep.py`
补非上市标的（久通物联）深度估值，四块：
1. **可比融资**：营收 × 可比 PS 倍数 → 估值区间/中值
2. **股权治理**：创始人持股/质押 → 治理风险分（0-1）
3. **退出路径概率**：并购/IPO/下一轮 三路径概率 + 时间窗口
4. **里程碑估值**：按营收目标 × PS 中值分段估值

### 验证（久通假设：营收5000万/PS[3,5,8]）
```
可比融资估值: 1.5~4亿（中值2.5亿）
治理风险: 15%（质押20%）
退出: 并购50% / IPO10% / 下一轮30%
里程碑: 当前2.5亿 → 12个月4亿 → 24个月6亿
```
