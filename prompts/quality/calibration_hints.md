## 评分校准规则

### 1. 严格性原则
- 综合评分 >= 0.9 才能进入 Iron Gate
- 所有单维度 >= 0.50 不能有任何短板
- 不满足即返回写作循环

### 2. 一致性原则
- 同一报告类型使用同一套评分标准
- 评分指标（regex关键词）保持稳定
- 不因报告长度自动调整权重

### 3. 常见评分偏差与纠正

| 偏差类型 | 表现 | 纠正方式 |
|---------|------|---------|
| 宽松偏差 | 轻易给高分 | 严格按正则匹配计数 |
| 首因效应 | 开头好=整体好 | 逐维度独立评分 |
| 晕轮效应 | 某维高分带动其他 | 严格加权计算 |
| 中心化偏差 | 不敢给极端分 | 强制分布：至少1个FAIL才合理 |

### 4. Iron Gate校验项
1. AIGC指纹 < 15%
2. 人感评分 >= 0.7
3. 质量评分 >= 0.8
4. SAC维度覆盖 >= 80%
5. 图表密度达标
6. 数据可追溯（有来源标注）
7. 格式一致（字体统一、无溢出）
8. 禁止模式（无内部方法论标签）
9. 说服力架构完整

### 5. 图表最少数量门禁

| 报告类型 | 图表 | 表格 |
|---------|------|------|
| 行业深度 | >= 5张 | >= 3个 |
| 上市公司 | >= 5张 | >= 3个 |
| 非上市公司 | >= 4张 | >= 2个 |
| 财报点评 | >= 2张 | >= 1个 |

每张图必须有：标题 + 编号 + 数据来源脚注 + 单位标注

### 6. 字数门禁

| 报告类型 | MD正文 | DOCX字数 |
|---------|--------|---------|
| 行业深度 | >= 8000字 | >= MD的70% |
| 上市公司 | >= 6000字 | >= MD的70% |
| 非上市公司 | >= 5000字 | >= MD的70% |
