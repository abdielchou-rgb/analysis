## 市场空间分析（TAM法 — 达摩达兰方法 + 趋势三武器）

在进行市场空间分析时，采用三层TAM法，并结合趋势判断三武器：

1. **TAM （Total Addressable Market）** — 总可寻址市场
   - 全球市场规模（当前+预测，含增速）
   - 中国市场规模（当前+预测，含增速）
   - 市场增速驱动因子拆解（量的驱动 vs 价的驱动 vs 结构变化）

2. **SAM （Serviceable Addressable Market）** — 可服务市场
   - 受技术/政策/地域约束后的实际可服务市场
   - 约束条件说明（如技术路线限制、国产替代比例、政策准入门槛）

3. **SOM （Serviceable Obtainable Market）** — 可获得市场
   - 竞争格局下的公司层面可获得份额
   - 份额驱动因子（产能/技术/客户认证/品牌）

4. **渗透率曲线 + 趋势三武器【增强】**
   - 【加速器】当前渗透率 vs 饱和渗透率，渗透率是否在5-10%加速拐点？
   - 【时光机】人均GDP对标分析（该行业在人均GDP多少时进入加速期？）
   - 【稳态仪】人口结构变化如何影响行业终局？
   - 渗透率曲线形态（S曲线/线性/指数）
   - 达到饱和的时间估计

5. **量价拆分**
   - 量的驱动力（产能扩张/渗透率提升/新应用场景）
   - 价的驱动力（技术升级/产品结构优化/供需关系变化）
   - 综合增速判断

每个数字必须标注来源和置信度。

## 弹性分析与信号验证【新增】

### 弹性分析（王思宇框架）
在行业分析中，请给出以下弹性判断：
1. 需求收入弹性（IED）：行业增速/GDP增速的敏感度
2. 需求价格弹性（PED）：定价权强弱判断
3. 供给弹性（PES）：产能调整的灵活度
4. 综合判断：该行业是**强周期/防御型/中性**？

### 信号验证体系（申银万国框架）
为你的核心判断建立可追踪的信号链：
- **先行指标（1-3个）**：什么变化会先于你的判断发生？来源是什么？
- **同步指标（1-3个）**：什么指标与你判断同步变化？
- **滞后指标（1-3个）**：什么指标确认你的判断已兑现？

## 多思维模型校验【新增】

在撰写分析的过程中，请从以下思维模型中选择至少3个，审视你的每一个核心判断：

| 模型 | 要审视的问题 |
|------|------------|
| 周期 | 当前处于什么周期的什么阶段？位置感正确吗？ |
| 趋势 | 终局思维——这个行业最终会变成什么样？ |
| 反馈 | 是否存在正反馈或负反馈回路？ |
| 共振 | 多个因素叠加会产生戴维斯双击还是双杀？ |
| 赔率 | 如果错了损失多大？如果对了收益多大？ |
| 证伪 | 什么证据会证明这个判断错了？ |
| 杠杆 | 经营杠杆/财务杠杆如何放大或缩小波动？ |
| 复利 | 这个行业的增长是否可持续且有粘性？ |
| 幂律分布 | 竞争格局是二八分化还是均分？ |
| 扩散模型 | 渗透率处于S曲线的什么位置？ |

## 严格要求

1. **图表必须嵌入正文** — 写到一个论点需要数据支撑时，立即插入对应图表。格式：
   
   如图X所示，[图表内容]...[分析]...

   ![图X： 图表标题](图表路径)
   *图X： 图表标题。数据来源： XXX*

   从图X可以看出，[进一步分析]...
   

2. **每个图表前后都要有分析文本** — 不能只放图没有分析，也不能只分析没有图

3. **至少引用每张图1次**，引用时标注图号和含义

4. **表格也必须在正文中**（不是堆在文末）

5. **数据来源在每次引用图表时标注**

6. **【强制】每节开头100字符内必须有判断词** — 如"我们认为"、"我们判断"、"核心判断"、"核心分歧在于"、"预计"中的至少一个。这是通过门禁的必要条件。

7. **【强制】推理链完整** — 每个分析段落必须有"因为→所以→因此"的推理链。使用"这意味着"、"根源在于"、"导致"、"从而"等推理连接词。

8. **【强制】数据交叉验证** — 关键数据点必须标注来源并做多源验证（如"Yole数据显示…；据公司公告…；两者偏差在5%以内"）

9. **【强制】So What链** — 每个分析板块末尾必须给出"这意味着…因此我们建议…"的投资含义

10. **正文引用图表数据做分析，而非仅贴图** — 每张图嵌入后，要提取图中关键数据点做定量分析

11. **【强制】字数要求** — 行业深度报告正文不少于10000字（中文）。必须充分展开每个分析维度。

12. **【强制】表格必须丰富** — 报告中至少包含3个数据表格（Markdown格式），表格须有标题和来源标注。

13. **【强制】弹性分析【新增】** — 必须包含需求收入弹性判断

14. **【强制】信号链【新增】** — 必须包含三级信号链（先行/同步/滞后）

15. **【强制】多模型校验【新增】** — 必须使用至少3种思维模型审视核心判断



## 决策门结构（必须先执行）
在开始正式分析前, 先判断3个决策门:
- 决策门1: 行业是否存在真正的稀缺层/瓶颈? (GO/NO-GO)
- 决策门2: 利润正在迁移还是锁定? (GO/NO-GO)  
- 决策门3: 是否存在明确的投资机会(Bold Call)? (GO/NO-GO)
如果少于2个GO, 建议跳过深度分析。

## 资金面分析【V3新增】
必须分析:
1. 北向资金对该行业板块的近期净流入/流出趋势
2. 公募基金仓位变化
3. 两融余额变化
4. 大股东增减持动态
给出一个综合判断: 资金面是否支持我们的观点?

## 产业链联动【V3新增】
不要孤立分析该行业。必须回答:
- 上游什么变化会传导到本行业?
- 本行业的变化会如何影响下游?
- 产业链的瓶颈层在哪? 利润集中层在哪?

## 政策力度评分【V3新增】
将政策分析量化:
1. 政策方向评分: -10(严格限制) 到 +10(大力鼓励)
2. 执行率判断: 中央政策在地方的执行情况
3. 当前政治周期定位
4. 补贴阶段: 培育/退坡/已退出

## So What 三层链【V3新增】
每个分析板块末尾必须回答:
1. 数据说明了什么? (What)
2. 这对投资者意味着什么? (So What 1)
3. 基于此, 投资者具体应该怎么做? (So What 2 -> Action)

## Track Record【V3新增】
在报告开篇, 显示分析师对该行业的预测历史准确率。
