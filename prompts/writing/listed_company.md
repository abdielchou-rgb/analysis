## 估值方法论（含达摩达兰补充 + 戴维斯双击）

### DCF估值（FCFF法）
- **WACC计算**： Rf + ERP x Beta（ERP含国家风险溢价CRP调整——中国A1评级对应约1%）
- **FCFF驱动因子**： EBIT x （1-t） + D&A - CapEx - DeltaOWC
- **终值**： TV = FCFFn x （1+g） / （WACC-g）
- **失败概率调整**： 对于亏损/早期阶段公司，明确失败概率假设（通常5-15%），DCF估值乘以生存概率【参考Damodaran方法】
- **流动性折价**： 非A股/小市值适用，通常10-20%

### 营收交叉验证（双路径）
用两种独立路径估算营收，对比收敛/分歧：
1. **自下而上（Bottom-up）** ： 量 x 价 x 利用率/产能，逐业务线测算
2. **自上而下（Top-down）** ： TAM x 市场份额，用行业数据验证
3. **若两者差异<20%**： 评为高置信度，取均值
4. **若两者差异>20%**： 评为低置信度，说明分歧原因，取保守侧

### 可比估值
- PE/PB/PS/EV/EBITDA多维度
- 折溢价调整： 规模/成长性/利润率/流动性
- A股国际桥接： 含国家风险溢价调整

### 戴维斯双击/双杀分析【新增】
- 盈利趋势判断： EPS增长方向（加速/减速/反转）
- 估值趋势判断： PE变化方向（扩张/收缩/稳定）
- 双击（EPS↑ x PE↑） vs 双杀（EPS↓ x PE↓） vs 分化（一升一降）

### 敏感性分析
- 5x5矩阵（营收增速 x WACC）
- 关键驱动因子变动对目标价的影响

### 赔率评估【新增】
- 潜在涨幅（我们的目标价/当前价 - 1）
- 潜在跌幅（最差情景/当前价 - 1）
- 盈亏比（潜在涨幅/|潜在跌幅|）
- 凯利公式视角下的最优仓位

## 决策门结构（必须先执行）
在开始正式分析前, 先判断3个决策门:
- 决策门1: 市场共识与我们判断是否存在显著分歧? (GO/NO-GO)
- 决策门2: 分歧是否有商业模式层面的支撑? (GO/NO-GO)
- 决策门3: 当前估值是否有吸引力? (GO/NO-GO)
如果少于2个GO, 建议跳过深度分析。

## 会计穿透分析【V3新增】
超越表面财务数字, 穿透到会计政策层面:
1. 收入确认政策（一次性确认 vs 分期确认 vs 完工百分比）
2. 研发资本化率 vs 行业惯例(是否激进?)
3. 商誉减值测试的关键假设(增长率/WACC)
4. 关联交易定价是否公允
5. 是否存在表外负债/或有负债
6. 非经常性损益占比

## 资金面分析【V3新增】
必须包含: 北向资金/公募仓位/大股东增减持/限售股解禁
综合判断资金面对股价的短期支撑/压力。

## So What 三层链【V3新增】
每个分析板块末尾必须回答:
1. What? 数据说明了什么
2. So What 1? 对投资者意味着什么
3. So What 2 -> Action? 具体该怎么做
