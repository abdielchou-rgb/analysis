# 决策备忘录 Skill

## 触发
报告类型为 decision_memo（委托方拍板场景）时加载。

## FP0 意图第一公民（最高优先级）
1. **先确认委托方问题清单**（谁读/决策点/必答问题）——缺此步不得进入写作
2. 报告结构由必答问题驱动，不由 SAC 模板驱动
3. 用 intent_parser 解析必答问题 → 报告结构

## 类型铁律（R83 教训）
- ❌ 禁止投资评级/目标价/EPS/二级市场用语
- ❌ 禁止匿名化委托方
- ✅ 执行摘要必须：进/不进/条件性进 + 依据 + 投入 + 回报 + 最坏损失
- ✅ 决策引擎产出卡位评分/三年投入/最坏损失（禁 LLM 自编）

## 必用框架
- 产业生命周期（成熟/成长/抢位 → 资源分层）
- 利润池 + 卡点评分（柯力卡在中游最薄环节 → 向两端延伸）
- 波特五力（中端机会带可切入的框架依据）
- 中美竞争 + 宏观传导（供应链地缘风险 + 需求传导链）
- 商业模式分类（产品型→平台型延伸影响估值）
- 情景触发引擎（scenario_engine：触发信号驱动概率，非拍脑袋）
- 实物期权（s_curve_engine real_option：扩张/放弃/延迟期权）
- 并购协同三源（ma_synergy_engine：收入/成本/税协同，若涉及并购）

## 内部整合 vs 外部合作（关系判断）
- 若标的是委托方子公司/关联方 → 集团内部整合视角（非外部谈判）
- 用 relation_gate 检测身份错位

## 财务纪律
- 经营期 NPV 唯一主指标，悲观情景算术自洽
- 税务/关联交易口径统一，敞口区间+压力测试
- A/E/F/B 标注 + 测算底稿清单

## 人类门禁（强制）
- 高险决策文档必须 human-gated（WDSS）
- 结论可回溯（决策 → 数据 → 来源）
- 交付附决策审计 + 双向溯源

## 写作姿态
加载 author_pose skill
用 2hao verify_report 一键校验

## 报告结构
执行摘要（一句话结论）→ 决策建议 → 行业真相 → 投入产出 → 战略卡位 → 最坏损失 → 衍生价值 → 路线图
