# 行业分析框架包 Skill

## 触发
行业深度报告（industry_deep）或任何报告含行业分析章节时加载。

## 七框架（框架适配检查按行业驱动类型注入）

### 0. 渗透率 S 曲线（s_curve_engine）
- 按渗透率+增速定位：导入(<10%)/起飞(10-50%高增)/扩张(50-80%)/饱和(>80%)
- 比成熟/成长定性更精确，决定策略

### 1. 产业生命周期（life_cycle_mapper）
- 四阶段定位：导入/成长/成熟/衰退
- 每阶段策略不同：成长投扩张/成熟投降本/抢位期投速度
- 不同细分可处于不同阶段（如油位整体成熟、罐箱成长）

### 2. 波特五力
| 五力 | 评估 |
|------|------|
| 供应商议价 | 上游集中度（双寡头→强议价） |
| 买方议价 | 客户分散度 + 转换成本 |
| 替代威胁 | 替代技术/方案 |
| 新进入者 | 认证/渠道/规模壁垒 |
| 现有竞争 | 份额集中度 |

### 3. 利润池（McKinsey Profit Pool）
- 环节利润池 = 收入 × 利润率
- 各环节占比 → 利润最厚/最薄 → 卡位策略（向厚端延伸）

### 4. 竞争格局
- 两极夹中间 / 份额集中度
- 玩家分层 + 对标表（营收/毛利/份额）

### 5. 中美竞争（geopolitical_engine）
- 政策时间线 + 双轨情景 + 国产替代传导 + 对美暴露度/自主可控度
- 上游供应链地缘风险

### 6. 宏观传导（macro_context 适配）
- 政策/内需驱动行业：原油→下游→设备 传导链（非宏观DDM估值框架）
- 宏观敏感行业：DDM三要素（盈利/流动性/风险偏好）

### 7. 商业模式分类（business_model_classifier）
- 产品型/平台型/项目型/服务型
- 影响估值逻辑（产品PS vs 平台SaaS倍数）

## 框架适配（防错配）

|---------|---------|--------|

## R93 判断驱动结构（行业报告核心）

行业报告 = 一套行业判断 + 公司作论据验证，不是公司信息堆砌。

### 结构骨架
```
行业判断（阶段/主线/空间/利润池）→ 上市公司验证 → 非上市公司前瞻 → 配置建议
```

### 上市公司 = "现在"的论据（验证行业判断）
- 每个行业判断必须用上市公司数据验证："判断说X环节最受益，铖昌+91%/卫通16.7%净利率已兑现"
- 传导次序：对比不同环节上市公司财务强度 → "元器件先受益→整机后受益"的早期特征
- 若公司数据与判断矛盾 → 诚实标注"传导未到"或"判断需修正"，不硬凑

### 非上市公司 = "未来"的论据（前瞻信号）
- 一级市场融资/估值/技术押注是行业方向的先行指标
- "判断说回收是2027分水岭，蓝箭融资220亿+天兵225亿已在为回收定价 → 验证成长期判断"
- 不写孤立威胁清单，回扣行业判断

### 禁止
- ❌ 行业报告给个股目标价（对象错位）——用行业评级+受益环节排序
- ❌ 开篇"我们vs一致预期"分歧（个股框架）——开篇写行业阶段+主线
- ❌ 孤立介绍公司（上市/非上市各来一段，游离于判断）
